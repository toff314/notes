# 计算语言学基础 · 绪论（2 学时）· 听课笔记

> **本讲一句话**：绪论不教算法，它给整门课立坐标系——**CL 研究什么、为什么难、几十年怎么走过来的**，以及这门课怎么上。
> **结构**：课程安排 → 什么是 CL → CL/NLP/HLT 三名一物 → 核心问题（宏观）→ 一条处理链（音→字→词→句）上的歧义 → 消歧 → 技术简史 → 课程体系与评分 → 中国先驱
> **可疑处**：讲师名、课程创建者等专名以 PPT 为准（见 corrections.md）
> **与我何干**：理解了"歧义无处不在 + 消歧靠语言内外知识"，后面每章（词法/词义/语言模型/句法）都只是这条主线的一个切面。

### 2. 什么是计算语言学（CL）

**线索**：CL 到底研究什么？为谁服务？
**内容**：
- 【师/PPT】**定义**：从**计算视角**对自然语言进行的科学研究，为各种自然语言现象**建立计算模型**
- 【师】**两个目标**：
  - **科学目标**——给语言/心理语言现象提供**计算解释**（揭示语言之奥秘）
  - **技术/工程目标**——让机器获得**处理人类语言的能力**，完成语言处理任务
- 【师】**研究对象**：人类自然语言（汉语、英语……乃至**手语**）
- 【师】它是**两个领域的交叉**：计算机科学的计算方法 × 语言学的语言知识
- 【师】个人感受：早期"搞 CL 的有一批是从语言学背景过来的"，也有从信息工程转过来的

**一句话总结**：CL = 用计算模型解释语言 + 让机器会用语言，是计算与语言学的交叉。

### 3. 三个名字：CL / NLP / HLT

**线索**：CL、NLP、HLT 是一回事吗？
**内容**：
- 【师】**CL 与 NLP 常互换使用**，但有细微差别：
  - **CL** 包含把语言**作为对象的揭示性研究**（偏**科学目标**）
  - **NLP** 更强调**技术/工程目标**，对科学目标关注较弱
- 【师】现状判断：**"技术/工程上的发展已超前科学认识"**——大模型能用，但为什么行？还不清楚（可解释性不足、有幻觉）
- 【师】**HLT（Human Language Technology）**：把语言的**物理载体**转成计算机可处理的形式
  - 书面文字 → **OCR**（Optical Character Recognition）
  - 口头语音 → **ASR**（Automatic Speech Recognition）
  - 其他载体：手势、体型（如挥手）
  - 二者关系：**为 CL 提供材料，也能得到 CL 的帮助**
- 【PPT】NLP 的定义出处：Manaris 1998、Jurafsky 2009（P5）

**一句话总结**：CL 偏科学、NLP 偏工程、HLT 管"把语言搬进电脑"，三者常混用。

### 4. 核心问题（宏观）：计算机如何进行语言处理

**线索**：没有大模型的年代，人们从哪找思路？
**内容**：
- 【师】宏观问题一句话：**计算机如何进行语言处理**；听上去简单，早期极难
- 【师】三条可借鉴的路径（PPT P8–9）：
  1. **向人学**：人是 NLP 最好的原型 → 借鉴**社会语言学、心理语言学、神经语言学**（"神经"指**生物神经**，不是神经网络）
  2. **把语言当客观对象**：对语言做**大量分析/统计**，发现有效方法
  3. **把语言当一般符号化数据载体**：用**数据分析**方法找内在规律
- 【师】第 1 条其实已经在生效：**Transformer 的 attention 就借鉴了人的注意力机制**
- 【师】为什么第 3 条成了主流：语料（互联网文本）最早变得丰富，且"**不用标注，拿语言本身就行**"（自监督掩码式训练）

**一句话总结**：向人学、把语言当对象、把语言当数据——三条路，第三条赢了。

### 5. 从音到字：一条处理链的起点

**线索**：老师为什么拿"拼音转汉字"开场？
**内容**：
- 【师】给出一串带声调的拼音：`yi(3) wei(4) he(2) dui(4) ba(1) ren(2) zhen(4) dong(4) shou(3)`，问：**该转成哪串汉字？**
- 【师/PPT】难点：**汉语普通话只有 402 个音节、约 1300 多个读音，汉字却有数万个**——一个读音对应大量同音字（"以/乙/已/矣…"）
- 【师】**现场实验**：把同一串拼音丢给 2023 年的大模型，即使反复追加约束（"你是汉语专家""直接给结果""必须是有意义完整的句子"），**大模型仍做得不好**；到 2024 年 9 月再试，**有明显进步**——技术进展很快
- 【师】老师请同学朗读**赵元任《施氏食狮史》**：全文同音、仅声调不同，是最极端的例子
- 【师】这不是文字游戏：**同一读音的全部组合数量巨大**，模型只能靠**算概率**去挑，语料不够大就抓不住正确那句

**一句话总结**：从音到字就已经是"概率搜索"——同音字多，靠统计才选得对。

### 6. 词选择、词性与词义

**线索**：拿到汉字串之后，为什么不能直接懂？
**内容**：
- 【师】**词选择（从字到词）**：同一串汉字可以有**多种切分**——"以为何对巴人阵动手"可切成
  `以/为何/对/巴人阵/动手`、`以为/何/对/巴人阵/动手`、`以/为何/对/巴人/阵/动手` …
- 【师】**词性选择**：同一个词可有**多种词性**（"以"可为介词/动词/……）；计算机在"一对一"的映射上比人快得多，**一遇到组合就难**
- 【师】**词义选择**：一个词有非常多义项——"动手"可表示"开始"，也可表示"自己用手做"
- 【师】现场例子：**"杭州市长春药店"**、以及"她这个人真有意思……"那段绕口令（同一个"意思"反复变义）
- 【师】"3 年处理"真正到这些特殊情况时，**碰到的都是这些问题**

**一句话总结**：切分歧义、词性歧义、词义歧义，一层层叠上去。

---

### 7. 结构歧义与句意歧义

**线索**：词都定下来了，句子为什么还有歧义？
**内容**：
- 【师】**句子结构选择**：例 **"重要会议精神"**——"重要"修饰"会议"还是"会议精神"？两条**句法分析路径（NP 树形分叉）**都成立
- 【师】真实案例：某**搬迁腾退补偿办法**定义"补偿受益人"——**"被搬迁腾退院落内户口在册的产权人及其直系血亲（含配偶）"**，"户口在册"修饰谁？**已经引起纠纷**——在自然语言里，这"不光对计算机难，人理解也难"
- 【师】**句子意义选择（不同语境）**："如果你到了我还没到，你就等着吧 / 如果我到了你还没到，你就等着吧"——语境一变，语义就变
- 【PPT】**歧义无处不在**（P23）：音→字、字→词、词性、词义、句法、句义，每一层都可能歧义

**一句话总结**：从词到句、从结构到语境，歧义逐层放大——还牵出真实的纠纷。

### 8. 落脚点：消歧（Ambiguity）

**线索**：整门课的核心任务到底是什么？
**内容**：
- 【师/PPT】**CL/NLP 的核心任务 = 消歧（Ambiguity resolution）**
- 【师】如果语言没有歧义，都是"一对一映射"，计算机又快又准；**难就难在歧义无处不在**
- 【师】**消歧的两个难点**（PPT P24–25）：
  1. **语言内部的知识**：语音（"以/已"同音）、词汇（"以后"是词、"已后"不是）、结构（"看书"合法、"他书"不合法）
  2. **语言之外的知识**：**"咬了猎人的狗"**可有两种解读；换成**"骂了猎人的狗"**就只剩一种——靠的是**常识**
- 【师】引出的根本问题：**语言计算模型如何表示/获取知识，又如何在具体场合选择/使用知识**

> 📌 **本讲最重要的一句**：消歧 = 用**语言内 + 语言外**的知识做选择——这也是后面每一章（词法、词义、语言模型、句法）的共同主线。

**一句话总结**：CL 的一切最终落在消歧，而消歧的难点在"知识怎么表示、怎么选用"。

### 9. CL/NLP 技术简史（1940s → 2020s）

**线索**：这条线是怎么一步步走过来的？
**内容**：
- 【PPT P27】一句话进度条：`1940s 准备 → 1950s 起动(MT) → 1960s 冷静(CL 术语提出) → 1970s 奠基 → 1980s 理性主义(知识来自专家) → 1990s 经验主义(知识来自语料) → 2000s 机器学习 → 2010s 深度学习 → 2020s 大语言模型`
- 【师】1940s：三条线同时起步——**计算理论**（1936 图灵机、1951 Kleene）、**概率统计**（1948 香农的 Markov/N-gram）、**神经网络**（1943 M&P 神经元、1949 Hebb 律）；Weaver 1946/7 提出 MT 想法
- 【师】1950s：**图灵测试（1950）**；MT 由军事科技情报需求驱动（1954 IBM 701 俄英 MT，首次自动翻译 60 多句）
- 【师】1960s：**1962 ACL 成立**（时名 Association for Machine Translation and Computational Linguistics）；1966 **ALPAC 报告**；乔姆斯基批判概率方法——**"a sentence 的概率这个概念毫无用处"**
- 【师】1980s：**理性主义 / 专家系统**当道，把专家知识写成规则
- 【师】1990s：**经验主义**——语料上来，统计方法兴起（HMM/SVM/LSTM/N-gram）；Jelinek 名言：**"每解雇一个语言学家，识别器的性能就提升一些"**
- 【师】2000s：**机器学习**（2001 CRF、随机森林；2003 LDA；2006 DBN）；曾有"**给我足够的平行语料，几小时内就能给你任意两种语言的翻译系统**"的自信
- 【师】2010s→2020s：**深度学习**（词向量→知识向量化→序列模型→seq2seq→注意力→预训练）→ **LLM**：**规模大**（容量/知识来源/学习能力）、**基础通用**（多任务）
- 【PPT P41】研究史总结：两个根本变化——**表示变了**（独立符号→上下文敏感向量，2013-）、**范式变了**（分任务建模→大模型做基础模型，2018-）

**一句话总结**：80 年从"专家写规则"走到"数据训大模型"，表示与范式各变了一次。

### 12. 中国 CL 先驱（PPT 有、转写未覆盖）

**线索**：国内这条线是怎么起头的？
**内容**：
- 【师】老师原话："后面给了一些咱们国家最早的从事自然语言中文研究的这些老先生……**我下节课再说几句也可以**"
- 【PPT P47–50】**刘涌泉（1929-）**：中国机器翻译开拓者；1958 年莫斯科 MT 会议发表**中国第一篇 MT 论文**；1959 年主持的**俄汉 MT 在 104 机上试验成功**（输出电报码）；著《机器翻译浅说》；还是**字母词的倡导者**
- 【PPT P51–55】**刘倬（1933–2022）**：主持研制 **JFY 型英汉 MT 系统**（I–IV 型，1976–1997）；提出系统设计四条原则（开放性的"词典规则化、规则函数化"、个性与共性结合、以轴心词为中心的随机上下文分析、自研 JFY 语言与追踪功能）
- 【PPT P56–58】**董振东（1937–2019）**：1987 年研制"**科译 1 号**"（国际首个可商品化的英汉 MT），后落地为"**译星**"；90 年代设计 **《知网》(HowNet)**——用 **2000 多个"义原"(Sememe)** 描述十几万词，与 WordNet 思路不同；2019 年后以 **OpenHowNet** 开源
- 【PPT P59】其他前辈：刘开瑛、王开铸、高庆狮、姚天顺、黄昌宁、吴立德、俞士汶、冯志伟、马希文

**一句话总结**：刘涌泉开 MT 先河、刘倬做 JFY、董振东做科译 1 号与知网——中文 NLP 的根。（本块老师留到下节细讲）

## 全篇 takeaway

1. **CL = 计算视角下的语言研究**，科学目标（揭示语言之谜）与技术目标（让机器会用语言）并行；CL 偏科学、NLP 偏工程、HLT 管载体转换。
2. **核心问题是消歧**：语言在音/字/词/词性/词义/句法/句义每一层都有歧义，消歧要**语言内 + 语言外**两类知识。
3. **技术史主线**：规则（理性主义）↔ 统计（经验主义）来回摆动，最终走到大模型；两个根本变化是**表示向量化**与**范式大模型化**。
4. **课程组织**：一切语言计算 = 语言串 → 中间表示 → 输出串；后续章节都是这条链上的一个切面。
5. **考核**：8×6 阅读 + 10 报告 + 2 参与 + 40 实践 = 100，**11/30 24:00 截止**，交教学云平台。
