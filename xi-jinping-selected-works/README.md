# 习近平著作选读 · 听课笔记

北京邮电大学 · 马克思主义学院。**专题教学**：老师讲**一个导论 + 两个专题**；课堂含**三个环节**——文献精读、老师授课、分组研讨。本次为**开课第一讲（导论）**。

- **课型**：导论 / 管理类偏重（含自我介绍、课程安排、考核与分组），叠加首个导论的总论
- **本仓库收录**：课堂录音转写 → 结构化听课笔记
- **本课无课件（PPT）**：新开课、老师未使用 PPT，笔记为**单源（转写）降级版**，专名/文献名不确定处一律 `❓ 存疑`
- **课程页**：从 [`index.html`](index.html) 进入，可在线阅读本讲笔记

## 产物说明

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `notes.md` | **主笔记**：按讲者思路主线重排，每节「线索 / 内容 / 一句话总结」 | 复习主线；约 8–10 分钟读完 |
| `outline.md` | **思路大纲**：主线 + Mermaid 结构图 | 先看图建立框架，再读正文 |
| `questions.md` | **自测 + 疑问 + 待查** | 遮住主笔记自测；疑问项待下次课或查资料 |
| `corrections.md` | **勘误**：本课无 PPT，转写↔PPT 差异检查无法执行；列转写内部 ASR 存疑 | 核对专名与篇目 |
| `spinoffs.md` | **衍生选题**：可独立成文的点，按下游写作流水线入参格式打包 | 直接复制「主题串」投喂写作技能 |

## 标记约定

`【师】` = 老师所讲；`【PPT】` = PPT 有、转写未覆盖（本课无 PPT）；`❓ 存疑` = 转写/识别不确定。

## 生成方式

由 **`write-lecture-notes` 技能**产出：输入＝录音转写文本（必选）+ 课件 PPT（本课未提供，降级单源），输出＝上述五类产物。
本仓库为**交付与阅读位置**；转写原件（`raw/`）为本地素材，**不入库**。
