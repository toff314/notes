## 五门课一句话判决

1. **如何成为学习高手**（3.5/5）— 五门中 SNR 最高。本质是「把认知心理学翻译成中文技巧」的整理与合成，金矿集中在记忆底层逻辑（考试思维、连点成线、组块化）。**优势**：数据可信度高（16/23 可追溯真实心理学成果，0 编造）；**短板**：后半段自律/时间管理模块重复度高，有软广。

2. **AI原生开发工作流实战**（3.2/5）— AI 工程方法论课的标杆。讲"AI 原生开发"（规范驱动开发、Agent Skills、TDD 与 AI 协同），约 60% 方法论 + 40% 工具操作。**风险**：方法论快速演进、工具部分随版本贬值，且存在"精确百分比无出处"的数据隐患（"领先 90% 开发者"等）。

3. **企业级多智能体设计实战**（3.0/5）— 44 讲大课，精华在后半程（数字员工团队、企业级加固、生产交付），是独立于 CrewAI 框架、可迁移的工程方法论；前半程偏框架 API 走读和 XiaoPaw 演示，有 RGB/C.U.P./五步SOP 等品牌化重命名信号。**风险**：约 40% 量化声明无法追溯（629 次测试 80% 劫持率、17.2x 误差放大）。

4. **AI大模型之美**（2.79/5）— 2023 年"用接口替代训练"的 LLM 入门课，历史价值大于实用价值。精华仅 RAG/第二大脑、多步提示语/CoT 2 讲，它们准确预见了后来主流范式。**风险**：LangChain/llama-index 的 API 已全部废弃，30+ 讲是会过时的库教程。

5. **LangChain实战课**（2.7/5）— 引用规范、教学清晰但原创为零的教程课。八成是 LangChain 官方文档的中文复述 + 鲜花案例，方法论 vs 水份约 3:7。唯一金矿是 ReAct 那一讲。

## 三门 AI 课的交叉命题（可做对比文章）

三门课共同指向同一条技术演进主线：**LLM 应用开发从"提示工程" → "链/代理抽象" → "AI 原生工作流"的范式迁移**。

- `AI大模型之美`（2023）讲的是最底层：用接口替代训练，如何和模型说话。
- `LangChain实战课`（2023）讲的是中间层：Chain / Memory / Agent / RAG 这些抽象。
- `AI原生开发工作流实战`（2024-2025）讲的是最上层：这些抽象如何沉淀成工程师的日常工作流（CLAUDE.md、Agent Skills、MCP、TDD）。
- `企业级多智能体设计实战`（2024-2025）则深入到多 Agent 协作的工程化落地（协作模式、企业级加固、生产交付）。

一个潜在的爆款选题：**《三年四堂课，看清 LLM 应用开发的一条主线》**，用四门课的消化结果串起完整演进史。
