# 20 Rules：员工手册与门禁系统

**结论**：Claude Code 有两套规则。指令规则写进 `.claude/rules/`，是认知约束，Claude 可以遵守也可以忽略；权限规则在 settings 里，是行为约束，系统不给选择。

**证据**：rules 支持全局加载与 `paths` 条件加载；关键细节是"一旦加载就不卸载"，paths 控制何时加载而非何时生效；CLAUDE.md 超过 500 行必须拆，200 行以内不必为组织而组织。

**关系**：承接 19 的无人值守问题——没人盯着时谁来定规矩；与 16 的 Stop Hook 构成"软规范 + 硬拦截"双层。

**批判**：课程未展开规则冲突与优先级仲裁；"500 行必须拆"是经验阈值，不是实测结论。
