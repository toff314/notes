# 第 22 讲 · 核心五问：失败模式自检（🥇 4.1）

- **结论**：AI 压缩的是体力活（写文档/扫代码/写测试），不是判断活。**工作量下来 ≠ 思考量下来**——省下的时间必须投入业务判断和深度 review，否则只是更快地做错。三个失败模式：拆需求偷懒、跳过决策点审核、跳过现状确认，各配自检问题。
- **证据**：三个失败模式直接对应 17/18/20 讲的坑，形成方法论自洽闭环。"99% 归因于该停的地方没停"为绝对化表述，无数据 🚩，引用需注明是讲师经验。
- **与其他讲的关系**：全课认知层收束，方法论迁移（24-33 讲）的判据来源。
- **我的批判**：最值得反复读的一讲，把整门课的认知浓缩成可执行清单；但绝对化数字暴露了讲师叙事习惯——读这门课要时刻区分"框架"与"修辞"。
