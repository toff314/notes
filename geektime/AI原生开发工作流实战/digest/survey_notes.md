# 课程通览：AI原生开发工作流实战

## 基本信息
- 模块数：8
- 总讲数：28
- 总时长：约 340 分钟
- 讲师：Tony Bai
- 课程定位：以 Claude Code 为核心载体，系统性传授"AI 原生开发工作流"（规范驱动开发 + 上下文工程 + 能力扩展 + 安全 + 自动化）的工程方法论

## Adler 两问（检视阅读阶段必答）
- **Q1: 这门课整体讲了什么？**
  这是一门"以规范（Spec）为中心、以命令行 Coding Agent 为引擎"的 AI 原生开发方法论课。核心主张：AI 时代工程师的价值从"写代码"倒转为"设计规范、编排工作流、治理质量"，而落地这套思想需要掌握三条主线——可执行的规范（spec.md/plan.md/tasks.md）、持久化的上下文（CLAUDE.md/constitution.md）、可编排的行动（Slash Command/Hooks/Skill/Subagent/MCP）。课程后半段用 Go 项目 `issue2md` 走完"需求→设计→TDD 编码→审查→CI/CD→维护重构"的完整闭环。

- **Q2: 作者想要解决什么问题？解决了多少？**
  要解决的是"AI 助理升级为 AI 同事"过程中的三大摩擦力：上下文摩擦力（反复搬运上下文）、工作流摩擦力（AI 建议无法直接执行）、认知摩擦力（心流被打断）。**已解决**：给出了系统化的上下文分层体系、能力封装矩阵、安全底座和 CI 集成的完整方案。**未解决/回避**：SDD 在多人大团队落地的一致性（答疑里承认"人性本懒"）、长上下文注意力衰减、以及工具快速迭代导致的过时风险，均只有原则性回应而无成熟方案。**回避**：几乎没有给出失败案例和反面数据（全课几乎全是"一次成功"的正面演示）。

## 整体印象
- 课程主线：**规范是真理之源** —— 一切能力（上下文、命令、技能、安全、自动化）都在服务"把意图精确编译为代码"这个核心。
- 最大亮点：概念篇的 SDD（02）与实战篇的 TDD 心法（19）构成了真正的思想内核；前沿速递的"Skill 工程心法"是意外惊喜。
- 明显水份：21 讲（Dockerfile/Makefile 大段源码走读）、04 讲（纯环境搭建）、结束语/结课测试。
- 独特之处：罕见的"从第一性原理出发、完整闭环到 CI/CD 与维护"的中文 AI 编程课程，且坚持"手工 Prompt 而非依赖 spec-kit"的教学路线。
- **形式/内容判断**：这门课约 60% 在"教思维方式"（SDD、上下文哲学、能力封装范式），40% 在"教工具操作"（Claude Code 具体配置与命令）。思维方式部分价值密度高，工具操作部分随版本快速贬值。
