# LangChain实战课 — 5 分钟速览

## 如果你只记住一件事
LangChain 的精华不是那些组件 API，而是"**CoT 提升推理却解决不了幻觉 → 所以要让 LLM 用工具 → 这就是 ReAct 代理**"这条认知链——LLM 从聊天机器人升级为能自主行动的智能代理。

## 3 个核心框架
1. **Model I/O**：任何 LLM 应用 = 输入提示(Format) + 调用模型(Predict) + 解析输出(Parse) 三步。
2. **ReAct**：推理(Reasoning: 观察+思考) + 行动(Acting: 调工具/给答案)，LLM 动态决定操作序列。
3. **RAG**：给非结构化数据建"向量地图"，检索增强生成，企业落地量最大。

## 5 个可操作方法
1. **Zero-Shot CoT**：提示里加一句"Let's think step by step"就能提升推理（第05讲）。
2. **Few-Shot + 语义选择器**：用向量相似度动态挑最相关示例，省 Token（第04讲）。
3. **StructuredOutputParser**：让模型返回 JSON，自动转结构化数据（第03/07讲）。
4. **记忆选型**：短对话用 Buffer，长对话用 SummaryBuffer（总结早期+保留近期）（第10讲）。
5. **文本分割三考量**：chunk 大小看上下文窗口 + 任务类型 + 文本结构（第15讲）。

## 1 个反直觉观点
提示工程里最神奇的技巧，不是精心设计的复杂模板，而是 Zero-Shot CoT 里一句大白话"让我们一步步思考"——一句话的魔法提示，就能显著提升模型的复杂推理能力。

## 值不值得花时间？
**值，但要挑着读** — 如果目标是"从零上手 LangChain"，这门课的中文讲解 + 可跑通代码比啃英文文档友好；但只有约 30% 内容（提示工程、ReAct、记忆、RAG、多代理）有长期复用价值，其余七成是官方文档复述和鲜花案例演示。建议只读 4-8 讲精华，跳过环境配置、项目实战源码和所有加餐。
