企业级多智能体设计实战 — 5 分钟速览

如果你只记住一件事

多智能体的核心不是"调框架"，而是"组建数字员工团队"——把人类团队的管理学（角色、协作、审批、复盘）工程化。

3 个核心框架

  1. Harness Engineering 三代演进：控制权从"写提示词"（骑手）→"组上下文"（教练）→"造环境"（牧场主）。
  2. Orchestrator 三关键设计：Task 对象精准传参、子 Agent 隔离沙箱、结果传路径不传内容——主 Agent 无写工具。
  3. 三维隔离判断法：记忆/技能/决策偏好三个维度，两个以上显著不同才新建角色，否则扩 Skills。

5 个可操作方法

  1. 邮箱用三态状态机（unread→in_progress→done）而非 read:bool，防崩溃丢任务。
  2. 复盘用 root_cause 枚举逼出分类思考，打破"下次注意"式复述。
  3. 成本围栏在 Hook 层用代码硬停止，不靠 Agent 自觉。
  4. 权限 Default-Deny，密钥在工具执行层注入、不上 LLM 上下文。
  5. 告警用消耗率（预算燃烧速度）而非原始阈值，噪声减 90%。

1 个反直觉观点

AI 项目失败的第一原因不是技术不够好，而是选题错了——MIT 报告 95% 的企业 GenAI 试点未产生可测量的业务影响，因为"用正确的技术解决了错误的问题"。

值不值得花时间？

值——但要挑着看。后半程（模块四/五 + 生产交付篇，约 15 讲）是独立于框架、可迁移的原创工程方法论，含金量高；前半程（架构思维 + 模块一/二/三）偏框架 API 走读和 demo 演示，可快速掠过。
