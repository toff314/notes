课程通览：Claude Code 企业级全链路开发实战

基本信息

  • 模块数：10（含热点速递、开篇词、结课测试等附属模块）
  • 总讲数：37
  • 总时长：约 6 小时（正课 32 讲 + 附属内容）
  • 讲师：Robert（十多年基础设施/后端经验）
  • 课程定位：用 Claude Code 从零造一个"简版 Dify"（Hify，AI Agent 开发平台），全程演示 AI 原生开发的方法论

Adler 两问（检视阅读阶段必答）

  • Q1: 这门课整体讲了什么？

一门"用 AI 工具做工程"的方法论课，载体是用 Claude Code 从零构建 Hify（简版 Dify）的完整项目：认知框架 → 顶层设计 → 工程搭建 → 核心功能（Provider/Agent/对话/RAG/工作流/MCP）→ 测试部署 → 复盘。核心主张是：瓶颈不在 AI，在人；贯穿全课的方法是规范驱动开发（SDD），即先定规范、再让 AI 按规范执行、人验证、迭代规范。

  • Q2: 作者想要解决什么问题？解决了多少？

解决"同样用 Claude Code，效果天差地别"的问题。作者给出的答案是：角色转变（你是架构师，AI 是工程团队）+ 方法论（SDD、咨询模式、领域四问、任务拆解、质量体系）。已解决：给出了一套可复用的工程方法论和完整项目骨架；未解决/回避：计算机基础厚度、垂直领域深度、大规模系统经验——作者在 32 讲诚实承认这些"没给你"，并把它变成"接下来往哪走"的路线图。

整体印象

  • 课程主线：一条明线（从零造 Hify）+ 一条暗线（AI 原生开发方法论），暗线才是真正的交付物。
  • 最大亮点：方法论密度高且自洽，SDD 闭环、领域四问、四步探路法、质量体系四层次、老项目改造三原则，彼此咬合，不是散装技巧堆砌。
  • 明显水份：实操课（07/12/19/26/30）与对应正课高度重复，占 5 讲；工程搭建篇（08-11）是铺垫性脚手架内容。
  • 独特之处：讲师有意识地做"批判性诚实"——明确说"做不到/没给你/个人体感"，并给出反面案例（双模型 review 抓出 12 个问题 4 个高危），这在"AI 提效课"里稀缺。
  • 形式/内容判断：这门课更多在"教思维方式"（可迁移的方法论），而非"堆砌事实知识"（Hify 具体代码是载体，不是目的）。这决定了它的保质期——工具会过时，方法不会。
