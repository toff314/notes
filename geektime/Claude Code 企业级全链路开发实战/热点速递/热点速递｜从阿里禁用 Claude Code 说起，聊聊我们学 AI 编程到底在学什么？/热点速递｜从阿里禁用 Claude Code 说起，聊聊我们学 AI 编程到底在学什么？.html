你好，我是 Robert。

今天技术圈被一条消息刷屏：据报道，阿里内部宣布禁用 Claude 全系产品，包括 Claude Code，禁令很快生效。消息一出，不少人开始慌：是不是以后用不了 Claude Code 了？我学的这套东西是不是白学了？生产力会不会大跌？

我想借这个事，聊几句冷静的话。不站队，也不煽动，就聊三个我认为比“能不能用”更重要的问题：大厂为什么会禁一个工具？我们学 AI 编程到底在学什么？真没了它，我们又能用什么？

先把我的结论放前面：工具是流动的，能力才是你自己的。任何一个工具的可用性，都不该成为你生产力的命脉，更不该成为你学习的拐杖。这件事，恰恰是个把这个道理想透的好机会。

大厂为什么禁一个工具？

一家大公司禁用某个工具，原因往往是多重的，不能简单归结成“这工具不行了”。

至少有以下几个层面：

  • 安全合规审查，大企业对研发链路里的外部工具，本来就有严格的准入和风险评估，一旦某个工具被列入高风险名单，禁用是常规动作。
  • 自有工具的竞争考量，阿里自己有 Qoder 这样的编程工具，从生态和数据的角度，收敛到自有工具是能理解的选择。
  • 这家工具的供应商本身，Anthropic 对中国市场的立场和一系列超出技术的因素。

这几层原因交织在一起，才有了这次的禁用。围绕这件事还有一些更具争议的说法，比如安全风险的具体性质，这些还需要更多证据，我这里不展开、也不轻易下判断。作为使用者，我更关心一个朴素的判断：

“被某家公司禁用”和“这工具好不好”，是两码事。Claude Code 依然是一个非常优秀的产品，这一点不会因为它被谁禁用而改变。反过来，一个工具再好，你也不该把自己的饭碗和成长，全押在它身上。

说句实在话，作为一个 Claude Code 的喜爱者，看到它被卷进这么多技术之外的对立、看到不少中国用户在没有预警的情况下被波及，我心里是不舒服的。但情绪归情绪，这不影响我们把注意力拉回到真正重要的事情上：我们的能力和我们的成长。

我们学 AI 编程，到底在学什么？

这才是我最想讲的一点。

如果你以为学 AI 编程，就是学会用 Claude Code 的某几个命令、某几个技巧，那这次禁用对你确实是打击，因为你学的东西是绑在工具上的，工具没了，你就空了。

但真正的 AI 编程，学的从来不是工具，是方法论和判断力。

  1. 用 SDD 把模糊需求变成清晰的规格，让 AI 知道做什么、做到什么程度；
  2. 用 Harness 给 AI 搭好上下文、工具、边界和验收，让它可靠地干活；
  3. 怎么拆解一个复杂项目、怎么编排 AI 协作、怎么审查产出、怎么在关键处人工兜底。

这些能力，是超越具体工具的。今天用 Claude Code，明天换 Codex，后天用国产工具，这套方法论一样成立。工具是手，方法论是脑子，脑子长在你身上，谁也拿不走。

这里还有一个反直觉，但我越想越认同的判断：太强的工具，反而不利于学习。

Claude Code 太顺手了，很多时候你一句话它就把活干得漂漂亮亮，爽是爽，但你容易学成一个黑盒，知其然不知其所以然。哪天它给你的结果不对，你都不知道问题出在哪、该怎么调。而当你用一个能力差一点、需要你反复调试、需要你去理解“它为什么这么做”的工具时，你反而被逼着把底层搞明白了。用差一点的模型和工具去学习，逼你调试、逼你理解，这对成长其实是利好。

没了 Claude Code，我们用什么？

回到最实际的问题：如果真用不了 Claude Code 了，生产力怎么办？我给几个务实的建议。

首选是 Codex。我的判断很直接：在编程这件事上，Codex 和 Claude Code 基本没有代差。如果你能切到 Codex，生产力基本不会有明显下降。用惯了 Claude Code 的人，迁移成本也不高，因为你带走的是工作方式，不是某个工具的肌肉记忆。

退一步是国内的工具和模型。比如 Qoder 这类。这里我得诚实：短期看，国内工具在复杂工程场景下的能力，和第一梯队还有可见的落差，这个不用讳言。但它们在快速追赶，而且足够用来完成大量日常工作。更重要的是，前面说的那个学习逻辑在这里成立，用需要你多操心的工具，反而练本事。

一个务实的提醒：中转站和 API 代理，近期尽量少碰。这段时间围绕这些服务的变数很大，跑路、停服的情况可能会增多，别为了图一时方便，把预付的钱搭进去，也别把关键工作流建在一个随时可能消失的中转服务上。

说到底，正确的姿态不是死守一个工具，而是手里常备两三套能互相替代的组合。任何单一工具被断，你都能平滑切换，活照样干得漂亮。这种切换自如的底气，本身就是能力的一部分。

写在最后

技术封锁这件事，历史反复上演过。短期看，它是阵痛，会带来不便和落差；但拉长看，它往往会逼出一个更强的本土生态。

把大量的使用、大量的数据、大量的场景留在国内，客观上会加速国内模型和工具的成长。这个过程对个体可能有短期的不适，但对整个生态，是成长的必经之路。我不觉得需要为此过度焦虑。

而对你我这样的个体来说，能做的其实很简单：别把心思花在焦虑“哪个工具还能不能用”上，把能力修炼到“给我任何一个还不错的工具，我都能干得漂亮”的程度。

这才是 AI 时代真正的安全感。它不来自某一个工具，它来自你自己。
