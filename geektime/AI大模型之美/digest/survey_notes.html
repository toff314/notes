课程通览：AI大模型之美

基本信息

  • 模块数：6
  • 总讲数：34（含开篇词、导读、结束语、结课测试、3 讲直播加餐）
  • 总时长：约 390 分钟（正课 27 讲 + 加餐 3 讲）
  • 讲师：徐文浩（曾创办 AI 聊天机器人公司，前拼多多工程师）
  • 课程定位：面向工程师/产品经理的「大模型应用开发」实操课，用 OpenAI API + 开源库（LangChain、llama-index、HuggingFace）从零搭应用，不涉及模型数学原理

Adler 两问（检视阅读阶段必答）

  • Q1: 这门课整体讲了什么？ 一门"零机器学习基础也能上手"的 LLM 应用开发课。核心主张：大模型把 AI 应用开发的门槛从"训练模型"降到"组合接口"，你只需要掌握 Completion、Embedding 两个核心接口 + 提示语设计 + 一套开源工具链，就能做出情感分析、聊天机器人、语义搜索、语音/图像应用。主线是"用接口而非训练"。
  • Q2: 作者想要解决什么问题？解决了多少？ 想解决"非 ML 背景的人如何进入 AI 应用开发"的问题。已解决：给出了从情感分析→聊天机器人→RAG（第二大脑）→Agent→多模态的完整可跑通路径，代码可直接复现。未解决：课程成稿于 2023 年初（GPT-3.5 时代），几乎所有 API 和开源库（LangChain/llama-index）的用法均已过时，需读者自行迁移；回避了模型原理、prompt 工程的系统性方法论，也回避了"何时不该用 LLM"的负面讨论。

整体印象

  • 课程主线："用接口而非训练"——把大模型能力拆成 Completion（生成）+ Embedding（检索）两个原语，再叠加提示语工程、RAG、Agent、多模态四条应用路径。
  • 最大亮点：第 10 讲"第二大脑"（即后来的 RAG）设计模式、第 13 讲"多步提示语/思维链"可迁移技巧——这两讲有独立于源码的、至今仍有效的洞见。
  • 明显水份：开篇词/结束语/导读的鸡汤、结课测试、直播加餐（视频无正文）、第 01 讲纯环境配置、以及大量已经过时的库 API 教程。
  • 独特之处：是国内极早期（2023 年初）系统讲 LLM 应用开发的中文课，历史价值大于现时工具价值；"第二大脑""多步提示语""Function Calling 描述准确性"等概念在当时的稀缺性高。
  • 形式/内容判断：这门课约 60% 是"教怎么用某个库/API"（会过时的事实知识），30% 是可迁移的方法论（RAG 模式、多步提示、Agent 编排、产品设计原则），10% 是鸡汤/填充。整体偏"事实+教程"而非"思维方式"，但少数几讲确有可迁移的思维贡献。
