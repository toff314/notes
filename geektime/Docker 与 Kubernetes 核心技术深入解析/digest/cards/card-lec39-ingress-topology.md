# 讲 39：案例分享：通过 Ingress 和 Service 完成一个网络拓扑（SNR 4.0 🥇）

**结论**：真实跨境多活项目的总集成——DNS 切流陷阱、99/1 权重保活、ECMP 四层扩展、DSR 回程优化、边缘节点+骨干网加速。
