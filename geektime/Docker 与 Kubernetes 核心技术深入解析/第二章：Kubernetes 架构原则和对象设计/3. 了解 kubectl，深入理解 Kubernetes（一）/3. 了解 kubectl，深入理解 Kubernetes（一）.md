- 用 Kubeadm 安装 Kubernetes 集群。
- [参考链接](https://github.com/cncamp/101/tree/master/k8s-install)
- 如果使用上述方法安装K8s遇到问题，也可参照以下步骤：
   1. [安装virtualbox虚拟机](https://github.com/cncamp/101/blob/master/k8s-install/k8s-by-kubeadm/1.vm-install.md)
   2. 使用虚拟机加载老师提供的自带K8s的ubuntu镜像文件
   - 镜像下载链接：https://pan.baidu.com/s/1bN70JcAIGuB_Fmm-TPfJsg 提取码：wf07 
   - [安装ubuntu镜像教程（点击查看）](https://github.com/cncamp/101/blob/master/k8s-install/k8s-by-kubeadm/install-ubuntu-on-virtualbox.pdf)
   - 或在PC端本页面下方👇附件下载教程pdf文件

   3. 登录ubuntu系统（账号/密码：cadmin/cadmin）；**注意输入密码时不会明文显示，直接输入cadmin后按回车即可，不要按回车再输入！**
   4. 登录进去后，先执行 `kubeadm reset` 命令
   5. 再按照[k8s-install.md教程]后半部分步骤执行以下代码即可(https://github.com/cncamp/101/blob/master/k8s-install/k8s-by-kubeadm/3.k8s-install.md)


```
kubeadm init \
 --image-repository registry.aliyuncs.com/google_containers \
 --kubernetes-version v1.22.2 \
 --pod-network-cidr=192.168.0.0/16 \
 --apiserver-advertise-address=192.168.34.2

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

$ kubectl taint nodes --all node-role.kubernetes.io/master-

$ kubectl create -f https://docs.projectcalico.org/manifests/tigera-operator.yaml
$ kubectl create -f https://docs.projectcalico.org/manifests/custom-resources.yaml
```
