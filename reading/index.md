## 新增一本书

1. 指定书稿路径（`.pdf` / `.epub` / `.md` / `.txt` 均可），用 `write-read-notes` 按章产出；
2. 在 `reading/<book-slug>/` 下为每章建 `<NN-chapter>/`，放入六件套 + `labs/`；书目级 `README.md` 做索引；
3. `raw/` 书稿与划线留在本地，不入库；
4. 跑 `bash scripts/build-html.sh`（自动扫描，无需登记）；
5. 更新本页（每章一行）与根 `README.md` / 根 `index.html`。
