lab-04　投射约束的代价：穷举小图量化非投射损失

目标

量化「强制投射」带来的结构性损失：在 n≤6 的随机图上穷举所有合法树，比较「全树最优」与「投射最优」的分数差。这就是投射解析器（Eisner 等 O(n³) 算法）相对于 MST 的上限代价——不是准确率差，是表达力差。

原文依据

  • §20.1.2：投射性定义——若弧 (i,j) 与 (k,l) 满足 i<k<j<l 或 k<i<l<j，则它们交叉；

含交叉弧的句子没有投射分析。

  • §20.3.2：Eisner 算法是 O(n³) 的投射解析器，通过三角 DP 保证无交叉。
  • 书中例句：JetBlue canceled our flight this morning which was already late

（含关系从句 flight→late，与 canceled→morning 交叉）。

输入

  • 90 张随机图：n ∈ {4,5,6} 各 30 张，分数 ∈ [-9,9]，random.seed(20261101)。
  • 书中 10 词非投射句（用于交叉弧检测验证）。

关键设计

穷举所有树（all_trees 生成器）：

for choice in itertools.product(range(0, n+1), repeat=n):
    heads = dict(zip(words, choice))
    # 过滤：无自环、恰好一个根孩子、无环

n=6 时穷举空间为 7⁶ = 117,649，Python 生成器 + 剪枝（自环/多根/环检测）在可接受时间内完成。

投射判定（projective 函数）：对所有弧对检查是否满足a < c < b < d 或 c < a < d < b 的交叉条件。

怎么跑

cd lab-04 && python3 lab04_projectivity_cost.py

纯标准库，约 3 秒。

结论

  1. 过半数图的最优树非投射：90 张中 47 张（52.2%）的全局最优树含交叉弧。

这不是小概率事件，而是随机分数下的常态。

  1. 损失随句长线性增长：n=4 平均损失 0.60，n=5 为 1.90，n=6 达 3.33。

句子越长，非投射结构越常见，强制投射的代价越大。

  1. 书中例句确实非投射：canceled→morning 与 flight→late 交叉，

验证了 §20.1.2 的论断——任何 arc-standard/eager 解析器都不可能产出这棵树。

  1. 投射解析器的结构性上限：Eisner 等算法的 O(n³) 复杂度换来的是「无交叉」约束，

本实验量化了这个约束的代价——在随机分数下平均损失约 2 分（满分约 30 分）。

反思

我原本以为「自然语言的投射性假设基本成立」，所以非投射损失应该很小。但随机分数下 52.2% 的最优树非投射，说明投射性是一个很强的结构约束，不是「偶尔有个例外」。当然，真实语言模型的分数不是随机的——关系从句、并列结构等确实会产生非投射，但频率远低于 52%。

这个实验让我理解为什么 UD 语料里既有投射解析器（Eisner）也有非投射解析器（MST、CLE）：前者快但有表达力上限，后者慢但完备。选择哪种算法，取决于语料中非投射结构的实际占比。
