第 20 章 实验：依存句法分析

五个 lab 全部可离线运行（python3 标准库；lab-03 额外依赖 networkx），每个脚本把结果写到自己的 out/，下面的「实测」栏都是从真实运行输出里抄的。

复现

cd labs
for d in lab-0*; do (cd $d && python3 *.py); done

阅读顺序建议

  1. 先做 lab-01：把「栈 + 缓冲区 + 三个动作」跑成一张转移表，比读文字快。
  2. 再做 lab-02：同一棵树两条路径，亲眼看到 eager 允许「先挂再长」。
  3. lab-03 / lab-04 是「图方法」的两面：前者求全局最优但允许交叉，后者量化禁止交叉要付多少钱。
  4. lab-05 最后做：指标很小，但 UAS 与 LAS 的差值能直接暴露「头对标签错」。

统一的坑

  • 书中 LEFTARC 的约定是「栈顶 S1 当中心词、第二个词 S2 当依存词，弹 S2」，

与 Nivre 原始论文的「弹栈顶」写法相反；照抄论文伪代码会得到镜像结果（lab-01 备注）。

  • 依赖 networkx 的 minimum_spanning_arborescence 不保证 ROOT 只有一个孩子，

必须枚举根孩子再跑（lab-03 踩过）。

  • 五句以内的穷举可行，六词以上就爆炸；lab-03/04 的随机图都限制在 n≤6。
