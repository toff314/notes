# lab-03　k-means 粒度效应 toy 实验

对应行动：`actions.md` 第 3 条。对应书中 §16.4.2–§16.4.3（HuBERT 的 k-means 两阶段聚类）。

## 怎么跑

```bash
cd labs/lab-03-kmeans-units
python3 kmeans_units.py
```

依赖：标准库 + numpy。

## 输入

合成 3 类「元音-like」2 维高斯（模拟 39 维倒谱被 PCA 到 2 维的 toy 版），每类 100 个样本，共 300 个。真实类数 k*=3。

## 产物

| 文件 | 内容 |
|---|---|
| `out/k_sweep.csv` | k=2..12 的纯度均值/标准差/极差、ARI 均值、惯性 |
| `out/k_sweep_summary.json` | 同上的 JSON 版，含实验参数 |

## 结论

1. **k=3 时纯度与 ARI 同时最高**：purity=0.9967、ARI=0.9956，几乎完美恢复真实类。k=2 时 purity 掉到 0.6667（两类合并），说明 k 小于真实类数时纯度上限被锁死。
2. **k>3 后纯度仍高但 ARI 持续下降**：k=12 时 purity 仍有 0.9887，但 ARI 已降到 0.7554。这说明「过细粒度的簇」不会显著降低纯度（每簇仍由单类主导），但会打乱簇之间的对应关系，ARI 对此更敏感。
3. **初始化稳定性**：5 组随机初始化下，k=3 时 purity 标准差为 0（全局最优），k≥4 时标准差 >0 且极差扩大，说明 k 越大越容易陷入局部最优。
4. **与 HuBERT 的对应**：HuBERT 第一阶段用 MFCC 聚 100 类、第二阶段用第 6 层输出聚 500 类，正是利用「过细粒度仍保纯度」的性质——标签变多不会毁掉监督信号，反而提供了更细的目标。

## 反思

纯度这个指标对「多聚类」过于宽容：只要每簇里有一个类占多数，就算分得好。这解释了为什么 HuBERT 能用 500 类甚至 1000 类做标签——纯度不会崩。但 ARI 告诉我们，簇与真实类别的对应关系在 k 过大时已经被打乱。如果下游任务依赖「簇编号即音素」的假设，k 的选择就不是越大越好，而是一个需要在验证集上调的超参。
