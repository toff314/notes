# lab-01　词级最小编辑距离 / WER 复算

对应行动：`actions.md` 第 1 条。对应书中 §16.6（词错误率）。

## 怎么跑

```bash
cd labs/lab-01-wer-tools
python3 wer.py
```

依赖：纯标准库（csv / os），无需 numpy。

## 输入

5 组手工构造的英文句对（A–E），覆盖单替换、缩合、填充词、书中量级、对齐歧义五种情形。句对写死在脚本 `CASES` 里，可复现且不依赖外部下载。

## 产物

| 文件 | 内容 |
|---|---|
| `out/wer.csv` | 5 组句对的 S/I/D 计数、WER_raw%、WER_norm%、最优路径条数 |
| `out/alignment.txt` | 逐句对齐明细（C/S/D/I 标记）+ 书中例子复算 |

## 关键输出（真实运行）

```
书中例子: 76.92%  （与书中 76.9% 差 0.02 个百分点）
['A-单替换', 6, 1, 0, 0, 16.67, 6, 16.67, 1, 1]
['B-缩合+多错', 8, 1, 0, 3, 50.0, 8, 50.0, 1, 1]
['C-带填充词', 10, 0, 0, 4, 40.0, 8, 25.0, 1, 1]
['D-书中量级', 13, 8, 3, 1, 92.31, 12, 91.67, 1, 1]
['E-对齐歧义', 4, 4, 0, 0, 100.0, 4, 100.0, 8, 8]
```

## 结论

1. **书中数值可复算**：13 词参考、6S+3I+1D → 76.92%，与书中 76.9% 差 0.02pp（§16.6）。若分母误用假设词数 15 → 66.67%，差 10pp，可见分母口径会改变结论。
2. **规范化影响显著**：C 句对带填充词（um/uh），原始参考 10 词 WER=40.00%，去填充词后 8 词 WER=25.00%，差 15pp。这说明「去填充词」这一步能显著美化数字。
3. **对齐歧义真实存在**：E 句对（a b c d vs c d a b）最优路径有 8 条，S/I/D 拆分为 4/0/0，但换一种回溯偏好可能拆成 0/4/0 或 0/0/4 等，总数相同、分布不同。
4. **路径数可检测歧义**：脚本统计最优路径条数，>1 即提示该句对存在对齐歧义，两个工具对同一对句子可能给出不同拆分而总数相同。

## 反思

我原以为 WER 是一个「算出来就完了」的指标；实际跑出来才发现，光是「参考文本要不要去填充词」就能让数字差 15pp。书里那句「错误率可能超过 100%」只是冰山一角——分母口径、规范化脚本、回溯规则，每一处都会改变结论。以后复现别人的 WER，第一件事是对齐这三样，否则数字没法横向比。
