lab-02　CTC 折叠函数与前向 DP

对应行动：actions.md 第 2 条。对应书中 §16.5–§16.5.2（CTC 的折叠、推断与训练）。

怎么跑

cd labs/lab-02-ctc-collapse
python3 ctc.py

依赖：标准库 + numpy。

输入

  • 书中 §16.5.1 的三帧 toy 分布（自定数值，仅用于演示）：
  t=1: a=0.50 b=0.40 ε=0.10
  t=2: a=0.10 b=0.50 ε=0.40
  t=3: a=0.10 b=0.30 ε=0.60
  • 20000 组 Dirichlet([1,1,1]) 随机分布，用于搜索 argmax 不一致实例。

产物

文件内容
out/alignments.csv9 个输出串的暴力枚举概率、前向 DP 概率、绝对差
out/summary.json对齐总数、输出数、最大差、argmax 结果、随机搜索统计、dinner/diner 对照

关键输出（真实运行）

对齐 27 条 → 不同输出 9 个
暴力枚举 vs 前向 DP 最大绝对差 = 5.55e-17
逐帧 argmax: abε → Y='ab'；求和后最大 Y='b'
随机 20000 组：argmax 不一致 5607 次（28.0%）
dinner: {'有空白符': {'frames': ['d','i','n','ε','n','ε','e','r'], 'collapse': 'dinner'},
         '无空白符': {'frames': ['d','i','n','n','e','r'], 'collapse': 'diner'}}

结论

  1. 暴力枚举与前向 DP 一致：27 条对齐折叠出 9 个输出，暴力枚举与前向 DP 的最大绝对差为 5.55e-17（浮点精度内一致）。这验证了前向 DP 的实现正确性（§16.5.2）。
  2. argmax 不是最优：toy 分布下，逐帧 argmax 路径 abε 折叠为 "ab"，但概率最大的输出是 "b"（0.333 vs 0.303）。随机 20000 组中，28.03% 的分布存在 argmax 不一致，最大差距实例中 "b" 概率 0.645 而 argmax 输出 "bb" 仅 0.156（§16.5.1）。
  3. 空白符一符两用：dinner 有空白符时折叠为 "dinner"，无空白符时 nn 塌成 n 变成 "diner"。空白符既是静音占位，又是重复分隔（§16.5）。
  4. 多对一折叠必然导致求和：同一输出串对应多条路径，概率只能定义为路径集合的总质量；前向 DP 用动态规划合并等价路径，复杂度从指数降到 T×S（§16.5.2）。

反思

我原以为「逐帧取最大」只是近似不够准，没想到在 3 帧 toy 分布上就能直接看到反例；随机搜索 28% 的不一致率更说明这不是边角案例，而是常态。空白符那个细节也是——看公式时觉得「去重复」很直观，真写到代码里才发现 nn 不插 ε 就会塌成一个 n。CTC 的坑不在公式本身，而在这些「一符两用」的实现细节上。
