|---|---|---|---|
| 后训练 | 预训练之后的指令微调、偏好对齐与可验证奖励强化学习等阶段 | §8.0 | 把"会续写"改造成"会按要求办事"的三段工序 |
| 基础模型 | 仅完成预训练、尚未经历任何后训练步骤的模型 | §8.0 | 还没上过任何"岗位培训"的原始模型 |
| 指令微调 | 在指令—回答语料上继续训练，既学任务也提升遵循指令的一般能力 | §8.1 | 拿任务说明书配标准答案，教模型看懂"要你干什么" |
| SFT（监督微调） | 把带正确答案或回答的指令数据当作训练语料继续训练 | §8.1 | 名字里的"监督"说的是标签现成，不是换了损失 |
| 微调 | 取预训练好的模型，在新数据上用交叉熵再跑若干轮 | §8.1 | 在已有能力上做定向补课，可全参也可只动一部分 |
| 元学习 | 指令微调带来的、跨任务的一般遵循指令能力 | §8.1 | 不只学会某几道题，而是学会"怎么读题" |
| PEFT | 冻结多数参数、只更新一小部分的微调方式 | §8.2 | 只给模型换几个零件，而不是整车重造 |
| LoRA | 冻结原权重矩阵、只训练一对低秩矩阵的参数高效方法 | §8.2 | 用两个瘦长矩阵的乘积当"补丁"，贴在原权重旁 |
| 低秩分解 | 用 k×r 与 r×d 两个小矩阵近似 k×d 的更新量 | §8.2 | 把一次大改动拆成"先压到 r 维、再展开" |
| 偏好对齐 | 用人类或机器对输出优劣的判断来优化模型行为 | §8.3 | 不教它怎么写，只告诉它"这两份里哪份更好" |
| 基于偏好的学习 | 利用偏好判断提升已微调模型在诚实、有用、无害等特质上的表现 | §8.3 | 把"比较"当作训练信号的一类方法总称 |
| 偏好对 | 同一提示下，被偏好输出优于另一输出的记法 (oi≻oj\|x) | §8.3.1 | 一次二选一的结果，连同它的前提提示一起存档 |
| Bradley–Terry 模型 | 把两项偏好概率写成二者得分差的 logistic 函数 | §8.3.2 | 假设每个候选有个隐藏分，谁分高谁赢，分差决定胜率 |
| 奖励 | 模型为给定提示和输出打出的标量分数 | §8.3.3 | 一个可比较的"好感度"，只在同一提示内排序有意义 |
| 奖励模型 | 从 LLM 初始化、把语言建模头换成线性层、用偏好数据训练的打分器 | §8.3.3 | 把成千上万次人工比较压缩成一个能实时打分的函数 |
| 策略 | RL 框架中，预训练 LLM 所体现的概率语言模型 | §8.4 | 给定前缀，决定下一个词概率分布的那套参数 |
| 参考策略 | 加 KL 约束时用作起点的原始模型 πref | §8.4 | 用来量"走多远"的那把固定尺子 |
| KL 散度 | 衡量两个概率分布之间距离的量 | §8.4 | 不是几何距离，而是"用错分布要多付多少信息代价" |
| β | 调节 KL 惩罚项影响的超参数，DPO 中常取 0.01–0.1 | §8.4、§8.4.2 | 同时当奖励缩放和 sigmoid 温度，不只是"保守程度" |
| 配分函数 | 给定提示下对所有可能输出求和的归一化项 Z(x) | §8.4.2 | 让"指数化的奖励"变成一个合法概率分布的除项 |
| DPO | 用策略与参考策略的对数比直接优化偏好数据的办法 | §8.4.2 | 不训打分器，直接把"哪份更好"变成二分类损失 |
| 隐式奖励 | DPO 中由 β log(πθ/πref) 表示的奖励，无需单独模型 | §8.4.2 | 奖励没有消失，只是藏进了两个策略的比值里 |
| RLVR | 在答案可明确验证的任务（编程、数学）上做强化学习 | §8.0、§8.5 | 用程序判对错，而不是靠人或模型打分 |
| best-of-N | 从 N 个采样回答中用奖励模型挑一个更受偏好的 | §8.3.3 | 广撒网再挑最好的，代价是 N 倍采样与打分 |

> 易混提示：**奖励**是分数本身，**奖励模型**是产生分数的函数；**显式奖励模型**（RLHF/PPO 路线）与**隐式奖励**（DPO 路线）是同一目标的两个参数化。**β** 在 RLHF 目标里是 KL 权重，在 DPO 损失里还额外充当温度，不能只按"越大越保守"理解。
