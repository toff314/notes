# lab-02：DPO 的 β 到底在控制什么

**对应**：§8.4（KL 约束目标，式 8.7）、§8.4.2（DPO 推导与 β 的取值，式 8.8、8.10–8.13）。
**行动**：`actions.md` 第 2 条。

## 目的

把书上「β 是控制 KL 惩罚项的超参数，通常取 0.01–0.1」这句话拆成三个可分别检验的问题：

1. **固定一对回答的对数概率比（margin）时，β 如何改变 DPO 损失与有效梯度？** 验证 β 不只是"越大越保守"，它还充当 sigmoid 的温度。
2. **在式 8.7 的 KL 约束目标下，β 如何决定闭式最优策略离参考策略多远？** 观察最优点的 DPO 损失是否随 β 变化。
3. **只对单个可分偏好对做 DPO 梯度下降，β 是"KL 预算"还是"优化步长"？** 比较不同 β 的 KL 轨迹终点与到达速度。

## 输入

- 无外部数据，全部为解析计算 + 小型数值优化。
- **A 部分**：固定 `log πθ(ow)=−1.2`、`log πθ(ol)=−1.5`、`log πref(ow)=−2.0`、`log πref(ol)=−1.9`，得到对数比 margin `m=0.4`；在 `β∈[10⁻³,10]` 上扫描 400 个点。
- **B 部分**：两个候选，参考 logits `[0.5, 0.0]`，真实奖励 `[1.0, 0.0]`；按式 8.7 的闭式解 `π* ∝ πref · exp(r/β)` 计算 `β∈{0.01,0.03,0.1,0.3,1,3,10}` 的最优策略。
- **C 部分**：四个候选，参考 logits `[1.0,0.5,0.0,−0.5]`，单个偏好对（候选 0 胜候选 1）；用数值梯度 + Adam（学习率 0.05）分别跑 600 与 6000 步。

## 运行

cd labs/lab-02

关键数值（本次运行）：

| 量 | β=0.01 | β=0.1 | 备注 |
|---|---:|---:|---|
| 固定 margin 的 DPO 损失 | 0.6911 | 0.6733 | m=0.4 |
| 隐式奖励差 β·m | 0.004 | 0.040 | 随 β 线性放大 |
| 有效梯度 β·σ(−βm) | 0.0050 | 0.0490 | 峰值在 β≈3.227，值 0.6961 |

- **B 部分**：β 从 0.01 增到 10，闭式最优的 `p(winner)` 从 1.000 降到 0.646，KL 从 0.4741 降到 0.00115；但隐式奖励差恒为 1.0，**最优点的 DPO 损失恒为 0.3133**。
- **C 部分**：600 步时 β=0.01/0.1/1 的 KL 分别为 0.78734/0.78734/0.69068；6000 步时前两者仍为 0.7873387/0.7873387，β=1 为 0.77327。β=0.01 与 0.1 到达同一端点，β=1 明显更慢。

## 结论

1. **β 同时缩放隐式奖励和 sigmoid 温度。** 固定 margin 时，隐式奖励差是 β·m，但有效梯度是 β·σ(−βm)：β 太小信号弱，β 太大 sigmoid 饱和、梯度也趋零，峰值在 β≈1.28/m（本实验 m=0.4，故约 3.2）。
2. **在 KL 约束目标下，β 越大，闭式最优策略离参考策略越近。** 这符合"β 是 KL 权重"的直觉：β=0.01 时几乎完全转向高奖励答案（KL=0.474），β=10 时几乎不动（KL=0.00115）。
3. **但在单个可分偏好对上，β 不决定最终端点，只决定到达速度。** β=0.01 与 0.1 充分训练后 KL 都是 0.78734（策略把胜者概率推到 1），β=1 因为 sigmoid 饱和而收敛更慢。把 β 当"KL 硬预算"会误判：它没有给 KL 设上限，只是改变了优化路径。
4. **最优点的 DPO 损失对 β 不敏感。** B 部分里隐式奖励差恒为 1，DPO 损失恒为 0.3133，β 的影响只体现在 KL 与策略分布上；因此不能只用 DPO loss 选 β。

## 局限

- 全部是**玩具分布**：2 个或 4 个候选的 softmax，不是真实词表上的自回归策略；没有采样、没有序列级信用分配。
- C 部分只有一个偏好对，数据完全可分；真实偏好数据多对、有噪声、可能不可分，端点行为未必相同。
- B 部分用固定真实奖励 `[1,0]`，没有模拟奖励模型误差；它检验的是式 8.7 的几何性质，不是训练动力学。
- 数值梯度 + Adam 的步长与 6000 步上限会影响"是否收敛"的判断；β=1 的 KL 0.773 是未完全收敛，不是另一个稳定端点。
- 没有扫描学习率、batch 大小与 β 的交互。

## 反思

我原来把 β 理解成"KL 预算"：β 越大，模型越不许动。B 部分确实支持这个直觉，但 C 部分给出了反例——在单个可分对上，β=0.01 和 0.1 最终都走到同一个 KL=0.787 的端点，只是前者慢得多。也就是说，β 在 DPO 损失里不是约束项前的系数，而是把奖励差整体缩放后再送进 sigmoid；它同时改变了"目标有多陡"和"信号有多强"。

另一个反直觉点是 B 部分：β 从 0.01 变到 10，最优策略的分布差了很多，但 DPO 损失一直是 0.3133。因为闭式解的隐式奖励差被真实奖励差固定住了。这提醒我，比较不同 β 的实验不能只看 loss 曲线，必须同时看 KL 和策略分布。
