# lab-04：连贯判别（原始顺序 vs 打乱顺序）

> **对应行动**：actions.md 第 4 条 —— 实现连贯判别
> **运行**：`python3 lab04_coherence_discrimination.py`

## 目的

实现 §25.3.3 的句子顺序判别任务（Barzilay and Lapata, 2005）：用实体网格转移概率作为连贯性度量，区分文档的原始顺序与随机打乱顺序。

## 输入

3 个文档，每个 6 句：
- d1：微软反垄断案（§25.3.2 图 25.9 风格）
- d2：John 买钢琴（§25.3.1 例句扩展）
- d3：新图书馆开馆

## 关键输出（真实运行）

```
训练文档 d1 的实体网格转移统计：
  共 50 个转移
  -→-: 32 次 (P=0.6400)
  S→-: 5 次 (P=0.1000)
  -→S: 4 次 (P=0.0800)
  O→-: 2 次 (P=0.0400)
  -→X: 2 次 (P=0.0400)

文档     原始得分         打乱均分         判别正确
----------------------------------------
d1     -0.4320      -0.4014      ✓
d2     -0.3897      -0.3739      ✓
d3     -0.4103      -0.4295      ✗

判别准确率: 2/3 = 66.7%
结论: 原始顺序 更连贯 (得分越低越连贯)
```

## 产物

- `out/coherence_discrimination.json`：每个文档的原始/打乱得分、判别结果、准确率

## 结论

- 2/3 的文档判别正确（66.7%），原始顺序在得分上更低（更连贯）
- d1 判别正确：原始顺序 -0.4320 < 打乱 -0.4014
- d2 判别正确：原始顺序 -0.3897 < 打乱 -0.3739
- d3 判别失败：原始顺序 -0.4103 > 打乱 -0.4295，可能因为 d3 的实体分布较均匀，打乱后仍保持较高连贯性

## 反思

1. **简化实现**：实体抽取用正则匹配，语法角色判断用位置启发式，与真实实体网格模型（Barzilay & Lapata, 2008）相比精度有限
2. **转移概率**：训练文档 d1 的转移统计中 `-→-`（缺失→缺失）占 64%，这是稀疏网格的普遍现象
3. **判别难度**：d3 判别失败说明，当文档本身话题连贯性较强、实体分布均匀时，顺序打乱对连贯性的影响较小
4. **改进方向**：可用更多训练文档统计转移概率、引入更长转移（n-gram）、或用神经模型（LCD）替代手工特征
