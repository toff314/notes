# 《Speech and Language Processing》（第 3 版）· 第 25 章 篇章连贯 · 读书笔记

> **本章一句话**：真实的篇章不是随机句子的堆砌，而是由连贯关系、基于实体的显著性、话题连贯和全局结构共同组织起来的；计算模型分别用 RST/PDTB 树库、中心理论/实体网格、词汇衔接和自监督判别来捕捉这些性质。

## 引言　篇章连贯的定义与三种局部连贯　⭐

**本节问题**：什么是篇章连贯？为什么随机句子拼凑不成篇章？局部连贯有哪三种方式？

### 摘录区（原文照抄 + 节号）
- 「我们把这样一个连贯的、结构化的句子群称为篇章，并用“连贯”一词来指称使真实篇章」（§引言）
- 「局部连贯的三种方式」（§引言）
- 「首先，真实篇章中的句子或小句与邻近句子之间的关联是」（§引言）
- 「篇章能够局部连贯的第二种方式，在于它“关于”」（§引言）
- 「最后，篇章还可以通过在话题上连贯而做到局部连贯：邻近的」（§引言）

### 思考区（必须自己的话；【我】开头）
- 【我】这一节先划了三条互不重合的轴：句间关系（REASON 等）、实体显著性（篇章围绕谁展开）、话题一致性（谈同一件事）。后面所有模型都只是把其中一条或几条轴数值化，没有哪个模型同时覆盖三条。
- 【我】作者用「喜欢菠菜 vs 必须去开会」对比，说明读者会主动寻找句间联系——这种「连贯寻求」是人类理解的本能。算法版本就是把这种联系的频繁程度记下来，变成可学习的特征。
- 【我】以前我把「连贯」和「通顺」当同义词用，直到看见 John 买钢琴的例子。检索系统里这是两类完全不同的需求：找同义改写要话题连贯，找「配套实体」要实体连贯，混用会给出看似合理却跑偏的结果。
- 【我】词汇衔接（lexical cohesion）是表层属性，但它是话题连贯的可靠信号。这提醒我：不要小看「重复使用相同或语义相关的词语」这个简单特征，它在无监督模型里非常有效。

## 第 25.1.1 节　修辞结构理论（RST）　⭐

**本节问题**：RST 怎么定义连贯关系？核心与卫星有什么区别？EDU 是什么？

### 摘录区（原文照抄 + 节号）
- 「在 RST 中，关系被定义在」（§25.1.1）
- 「核心（nucleus）是这样一个单元：它」（§25.1.1）
- 「Reason: 核心（nucleus）是一个由有生命的施事者执行的动作，卫星（satellite）是核心（nucleus）的原因。」（§25.1.1）
- 「Elaboration: 卫星（satellite）对核心（nucleus）所呈现的情景给出附加的信息或细节。」（§25.1.1）
- 「Evidence: 卫星（satellite）对核心（nucleus）所呈现的情景给出附加的信息或细节。给出这些信息的目的在于说服读者接受核心（nucleus）所呈现的信息。」（§25.1.1）
- 「List: 在这个多核心关系中，给出一系列核心（nucleus），其间没有对比或显式的比较」（§25.1.1）
- 「树库（Carlson et al., 2001）是目前规模最大的篇章语料库。它由 385 篇选自宾州树库的英语文档组成，每篇都带有完整的 RST 分析，使用多达 78 种不同的关系，归为 16 个类别。」（§25.1.1）

### 思考区（必须自己的话；【我】开头）
- 【我】RST 的「核心-卫星」不对称设计很巧妙：摘要时保留核心、删除卫星就行。这解释了为什么 RST 对自动文摘特别有用——它天然给了「重要性」一个结构化的定义。
- 【我】EDU（基本篇章单元）对应篇章树的叶结点，大致相当于小句。确定 EDU 边界是篇章分析的第一步，也是错误传播的根源——边界错了，后面的关系全错。
- 【我】RST 树库有 78 种关系、16 个类别，这个粒度差异提醒我们：标注方案的设计直接影响模型学习的难度。太细的关系区分连人都标不准，模型更难学。
- 【我】我以前以为「修辞结构」是写作课的概念，现在明白它是计算模型：把篇章组织成一棵树，每个内部结点是一个关系，叶子是 EDU。这和句法树惊人地同构，所以移进-归约分析器能直接用过来。

## 第 25.1.2 节　宾州篇章树库（PDTB）　⭐

**本节问题**：PDTB 与 RST 有什么区别？为什么 PDTB 不建完整的树？显式与隐式关系怎么区分？

### 摘录区（原文照抄 + 节号）
- 「宾州篇章树库（PDTB）」（§25.1.2）
- 「PDTB 的标注以词汇为基础。它不要求标注者直接标注文本跨度之间的连贯关系，而是给他们」（§25.1.2）
- 「并非所有连贯关系都由显式篇章连接词标示，」（§25.1.2）
- 「最终数据集包含约 18,000 个显式关系和 16,000 个隐式」（§25.1.2）
- 「与 RST 篇章树库不同，后者把这些成对的连贯」（§25.1.2）
- 「由于汉语中显式篇章连接词的比例低于英语（所有篇章关系中只有 22% 由显式连接词标示，」（§25.1.2）

### 思考区（必须自己的话；【我】开头）
- 【我】PDTB 的「从连接词出发」标注策略很聪明：连接词是显式的线索，标注者先找连接词，再标注它连接的两个论元。这降低了标注难度，但也导致没有连接词的地方（隐式关系）更难标。
- 【我】PDTB 不建完整树，这是与 RST 的本质区别。它只关心「这两个片段之间是什么关系」，不关心整篇怎么组织。这使得 PDTB 更适合「浅层」应用（如关系分类），但不适合需要全局结构的任务（如摘要）。
- 【我】汉语显式连接词比例只有 22%（英语 47%），这对中文篇章分析是个巨大挑战。意味着中文模型必须更依赖隐式关系推理，而不能像英语那样「抓连接词就完事」。
- 【我】我曾在一个中文摘要项目里直接套用英语的「连接词特征」，效果很差。现在明白根本原因是汉语的隐式关系比例太高，连接词覆盖不了多少。

## 第 25.2.1 节　基本篇章单元（EDU）切分　🔴

**本节问题**：EDU 切分为什么重要？现代系统怎么做 EDU 切分？

### 摘录区（原文照抄 + 节号）
- 「RST 分析通常分两个阶段进行。第一个阶段是基本篇章单元（EDU）切分，抽取每个基本篇章单元（EDU）的起点和终点。」（§25.2.1）
- 「由于基本篇章单元（EDU）大致对应于小句，早期的基本篇章单元（EDU）切分模型」（§25.2.1）
- 「现代系统通常使用神经序列模型，并以 RST 篇章树库等数据集中的金标基本篇章单元（EDU）切分作为监督信号。」（§25.2.1）
- 「这里输入的句子先经过一个编码器，再经过一个线性层和一个 softmax，产生由 0 和 1 组成的序列，其中 1 表示一个基本篇章单元（EDU）的起点。」（§25.2.1）

### 思考区（必须自己的话；【我】开头）
- 【我】EDU 切分是篇章分析的「分词」步骤，边界错误会级联传播到关系标注和树构建。这和中文分词错误影响句法分析是同一个道理。
- 【我】从「句法分析器 + 后处理」到「端到端神经序列模型」的演进，和 NLP 其他任务（NER、句法分析）的演进完全一致：先靠规则，再靠特征工程，最后靠表示学习。
- 【我】把 EDU 切分看成序列标注（每个词元预测 0/1）是很自然的思路，但难点在于 EDU 边界的定义本身有模糊性——小句的边界不像词边界那样清楚。

## 第 25.2.2 节　RST 分析：移进-归约　⭐

**本节问题**：移进-归约分析器怎么构建 RST 树？神经编码器怎么表示 EDU 和子树？

### 摘录区（原文照抄 + 节号）
- 「为篇章构建 RST 连贯结构的工具长期以来都基于句法分析算法，例如移进-归约分析（Marcu, 1999）。」（§25.2.2）
- 「分析器的状态由一个栈和一个队列组成，它通过在状态上执行一系列动作来生成这一结构。」（§25.2.2）
- 「移进（shift）：把队列中的第一个基本篇章单元（EDU）压入栈，创建一个单节点子树。」（§25.2.2）
- 「归约（reduce(l,d)）：合并栈顶的两个子树，其中 l 是连贯关系标签，d 是核性方向，d ∈{NN,NS,SN}。」（§25.2.2）
- 「Yu 等人（2018）的系统使用编码器-解码器架构，其中编码器」（§25.2.2）
- 「训练首先把每棵标注的 RST 分析树映射为一个 oracle 动作序列，然后使用标准的交叉熵损失（带 l2 正则化）训练系统采取这些动作。」（§25.2.2）

### 思考区（必须自己的话；【我】开头）
- 【我】移进-归约是句法分析的经典算法，直接搬到 RST 分析上，说明篇章结构和句法结构在形式上有同构性。这种「借用」是 NLP 工程里的常见做法。
- 【我】分层 biLSTM 的设计很合理：第一层表示 EDU 内部的词，第二层表示 EDU 序列。这和 Transformer 的「词 → 句 → 篇」层级表示思想一致，只是用 biLSTM 实现。
- 【我】oracle 动作序列的构造是关键：把标注树转换成移进/归约动作序列，模型就只需要学习「当前状态该做什么动作」，变成一个分类问题。
- 【我】存疑：抽取文本里式 25.18–25.23 的 biLSTM 公式与交叉熵损失排版错乱（求和符号与分式被拆行），我只能按上下文重建。lab-02 用中心理论转移走查对了一遍，若重建有误，数值会立刻暴露。

## 第 25.3.1 节　中心理论　⭐

**本节问题**：中心理论怎么定义显著性？Cb、Cf、Cp 分别是什么？四种转移状态怎么判定？

### 摘录区（原文照抄 + 节号）
- 「中心理论（Grosz et al., 1995）」（§25.3.1）
- 「作为篇章显著性的模型，中心理论提出：在篇章的任一给定位置上，篇章模型中的某个实体是显著的，即正被“中心化”。」（§25.3.1）
- 「作为篇章连贯的模型，中心理论提出：相邻句子 CONTINUE（延续）保持同一显著实体的篇章，比在多个实体之间来回 SHIFT（转换）的篇章更连贯」（§25.3.1）
- 「Un 的后向中心记作 Cb(Un)，表示当前的显著实体，也就是在 Un 被解读之后篇章所聚焦的那个实体。」（§25.3.1）
- 「Un 的前向中心记作 Cf (Un)，是一个」（§25.3.1）
- 「我们把排序最高的前向中心称为 Cp（即“preferred center”，首选中心）。Cp 是对接下来将谈论哪个实体的一种预测。」（§25.3.1）

### 思考区（必须自己的话；【我】开头）
- 【我】中心理论的核心直觉是「篇章关于某个实体」：持续谈 John 的段落比 John/店铺来回切换的段落更连贯。这和 RST 的「关系」视角完全不同——RST 问「这两句什么关系」，中心理论问「这两句在谈谁」。
- 【我】Cb/Cf/Cp 的区分很精妙：Cb 是「现在正在谈的」，Cf 是「可能接下来谈的」，Cp 是「最可能接下来谈的」。这种「预测-验证」机制让中心理论既有描述力又有可计算性。
- 【我】规则 1（代词必须实现 Cb）和规则 2（转移状态有序）是中心理论的可操作部分。规则 1 把代词消解和显著性联系起来，规则 2 给连贯性一个可度量的排序。
- 【我】我曾在一个对话系统里用「最近提到的实体」做共指回退，效果很差。现在明白应该用的是「显著实体」而不是「最近实体」——显著性由语法角色和代词化标记决定，不只是时间顺序。

## 第 25.3.2 节　实体网格模型　🔴

**本节问题**：实体网格怎么构建？转移概率怎么计算？为什么自监督训练有效？

### 摘录区（原文照抄 + 节号）
- 「Barzilay 与 Lapata (2008) 的实体网格模型是另一种」（§25.3.2）
- 「该模型以一个实体网格为基础，实体网格是一个二维数组，表示实体提及在各句之间的分布。行表示句子，列表示篇章实体」（§25.3.2）
- 「每个单元格表示某个实体在某句中可能出现的位置，其取值表示该实体是否出现以及它的语法角色。语法角色包括主语（S）、宾语（O）、两者皆非（X）或缺失（–）」（§25.3.2）
- 「在实体网格模型中，连贯通过局部实体转移的模式来衡量。」（§25.3.2）
- 「Barzilay 与 Lapata (2005) 提出了一个简化性的创新：连贯模型可以通过自监督来训练，即训练它区分篇章中句子自然的原始顺序与经过改动的顺序（如随机顺序）。」（§25.3.2）

### 思考区（必须自己的话；【我】开头）
- 【我】实体网格是中心理论的「自底向上」版本：不预设什么理论，直接从数据里学「什么样的实体转移模式更连贯」。这和统计学派 vs 规则学派的经典对立是同构的。
- 【我】把语法角色（S/O/X/–）编码进网格，让模型能区分「John 是主语」和「John 是宾语」——这种细粒度信息对连贯性判断很重要，因为主语位置的实体更可能是篇章中心。
- 【我】自监督训练（区分原始顺序 vs 随机顺序）是实体网格模型的关键创新：不需要人工标注连贯性分数，用「原始文本比打乱文本更连贯」这个弱假设就能训练。这和 word2vec 的「上下文预测」一样，是「任务即脚手架」思想的早期应用。
- 【我】转移概率 [S –] = 0.08 这种特征，本质上是在编码「实体被提及后是否持续被提及」的模式。高频转移（如 [S S]）表示实体持续处于主语位置，这通常意味着篇章围绕该实体展开。

## 第 25.3.3 节　评估：人工评分与自监督　🔵

**本节问题**：连贯模型怎么评估？自监督的三种实现方式各有什么特点？

### 摘录区（原文照抄 + 节号）
- 「首先，我们可以让人类对文档的连贯进行评分，并训练一个分类器」（§25.3.3）
- 「另一种做法是，由于获取人工标签的成本非常高，而且我们可能」（§25.3.3）
- 「在句子顺序判别任务（Barzilay and Lapata, 2005）中，我们把一个文档与其句子的随机排列进行比较。」（§25.3.3）
- 「在句子插入任务（Chen et al., 2007）中，我们取一个文档，去掉」（§25.3.3）
- 「最后，在句子顺序重构任务（Lapata, 2003）中，我们取一个」（§25.3.3）
- 「插入比判别更难，因为我们比较的是仅相差一个句子的文档。」（§25.3.3）

### 思考区（必须自己的话；【我】开头）
- 【我】三种自监督任务难度递增：判别（哪个更连贯）< 插入（这个句子该插哪）< 重构（把整篇排回去）。难度越高，对模型的要求越高，但也越接近真实应用（如自动排版）。
- 【我】人工评分评估最适合有明确下游任务的场景（如作文评分），因为「连贯」的定义本身随任务而变。自监督评估则适合「还不知道用来干什么」的基础研究。
- 【我】我曾在一个文本质量项目里纠结「连贯性标注指南」怎么写，最后发现不同标注者对「连贯」的理解差异巨大。现在明白：如果没有明确任务，不如直接用自监督，避免标注噪声。

## 第 25.4 节　面向局部连贯的表征学习模型　⭐

**本节问题**：LCD 模型怎么计算句子对连贯得分？和早期 LSA 方法有什么继承关系？

### 摘录区（原文照抄 + 节号）
- 「第三种局部连贯是话题连贯或语义场连贯。篇章之所以连贯，是因为它们谈论相同的话题和子话题，并在此过程中调用相同的语义场。」（§25.4）
- 「Foltz et al. (1998) 的 LSA 连贯方法，是」（§25.4）
- 「现代神经表征学习连贯模型始于 Li et al.」（§25.4）
- 「与早期无监督模型不同，LCD 是一个自监督模型，其训练目标是区分训练文档中（被假定为连贯的）连续句子对 (si,si+1) 与（构造出的）不连贯句子对 (si,s′)。」（§25.4）
- 「给定输入的句子对 s 和 t，模型计算句子嵌入 s 和 t（使用任意句子嵌入算法），然后拼接该对的四个特征：(1) 两个向量的拼接；(2) 它们的差 s−t；(3) 它们差的绝对值 |s −t|；(4) 它们的逐元素乘积 s ⊙t。」（§25.4）
- 「Xu et al. (2019)」（§25.4）

### 思考区（必须自己的话；【我】开头）
- 【我】LCD 的四个特征（拼接、差、绝对差、逐元素乘积）是自然语言推理（NLI）模型的标准配置，直接搬到连贯判别上。这说明「句子对分类」的任务家族共享同一套特征工程。
- 【我】从 LSA 余弦 → LCD 判别式学习，演进主线是「从手工定义相似度到学习什么算连贯」。但 LCD 仍然保留了「相邻句子对」这个基本单元，没有试图建模更长程的依赖。
- 【我】RNN 语言模型的「条件对数似然 − 边缘对数似然」基线很聪明：它用「上下文让句子更可预测的程度」来度量连贯，不需要额外训练。这和 GPT 的困惑度评估思想一致。
- 【我】Iter et al. (2020) 用对比式句子目标训练 Transformer，在 ±2 句子上提升篇章任务——这说明预训练目标里加「篇章感知」的对比损失，对下游有帮助。这和现在流行的「句子级对比学习」（如 SimCSE）是同一思路。

- 本周内复现 LCD 的四个特征提取，用 sklearn 训练一个逻辑回归判别器（验收：在 100 个文档对上准确率 ≥ 70%）。

## 第 25.5.1 节　论证结构　🔴

**本节问题**：论证挖掘与 RST/PDTB 有什么区别？主张与前提怎么标注？论证关系有哪些类型？

### 摘录区（原文照抄 + 节号）
- 「第一类全局篇章结构是论证的结构。对」（§25.5.1）
- 「对论证的研究可追溯到 Aristotle，他在其《修辞学》（Rhetorics）中描述了」（§25.5.1）
- 「关于论证的篇章结构研究大多聚焦于理性诉求（logos），」（§25.5.1）
- 「这类语料往往包含对论证成分的标注，如主张（claims）（论证中」（§25.5.1）
- 「因此这个例子有三个论证关系：SUPPORT(2,1)、SUPPORT(3,1)」（§25.5.1）

### 思考区（必须自己的话；【我】开头）
- 【我】论证挖掘与 RST/PDTB 的核心区别：RST 关心「文本怎么组织」，论证挖掘关心「作者怎么说服」。同一个文本可以有很好的 RST 结构但很差的论证（前提不支持主张）。
- 【我】Aristotle 的三分法（pathos/ethos/logos）在现代计算工作中几乎全部聚焦 logos，因为 pathos 和 ethos 太难形式化。但最近的工作（如 Cialdini 的说服原则）开始把 pathos/ethos 也纳入计算模型。
- 【我】SUPPORT 和 ATTACK 的二分比 RST 的 78 种关系粗糙得多，但可能更实用——在辩论分析、事实核查等应用中，「这个观点支持还是攻击那个观点」是最核心的问题。
- 【我】论证的「全局性」体现在：一篇说服性文章往往只有一个主要主张，前提散布于全文。这和 RST 的局部连贯关系形成对比，也解释了为什么论证挖掘需要不同的模型架构。

- 本周内找一篇中文社论，手工标注其主张、前提和 SUPPORT/ATTACK 关系（验收：至少标注 5 个成分和 3 个关系）。

## 第 25.5.2 节　科学篇章的结构　🔵

**本节问题**：科学论文有什么特定的全局结构？论证分区（AZ）怎么标注？

### 摘录区（原文照抄 + 节号）
- 「科学论文具有非常特定的全局结构：在论文进程的某个位置，作者必须指明一个科学目标、提出用于求解的某种方法、为该解决方案提供证据，并与先前工作进行比较。」（§25.5.2）
- 「为这些修辞目标建模的一种流行标注方案是 Teufel 等（1999）与 Teufel 等（2009）的论证分区模型」（§25.5.2）
- 「观点：每篇科学论文都试图就一项被加入该领域知识库的新知识提出知识主张（Myers，1992）。」（§25.5.2）
- 「科学论文中的句子可被赋予 15 个标签之一」（§25.5.2）

### 思考区（必须自己的话；【我】开头）
- 【我】科学论文的结构是最「八股」的全局连贯：目标→方法→结果→比较。这种高度规约化的结构让 AZ 标注相对容易，也让自动分类器的效果相对较好。
- 【我】15 个 AZ 标签比 PDTB 的 16 个类型细得多，但科学论文的句子类型确实更受限——这是「领域特定结构」的优势：标签集可以更精细，因为语料更同质。
- 【我】我曾在一个学术搜索项目里想「自动提取论文的贡献点」，当时不知道 AZ 这个标注方案。现在明白：把句子标成 OWN_METHOD / OWN_RESULTS / GAP 等，就是在做「贡献点提取」的结构化版本。

### 全章 takeaway（5 条）
1. 篇章连贯有三种局部机制：连贯关系（RST/PDTB）、实体显著性（中心理论/实体网格）、话题一致性（词汇衔接/LCD），分别对应「句间关系」「篇章关于谁」「谈同一件事」。
2. RST 建完整树、PDTB 只标片段对；RST 适合需要全局结构的任务（摘要），PDTB 适合关系分类等浅层任务。
3. 中心理论用 Cb/Cf/Cp 追踪显著实体，实体网格用转移概率自底向上学习连贯模式；自监督（原始 vs 打乱顺序）是训练连贯模型的通用方法。
4. LCD 等神经模型把「什么算连贯」从手工定义（LSA 余弦）变成学习问题，但保留了「相邻句子对」的基本单元。
5. 全局连贯包括论证结构（主张-前提-SUPPORT/ATTACK）和科学篇章结构（AZ 15 标签），分别对应「说服」和「知识主张」两种交际目的。
