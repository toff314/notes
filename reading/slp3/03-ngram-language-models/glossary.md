# 第 3 章 N-gram 语言模型 · 术语表

| 术语 | 书上定义（缩引） | 位置 | 我的话 |
|---|---|---|---|
| 语言模型（LM） | 为每一个可能的下一个词赋予一个概率，或给出其概率分布 | §3.1 | 给下一个符号打分并归一化的函数，可给整句打分 |
| n-gram | n 个词的序列；也指用前 n−1 个词预测下一个词的概率模型 | §3.1 | 同时是数据切片和建模假设，读时要分清 |
| bigram | 两个词的序列；用前一个词预测下一个词 | §3.1.1 | 窗口为 1 的马尔可夫模型 |
| trigram | 以前面两个词为条件预测下一个词 | §3.1.3 | 窗口为 2；数据够多时的常用阶数 |
| 马尔可夫假设 | 一个词的概率仅依赖于前 n−1 个词（bigram 时即前一个词） | §3.1.1 | 丢掉远处历史，换取可计数的上下文 |
| 最大似然估计（MLE） | 用计数归一化估参，使训练集在该模型下的似然最大 | §3.1.2 | 在已见数据上最不意外的参数 |
| 相对频率 | 某序列的观测频率除以前缀的观测频率 | §3.1.2 | MLE 的算术形式，就是计数相除 |
| 对数概率 | 在对数空间存储与计算概率，避免连乘下溢 | §3.1.3 | 乘法变加法，按 token 累加打分 |
| 外在评估 | 把模型嵌入应用，依任务效果改善来评估 | §3.2 | 验收：到底有没有用 |
| 内在评估 | 独立于应用、直接衡量模型质量 | §3.2 | 筛选：像不像这门语言 |
| 训练集 | 用来学习模型参数的数据 | §3.2 | 计数来源 |
| 开发集（devset） | 最终测试前反复调参用的留出集，与测试集同分布 | §3.2 | 给人迭代用，防止人手污染测试集 |
| 测试集 | 与训练集不重叠、用于最终评估的留出数据 | §3.2 | 只跑一次，跑多了就漏信息 |
| 数据污染 | 测试集内容混入训练数据，导致评测虚高 | §3.2 | 分数好看但不可复现的常见原因 |
| 困惑度（PPL） | 测试集概率倒数的逐词几何平均 | §3.3 | 平均在每个位置犹豫多少个等概率候选 |
| 分支因子 | 可以跟在任意一个词之后的下一个词的可能数目 | §3.3.1 | 结构上的走法数，未按概率加权 |
| 平滑 / 折扣 | 从高频事件挪一点概率质量给未见事件 | §3.6 | 给零计数留活路，代价是压低估已见项 |
| 拉普拉斯平滑 | 归一化前给所有 n-gram 计数加一 | §3.6.1 | 加一平滑；分子加 1 分母必须加 V |
| 加 k 平滑 | 把加一换成加分数 k | §3.6.2 | 少挪一点质量，k 在开发集上选 |
| 插值 | 把不同阶 n-gram 概率加权混合 | §3.6.3 | 每次都混，权重和为 1 |
| 回退 | 高阶计数为零时退回低阶近似 | §3.6.4 | 缺了才降级，会有"台阶" |
| 愚蠢回退 | 不折扣、不归一化，按固定权重回退 | §3.6.4 | 分数不是概率，常用 λ=0.4 |
| 留出语料 | 从训练数据中留出、用于设定插值权重的数据 | §3.6.3 | 专门用来学 λ，不参与计数 |
| 熵 | 衡量不确定性的量，也是最优编码的比特下界 | §3.7 | 平均需要多少比特描述一个决策 |
| 熵率 | 长序列每词的平均熵 | §3.7 | 把整段熵除以长度 |
| 交叉熵 | 用模型分布编码真实分布时的平均编码长度 | §3.7 | 永远不小于真实熵，越低越接近 |
| 采样 | 按模型给出的分布随机抽取下一个词 | §3.4 | 让模型"说话"，暴露全部偏好 |
| infini-gram | 用后缀数组在推理时计算任意长度 n-gram 概率 | §3.1.3 | 不预计算所有阶，查询时现算 |
