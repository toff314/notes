# lab-03：把书中的数字重新算一遍

## 目的

对应 `actions.md` 第 3 条：不依赖书上的结论，用代码把本章可手算的例子全部重算并断言，作为"例题重做 + 错题归因"的证据。

## 覆盖的检查（20 条）

1. I am Sam 语料的 6 个 bigram 概率：P(I|&lt;s&gt;)=2/3、P(Sam|&lt;s&gt;)=1/3、P(am|I)=2/3、P(&lt;/s&gt;|Sam)=1/2、P(Sam|am)=1/2、P(do|I)=1/3。
2. `0.25×0.33×0.0011×0.5×0.68 = 0.000031` 的算术。
3. 颜色模型 A（均匀）困惑度 = 3；B（0.8/0.1/0.1）在 red×4 + blue 上 = 1.89。
4. 反转测试集（blue×4 + red）：A 仍为 3，B 升至 6.60。
5. 八匹马分布熵 = 2 bit；均匀八选一 = 3 bit；2 bit 换算为 1.386 nat。
6. 练习 3.5：不带 `</s>` 时，2 词句与 3 词句的概率和都等于 1.0。
7. 练习 3.12：91 个 0 + 各一个 1–9 的训练集，测试 `0 0 0 0 0 3 0 0 0 0` 的 unigram 困惑度 ≈ 1.725。
8. 练习 3.4：修改语料上加一平滑 P(Sam|am) = 3/14 ≈ 0.214（V=11）。
9. 练习 3.7：λ=0.5/0.5 插值 P(Sam|am) ≈ 0.413。

## 结论

- 书中的关键数字全部可复现；最容易被忽略的是加一平滑的 V：练习 3.4 若不把 `<s>`、`</s>` 计入词表，V 会算成 9，结果随之改变。
- 颜色模型的反转测试（B 从 1.89 升到 6.60）证明低困惑度只对特定测试分布成立。
- 练习 3.5 的"两种长度概率和都为 1"用代码枚举后非常直观：缺 `</s>` 时模型把质量分给了每个长度层，而不是全局。

## 反思

我原本以为这些例子只是算术，真正动手才发现错误几乎都出在"计数口径"：`<s>` 算不算、句末算不算、V 怎么数。以后做任何 n-gram 题，先画一张含边界符号的计数表，再代公式。
