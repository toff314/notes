第 13 章 机器翻译 · 术语表

收录本章出现的术语与工程动词。每条给「中 / 英 / 一句话定义 / 出处」。定义尽量用我自己的话，不照抄原文。

排序：按首次出现的节号。带 ⚠️ 的是我自己容易混淆、需要对照区分的条目。

术语英文一句话定义出处
语序类型学word-order typology按主谓宾的常规排列给语言分类（SVO/SOV/VSO…），并考察它与前置词/后置词的联动。§13.1.1
SVO / SOV / VSOsubject-verb-object order基本从句里「主语—动词—宾语」三者的相对次序；汉语普通话与英语同为 SVO。§13.1.1
前置词 / 后置词preposition / postposition位于名词短语之前的虚词（of、in）与位于之后的虚词（日语 の、德语 部分介词短语场景）。§13.1.1
结构重排structural reordering生成译文时改变成分的先后次序，语序差异要求的大规模变换。§13.1.1
词汇空缺lexical gap ⚠️一种语言里没有现成的词或短语能表达另一语言某词的确切含义，只能靠解释性说法。§13.1.2
一对多 / 多对多映射one-to-many / many-to-many源词对应多个目标词，或两边都按不同方式切分概念空间。§13.1.2
卫星成分satellite承担运动方向等信息的非动词成分：小品词、介词短语、副词短语。§13.1.2
动词框架语言verb-framed language把运动方向编码进动词本身的语言（如西班牙语 entrar）。§13.1.2
卫星框架语言satellite-framed language把运动方式留在动词、方向交给卫星成分的语言（如英语 crawl out）。§13.1.2
指称密度referential density ⚠️语篇中显式指称成分出现的多寡；省略多则密度低。是连续维度，不是二元标签。§13.1.3
代词脱落语言pronoun-drop language允许主语代词在语境充分时缺席的语言（汉语、日语、西班牙语程度不同）。§13.1.3
零形式zero anaphor源文里没写、但语义上存在且译文中必须补出的指称位置。§13.1.3
子词 / 词片subword / wordpiece介于字符与整词之间的切分单位，用来在固定词表下覆盖未登录词。§13.2.1
共享词表shared vocabulary源语言与目标语言索引同一张子词表，使专名可原样复制。§13.2.1
BPEbyte-pair encoding从字符起步，反复合并最高频相邻对来扩表；单调增长、不可回退。§13.2.1
一元分词unigram tokenization以概率模型给切分打分，用 EM 重估并允许删掉低价值词元。§13.2.1
SentencePiece—把空格也当普通字符处理的子词工具，可直接在原始文本上训练；实现 BPE 与 unigram 两种算法。§13.2.1
平行语料库 / 双语文本parallel corpus / bitext互为译文的双语句子集合，是机器翻译的监督信号来源。§13.2.2
句对齐sentence alignment把两篇互为译文的文档切成一一对应的句对；分「打分」与「搜索」两步。§13.2.2
动态规划对齐DP alignment在句对代价矩阵上找总代价最小的单调路径，允许 1-1、1-2、2-1 配对。§13.2.2
编码器-解码器encoder-decoder先把源文压成表示、再以该表示为条件逐词生成译文的架构。§13.3
交叉注意力cross-attention ⚠️Q 来自解码器上一层、K/V 来自编码器输出的注意力；与自注意力同形，只换来源。§13.3
掩码masking禁止注意力看到右侧/未来的位置；编码器不掩码，解码器掩码。§13.3
教师强制teacher forcing训练时每步用标准答案作为下一步输入，而非模型自己的预测。§13.3
贪心解码greedy decoding每步取局部概率最高的词元，不回溯。§13.4
束搜索beam search每步保留 k 条最优前缀，用 k 倍算力换取「晚一步下注」。§13.4
束宽beam width (k)每步保留的候选前缀数；机器翻译常用 5–10。§13.4
长度归一化length normalization ⚠️用长度惩罚把不同长度候选的分数拉到可比区间，如 GNMT 的 `(5+y)^α/6^α`。§13.4
最小贝叶斯风险minimum Bayes risk (MBR)选与候选集合平均最相似的译文，即期望损失最小者，而非概率最大者。§13.4.1
回译back-translation用反向系统把目标单语译回源语，造出合成平行句来补训练数据。§13.5.1
多语言翻译multilingual MT单一模型服务多个语言对，用 ls/lt 特殊词元指明方向。§13.5.2
充分性 / 流畅性adequacy / fluency人工评估的两个维度：意思传没传到、目标语顺不顺。§13.6
chrFcharacter n-gram F-score在去空格的字符 n 元上算 P/R 的调和平均，β=2 时召回权重加倍。§13.6.2
BLEUbilingual evaluation understudy词级 n 元精确率的几何平均乘以简短惩罚；对分词敏感，短句易塌零。§13.6.2
简短惩罚brevity penaltyBLEU 中惩罚过短候选的因子，防止「少说少错」刷高分。§13.6.2
BERTScore—用上下文嵌入做贪心一对一匹配，算语义层面的 P/R/F。§13.6.3
分配伤害 / 表征伤害allocational / representational harm前者是资源与机会的实际分配不公，后者是刻板印象的强化。§13.7
Vauquois 三角Vauquois triangle以「分析深度」为纵轴、以「转换知识量」反向为横轴的翻译方法谱系图。§历史注记
中间语言interlingua把源文先译成语言无关的表示，再由它生成目标文；三角顶端。§历史注记
噪声信道模型noisy channel把翻译看成「目标句经信道被噪声污染成源句」，用贝叶斯反推目标。§历史注记
ALPAC 报告ALPAC report1966 年否定机器翻译可行性的评估报告，导致美国资助骤减。§历史注记

⚠️ 易混对照（单独记）

容易混的两项区别一句话
交叉注意力 vs 自注意力只差 K/V 从哪来：自注意力三者同源，交叉注意力 K/V 来自编码器。
BPE vs unigramBPE 只合并、词表单调长；unigram 有概率、能删除、可回退。
chrF vs BLEUchrF 在字符层算 P/R（对形态变化稳健），BLEU 在词层只算精确率（对分词敏感）。
束搜索 vs MBR前者换搜索宽度、目标仍是概率；后者换目标函数、用相似度当效用。
指称密度 vs 代词脱落前者是连续维度，后者是这条维度某一端的语言类型标签。
词汇空缺 vs 一对多一对多是「有多个候选可选」，空缺是「根本没有可选」。
