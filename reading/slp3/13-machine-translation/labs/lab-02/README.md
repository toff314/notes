对应 `../../actions.md` 第 2 条；对应书中 §13.6.2（chrF）与 §13.6.1（BLEU）。
目的：把书里那两个数（`.86` / `.62`）亲手算出来，并解释为什么同一句话换个口径会变成 `.66` / `.42`。

## 结论

1. **书中的 .86 / .62 复现成功**：手算口径（只取 1–2 元、去空格、β=2）得 `.8644` / `.6198`，四舍五入正好是书上那两个数。差异只有 0.004 / 0.002，来自我对「18 字符」边界的取法。
2. **但按 chrF 原始定义（n=1..6 取平均）同一句话只有 `.6552` / `.4162`**。也就是说书上给的是 n≤2 的简化版，而不是标准 chrF。这个差别（0.21 / 0.20）远大于两个译文之间的排序信息，**报分数不注明 n 等于没报**。
3. `max_n` 扫描单调下降，且两条曲线不交叉：`.9551→.6552` 与 `.6627→.4162`。n 越大，能被匹配上的长片段越少，分母不变而分子掉得快，所以分数必降。HYP2 掉得更快（−0.25 vs −0.30 相对），因为它本来就更短、更缺长片段。
4. **BLEU 在短句上塌成 0**：HYP2 的 4 元命中数为 0，几何平均直接归零，平滑也救不回来（`0.0000` / `0.0000`）。HYP1 有 `.8091`（平滑）/ `.7598`（不平滑），平滑把 0 计数替换成小值，抬高了 0.05。
5. **语料级才是有意义的粒度**：`corpus5 BLEU-4 = .5528`、平均 chrF2 = `.7254`，都落在「看起来还行」的区间——而这 5 个句段里有一句 chrF2 只有 0.4062（`i see a house` 对 `the cat sat on the mat`，几乎是无关句）。句子级指标的方差被平均掉了。

## 反思

- 这次最重要的收获不是复现了 .86，而是**发现 .86 与 .66 是同一个算法的两个档位**。我原先默认「书上给的数字就是标准值」，实际教材为了手算方便做了简化，而简化改变的量级足以掩盖真实差距。以后引用任何指标数字，先确认 n、β、去不去空格、平滑不平滑。
- HYP1 的 chrP（.6906）居然低于 HYP2（.6774），而 chrR 差距巨大（.6469 vs .3799）。这说明 `past witness` 的字符几乎全都能在参考里找到（它是参考的子序列重排），只是覆盖率低——**chrF 对「词序颠倒」几乎不惩罚**，正好印证书上那句「chrF 非常局部：一个被移动位置的大型短语可能几乎完全不改变 chrF 分数」。这条如果只读原文很容易滑过去，算一遍才真信。
- 语料级 BLEU 用的是 4 元，5 句里有一句完全不相关，仍然给出 .5528。这让我对「BLEU 高 = 译得好」更警惕了：语料级平均会奖励那些「大部分句子简单且重复」的系统。
- 待改进：应该加一个「同一句多参考译文」的 chrF 版本（multi-ref），因为 §13.1.3 讲零形式时已经指出单一参考会惩罚正确的另一种译法。这属于下一轮的事，本轮不重跑。
