# lab-03　贪心解码 vs 束搜索，以及长度归一化的翻转率

对应 `../../actions.md` 第 3 条；对应 §13.4（图 13.7 的搜索树）与 §13.4.1（长度归一化 / MBR 的动机）。
目的：用书上给出的三个锚点数重建一棵最小玩具树，验证「局部最优不等于全局最优」，再量化长度归一化到底会翻掉多少原本正确的选择。

## 输入

**一棵写死的玩具搜索树**，只用书中 §13.4 图 13.7 明确给出的三个锚点：

- 第一步 `P(yes) = 0.5`（贪心会被它吸走）
- `ok` 的先验 `P(ok) = 0.4`
- 完整串 `P(ok ok EOS) = 0.4 × 0.7 × 1.0 = 0.28`

其余分支（`yes` 之后的 `yes/ok/EOS/the` 分布）书中抽取文本没有给出，按「让贪心走错的最小设定」补齐：`P(yes|yes)=0.4`、`P(ok|yes)=0.3`、`P(EOS|yes)=0.2`、`P(the|yes)=0.1`。

**翻转率实验的输入**是合成的：每次试验随机抽 6 个候选假设的对数概率（`TRIALS=2000`、`N=6`），比较三种打分——原始对数概率、GNMT 归一化 `(5+|y|)^α/6^α`（`ALPHA=1.0`）、平均对数概率 `÷|y|`——选出的最优假设是否发生改变。

## 关键输出（真实运行）

`beam_trace.csv`：

| step | alive | logp |
|---|---|---|
| 1 | yes | −0.6931 |
| 1 | ok | −0.9163 |
| 2 | ok ok | −1.2730 |
| 2 | yes yes | −1.6094 |

贪心：`yes yes EOS`，`prob = 0.2`，轨迹 `P(yes)=0.5 → P(yes|yes)=0.4 → P(EOS)=1.0`。

束搜索 k=2 的候选池（按 logp 排序）：

| 假设 | logP |
|---|---|
| **ok ok EOS** | **−1.2730** |
| yes yes EOS | −1.6094 |
| yes EOS | −2.3026 |
| ␣EOS（空串） | −2.9957 |
| ok EOS | −3.2189 |

长度归一化（`trials=2000`、`n_hyp=6`、`alpha=1.0`）：

| 归一化方式 | 改变最优选择的比例 |
|---|---|
| GNMT `(5+\|y\|)^α/6^α` | **0.1135** |
| 平均对数概率 `÷\|y\|` | **0.2280** |

top-2 归一化分数：

| 假设 | len | logP | avg | GNMT |
|---|---|---|---|---|
| ok ok EOS | 2 | −1.2730 | −0.6365 | −1.0911 |
| yes yes EOS | 2 | −1.6094 | −0.8047 | −1.3795 |

## 结论

1. **贪心确实会错，而且错得很便宜**：第一步只差 0.1（0.5 vs 0.4），但第二步就把 0.28 的全局最优让给了 0.20 的次优。束宽 k=2 就够了——它只需要在第一、二步各留一个「次优」分支，就能接住 `ok ok EOS`。
2. **束搜索在第二步就已经把最优解放在池子里**（`ok ok` 的 logp −1.2730 排名第一），说明这棵树上「晚一步下注」的成本极低。书上说的束宽 5–10 是给真实长句留的余量，玩具树上 k=2 即饱和。
3. **长度归一化会改变 11.35% 的选择**（GNMT）。这个数字比我想的高：十次里有一次以上，最终输出的候选会变。它证明 §13.4 那句「我们常常采用长度归一化」不是可选装饰，而是会实打实改变结果的步骤。
4. **简单除以长度比 GNMT 激进一倍**（0.2280 vs 0.1135）。`(5+|y|)^α/6^α` 在长度小时分母接近 1，惩罚温和；`÷|y|` 对短句惩罚过猛。这就是工业界用前者的原因——它是一个「软惩罚」。
5. 注意 top-2 两行 **len 都是 2，归一化不改变它们的相对顺序**（GNMT 后 −1.0911 vs −1.3795，与原始 −1.2730 vs −1.6094 同序）。翻转只发生在长短候选混排时——这正是 13.4 节的警告，也是本实验里 6 个候选随机长度才需要 2000 次试验的原因。

## 反思

- **我原来以为束搜索「更好」是理所当然**，跑完才发现它的收益完全来自「次优分支在下一步能翻盘」这一前提。如果树的概率分布是单调衰减的（越往后越没有反转），束搜索就是纯浪费算力。这给出一个可操作的判断：值不值得加束宽，看第二步的候选排序与第一步是否一致。
- 玩具树是我按书中三个锚点补齐的，**「让贪心走错的最小设定」意味着结论方向被我预设了**。这不是造假，但必须承认：它验证的是「图 13.7 那棵树长这样就能骗过贪心」，而不是「真实模型里贪心经常错」。真实模型上的错误率得用真模型测，本轮做不了。
- 翻转率实验用的是**随机对数概率**，不是真实解码分布，所以 0.1135 只能说明「归一化方式的影响量级在 10% 量级」，不能当任何真实系统的指标引用。这条写进结论时我特意标了「合成输入」，避免以后自己或别人误用。
- 还缺一块：书中 §13.4.1 的 MBR 没有实现。MBR 换的是目标函数（最小期望风险），与本 lab 的「换打分方式」是两种不同的修法。下一轮可以加一个 5 候选的 MBR 玩具实验，用字符 2 元重叠当效用——这条已写进 `spinoffs.md` 与 `self-test.md`，不在本轮范围。
