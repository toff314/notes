# lab-01：从零实现二分类逻辑回归

对应 `actions.md` 第 1、2 条（§4.2 / §4.5 / §4.6 / §4.15）。

## 运行

```bash
cd labs/lab-01
python3 logreg_binary.py
```

只依赖标准库 + numpy + matplotlib（Agg 后端，无显示环境也能跑）。

## 数据

22 条手工构造的迷你影评，2 个特征：

- `x1`：正向词典词计数
- `x2`：负向词典词计数
- `y`：1 正面 / 0 负面

其中两条故意歧义（`great acting, awful story` 标正、`dull start, lovely ending` 标负），
避免数据完全可分导致权重无限增大。

## 做了什么

1. 实现数值稳定的 sigmoid（按 z 的符号分支，避免 `exp` 溢出）；
2. 实现批平均交叉熵与解析梯度 `(X^T (ŷ-y))/m`；
3. 用批量梯度下降训练 600 轮，学习率 0.5；
4. 复现 §4.6.3 单步更新：`x=[3,2], y=1, w=b=0, η=0.1`；
5. 用中心差分校验解析梯度。

## 关键输出（真实运行）

```
documents: 22  features: 2
learned weights: w=[1.5131, -1.8113]  b=0.1646
final train loss: 0.2550  train accuracy: 0.909
```

`gradient_step.json` 中：

- 解析梯度 `w=[-1.5, -1.0]`、`b=-0.5`；
- 数值梯度 `w=[-1.4999999999876223, -1.0000000000287557]`、`b=-0.5000000000143778`；
- 一步更新后 `w=[0.15, 0.1]`、`b=0.05`，与书中 §4.6.3 完全一致；
- 相对误差量级 `1e-11`，远小于 1e-6 的验收线。

## 结论

- 正词权重 1.51、负词权重 −1.81，符号符合“正向词支持正类、负向词反对正类”的直觉；
- 负向证据的绝对值更大，和书中 §4.3.1“负面词重要性约为正面词两倍”的例子方向一致；
- 损失从 `ln 2 ≈ 0.693` 单调降到 0.255，没有震荡，符合 §4.6 的凸性判断；
- 训练准确率 0.909 而非 1.0，说明两条歧义样本确实没有被硬拟合，模型保留了误差。

## 反思

我原先以为“梯度下降就是调参”，跑完才注意到：单步更新里的 `(ŷ-y)` 在初始点恒为 −0.5，
所以第一步的方向完全由输入特征决定。也正因为如此，正样本会让两个权重同时变正——
书里那句“看到更多负例后 w2 才会变负”，在完整训练后的 `w2=-1.81` 上得到了验证。
另一个意外是数值稳定：教材公式 `1/(1+exp(-z))` 直接照抄会在 z 很负时溢出，
工程实现必须自己补分支。
