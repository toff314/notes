对应 `actions.md` 第 3、4 条（§4.7 / §4.8 / §4.9 / §4.11 / §4.14）。

## 运行

```bash
cd labs/lab-02
python3 logreg_multiclass.py
```

只依赖标准库 + numpy + matplotlib（Agg 后端）。随机种子固定，结果可复现。

## 数据

三类影评（positive / negative / neutral），每类 60 条，按泊松分布生成 3 个特征：

- `x1`：正向词计数（正类均值 4.2，负类 1.0，中性 2.2）
- `x2`：负向词计数（负类均值 4.2，正类 1.0，中性 2.2）
- `x3`：感叹号数（正/负类略高，中性接近 0）

每类取 40 条训练、20 条测试，共 120 / 60。

## 做了什么

1. 实现 softmax、多分类交叉熵、解析梯度 `(P-Y)^T X / n + αW`；
2. 训练 800 轮全批量梯度下降，输出混淆矩阵与逐类 P/R/F1；
3. 扫描学习率 `[0.01, 0.05, 0.1, 0.3, 0.6, 1.0]`；
4. 扫描 L2 强度 `[0, 0.001, 0.01, 0.1, 1.0]`，同时记录权重范数；
5. 按 §4.11.1 实现配对自助检验（b=2000），比较 L2 模型与无正则模型。

## 结论

- 正类几乎不被误判（20/20），错误集中在“中性 ↔ 正/负”之间，说明中性类的特征向量夹在两类原型中间，符合 §4.7.2 的“原型相似度”解释；
- 学习率 1.0 时测试损失反弹到 0.7777、准确率跌到 0.683，是 §4.6.2“步子过大越过最小值”的直接证据；
- L2 强度从 0 增到 1.0，‖W‖₂ 从 2.39 降到 0.44，说明正则确实在压权重；但最佳测试准确率出现在 α=0.1，而非 α=0 或 α=1；
- 宏平均 F1（0.760）低于微平均（0.767），差异来自错误在各类别间分布不均，验证了 §4.9.1 的讨论；
- 准确率高 6.7 个点，p 值却为 0.085，按书中 0.01 阈值不能拒绝原假设——这就是 lab 最重要的反直觉结果。

## 反思

我原以为“准确率高出 6 个点”肯定显著，跑完自助检验才发现：在 60 条测试样本上，
几个样本的翻转就足以吞掉这点差距。书里的 2δ 判据比常见的“δ 是否大于 0”保守得多，
我第一次直观看到“效应量”和“显著性”是两件事。

另一个收获是评估口径：宏平均与微平均只差 0.007，但如果三类样本量改成 10:10:100，
差距会被放大——这正是书中“微平均被高频类别主导”的意思。
