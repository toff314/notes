# Lab 04 · BM25 的 k1 / b 网格扫描

- **对应行动**：actions.md 第 4 条（⇄ book-notes §11.1.2）
- **脚本**：`bm25_sweep.py`
- **运行**：`cd labs/lab-04 && python3 bm25_sweep.py`
- **产物**：`out/grid_mrr.csv`、`out/grid_r1.csv`、`out/grid_longwin.csv`、`out/summary.json`、`out/mrr_heatmap.png`、`out/b_curve.png`

## 设置

- 16 篇短文档，每篇配 1 条查询，金标准是该短文档。
- 其中 8 篇另有一个「正文重复三遍 + 填充句」的长版本（同一主题的干扰项，词频更高、篇幅约 3–6 倍）。
- 若长版本排到第一，记为「长度归一化失效」。
- 网格：k1 ∈ {0, 0.5, 1.0, 1.5, 2.0, 3.0} × b ∈ {0, 0.25, 0.5, 0.75, 1.0}，指标 MRR 与 Recall@1。

## 结果（实跑输出）

```
best: k1=0.5, b=0.75 -> MRR=0.793
book setting k1=1.5,b=0.75 -> MRR=0.793, R@1=0.750
k1=0 flat across b: True
long-doc win rate: b=0 -> 0.56, b=1 -> 0.00
```

MRR 网格（行=k1，列=b）：

| k1 \ b | 0.0 | 0.25 | 0.50 | 0.75 | 1.0 |
|---|---|---|---|---|---|
| 0.0 | 0.782 | 0.782 | 0.782 | 0.782 | 0.782 |
| 0.5 | 0.563 | 0.595 | 0.595 | 0.793 | 0.793 |
| 1.0 | 0.563 | 0.563 | 0.595 | 0.793 | 0.793 |
| 1.5 | 0.563 | 0.563 | 0.595 | 0.793 | 0.793 |
| 2.0 | 0.563 | 0.563 | 0.595 | 0.793 | 0.793 |
| 3.0 | 0.563 | 0.563 | 0.595 | 0.793 | 0.793 |

## 结论

1. **b 的效果是断崖式的**：b=0 时长文档抢走 56% 的第一名，MRR 只有 0.563；b≥0.75 后长文档一次也没赢，MRR 升到 0.793。这直接印证书里「长文档天然占优」的说法。
2. **k1=0 时 b 完全失效**：整行 0.782 不随 b 变化。因为 k1=0 把 tf 项约掉，长度归一化没有作用对象。这是「参数不正交」的干净例子。
3. **k1 在 1.2–3.0 区间几乎无差别**（0.793 全同），只有 k1=0 与 k1≥0.5 跨过阈值不同。说明在这个语料上，重要的是「用不用词频」，而不是「用多少」。
4. **默认值与最优值接近**：书建议 (1.5, 0.75) 与网格最优 (0.5, 0.75) 的 MRR 都是 0.793，差别只在 R@1 之外的排序细节。默认值在这个玩具语料上没有吃亏，但不能推出它在中文短文本上一定合适。

## 反思

我原以为 b 是「微调旋钮」，可以从 0 慢慢加到 1 看渐变。实际得到的是一条断崖：0.5→0.75 之间 MRR 从 0.595 跳到 0.793。原因是干扰项的重复次数刚好落在饱和区之外，一旦开始归一化就被压下去。这让我对「调参看曲线」这件事更谨慎——曲线平缓可能只是因为测试集没覆盖到敏感区间。另一个意外是 k1=0 那一行：它提醒我，某些参数组合下某个参数是「死」的，扫参时必须先确认当前区域每个维度真的在起作用。

## 复现说明
