《Speech and Language Processing》第 3 版 · 读书笔记 · lab-03：两说话人日志（VAD → 片段级嵌入 → 聚类）

lab-03：两说话人日志（VAD → 片段级嵌入 → 聚类）

怎么跑

cd labs/lab-03
python3 lab03_vad_diarize.py

只依赖 numpy + matplotlib + 标准库 wave。不联网。

输入

  • 脚本内合成 11.8 秒 两说话人交替音频（同一元音序列，只改基频与声道长度）；
  • 说话人 A：F0=110 Hz，声道 scale=1.00；说话人 B：F0=205 Hz，声道 scale=1.15；
  • 轮流顺序：A B A B A B A B A B（10 轮，每轮 1.0 s，间隔 0.2 s 静音）；
  • 两档信噪比：clean（约 20 dB）与 SNR=8 dB 白噪。

产物

文件说明
out/mix.wavclean 条件合成音频（16 kHz）
out/mix_snr8.wavSNR=8 dB 条件合成音频
out/diarization_frames.csv逐帧特征与真值/预测标签（2356 行）
out/summary.json两档条件的评估指标汇总
out/frames.pngF0 轨迹按预测说话人着色的可视化

关键输出真实值

clean 条件（summary.json）

  • 总帧数 = 1178，浊音帧 = 1012；
  • VAD 阈值 = -133.63 dB（能量门限）；
  • VAD 召回率 = 0.8591，误报率 = 0.0；
  • 帧准确率 = 0.1409（以真值语音帧为分母）；
  • 真实切换点 = 9，预测切换点 = 23；
  • 边界平均绝对误差 = 15.6 ms。

SNR=8 dB 条件

  • 总帧数 = 1178，浊音帧 = 344；
  • VAD 阈值 = -19.29 dB；
  • VAD 召回率 = 0.292，误报率 = 0.0；
  • 帧准确率 = 0.0289；
  • 真实切换点 = 9，预测切换点 = 19；
  • 边界平均绝对误差 = 10.0 ms。

结论

  1. VAD 在 clean 条件下召回 85.91%，但 SNR=8 dB 时骤降至 29.2%——能量门限对噪声极度敏感，低信噪比下大量语音帧被误判为静音。
  2. 帧准确率极低（clean 14.09%，SNR8 2.89%），主要原因是：
  • 片段级嵌入窗长 0.5 s、跳 0.25 s，时间分辨率粗；
  • 聚类后窗标签回填到帧时，边界帧容易分配到错误说话人；
  • 合成音频的「同内容不同嗓音」设计使 F0 成为主要区分特征，但 F0 估计在静音过渡段不稳定。
  1. 边界 MAE 在 10–16 ms 量级，说明切换点大致可定位，但帧级标签噪声大。
  2. 该流水线（VAD → 嵌入 → 聚类）与 §17.5 描述的三步一致，但简化版在噪声下性能崩坏，印证了书中「真实日志需要更鲁棒的 VAD 与说话人嵌入」的论述。

反思

  • 合成数据只改 F0 和声道长度，未模拟真实说话人的韵律、口音、情绪差异；真实 diarization 的类间方差更大。
  • 能量 VAD 是最简方案，实际系统应使用神经网络 VAD（如 Silero VAD）或谱特征门限。
  • 聚类仅用 5 维手工特征（F0 中位数、谱质心、低频比、谱平坦度、浊音比例），未使用预训练说话人嵌入（如 x-vector、ECAPA-TDNN）；这是准确率低的另一个原因。
  • 帧准确率以真值语音帧为分母，VAD 漏检直接计为错误——该指标同时惩罚 VAD 与聚类错误，不利于单独诊断。
