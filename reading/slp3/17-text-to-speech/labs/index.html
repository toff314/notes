labs/ 索引：第 17 章《文本转语音》实验汇总

本章共 3 个 lab，覆盖 §17.1–§17.5 的核心概念。所有实验只依赖 numpy + matplotlib + 标准库，不联网，可在本地直接复现。

Lab主题对应章节核心发现关键数字
lab-01源-滤波器（共振峰）合成 + 回收校验§17.1 TTS 概览、§17.2.1 采样率、§17.4 代理指标F0 回收精确；/u/ 的 F1 回收偏差大；代理谱距离 ≠ 听感F0 误差 0.0%；平均 F1 误差 7.43%；/u/ F1 误差 +23.75%
lab-02VQ → RVQ 逐级残差衰减§17.2.2 码本、§17.2.3 RVQ、§17.2.4 初始化、§17.2 词元率单级 VQ 快速饱和；RVQ 第 1 级拿走 82.66% 信息；词元率压缩 26.67×8 级 RVQ 最终 SNR 17.63 dB；k=256 仅比 k=16 高 2.28 dB；注意力节省 98.44%
lab-03两说话人日志（VAD → 嵌入 → 聚类）§17.5 其他语音任务能量 VAD 在 SNR=8 dB 下召回率骤降至 29.2%；帧准确率极低，边界 MAE 约 10–16 msclean VAD 召回 85.91%；SNR8 帧准确率 2.89%；边界 MAE 15.6 ms / 10.0 ms

运行方式

cd labs/lab-XX
python3 labXX_*.py
