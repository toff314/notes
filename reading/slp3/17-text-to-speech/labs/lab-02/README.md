# lab-02：矢量量化 → 残差矢量量化（RVQ）逐级残差衰减

## 怎么跑

```bash
cd labs/lab-02
python3 lab02_rvq_ladder.py
```

只依赖 `numpy + matplotlib`。不联网。

## 输入

- 用固定随机种子生成 **4000 帧 × 256 维** 的合成帧嵌入（约 53 秒 @75 Hz）；
- 模拟 ENCODEC 编码器输出的嵌入分布：6 个隐成分（粗）+ 24 个隐成分（细）+ 噪声 + 时间漂移；
- 维度 D=256 与 §17.2.1 的 ENCODEC 嵌入维度一致。

## 关键输出真实值

### 单级 VQ：k 扫描（vq_k_scan.csv）

| k | MSE | SNR (dB) | 空簇比例 |
|---|-----|----------|----------|
| 16 | 0.1160 | 8.38 | 0.0 |
| 32 | 0.1066 | 8.75 | 0.031 |
| 64 | 0.0944 | 9.27 | 0.0 |
| 128 | 0.0814 | 9.92 | 0.0 |
| 256 | 0.0685 | 10.66 | 0.0 |

- k 从 16 增到 256（16×），SNR 仅提升 **2.28 dB**，收益急剧递减。

### RVQ：8 级 × k=64（rvq_stages.csv）

| 级 | 残差 MSE | 累计 SNR (dB) | 空簇比例 |
|----|----------|---------------|----------|
| 1 | 0.09436 | 9.27 | 0.0 |
| 2 | 0.05156 | 11.90 | 0.0 |
| 3 | 0.03234 | 13.92 | 0.0 |
| 4 | 0.02352 | 15.31 | 0.0 |
| 5 | 0.01937 | 16.15 | 0.0 |
| 6 | 0.01685 | 16.76 | 0.0 |
| 7 | 0.01503 | 17.25 | 0.125 |
| 8 | 0.01376 | 17.63 | 0.328 |

- 第 1 级解释了 **82.66%** 的信息（info_share_stage1 = 0.8266）；
- 最终 SNR = **17.63 dB**；
- 相邻级残差衰减比：[1.83, 1.59, 1.38, 1.21, 1.15, 1.12, 1.09]——逐级收益递减。

### 码本初始化对照（k=64，单级）

| 初始化 | 空簇数 | MSE | SNR (dB) |
|--------|--------|-----|----------|
| random | 0 | 0.0943 | 9.28 |
| kmeans++ | 0 | 0.0942 | 9.28 |

### 词元率账（§17.2：词元率与注意力平方开销）

| 表示 | 序列长度 | 注意力开销（相对 600 词元/秒） |
|------|----------|-------------------------------|
| 16 kHz 采样点 | 26.67× | 711.11× |
| 75 Hz 帧 | 0.12× | 0.02× |
| 75×8=600 词元/秒 | 1.0× | 1.0× |

- 若只对第 1 级做精细注意力、其余级粗略处理，理论注意力节省 = **98.44%**。

## 结论

1. 单级 VQ 的 k-SNR 曲线迅速饱和：k>64 后每翻倍只带来 ~0.6 dB 提升，与 §17.2.2 的「k 的选择需权衡码本大小与收益」一致。
2. RVQ 的残差逐级衰减 but 收益递减：第 1 级拿走 82.66% 信息，第 8 级仅剩 1.09× 衰减比。这与 ENCODEC 实际使用 8 级 RVQ 的设计吻合。
3. k-means++ 在本合成数据上几乎无优势（MSE 差 0.0001），因为数据本身有强簇结构；真实语音嵌入可能更受益。
4. 词元率从 16 kHz 采样点到 600 词元/秒，序列长度压缩 26.67×，注意力开销压缩 711×——这是离散词元化对 LLM 友好性的核心。

## 反思

- 合成数据的簇结构是「6 粗 + 24 细」的稀疏混合，与真实语音嵌入的流形结构差距未知；RVQ 逐级衰减比在真实 ENCODEC 上可能更平缓。
- 空簇比例在第 7、8 级升至 12.5% 和 32.8%，说明高阶码本的码字利用率低——实际工程中可考虑共享码本或早停。
- 本实验未涉及码本训练中的「三种损失」（§17.2.4），后续可加入 commitment loss 与 codebook loss 的对照。
