# lab-01：源-滤波器（共振峰）合成 + 基频/共振峰回收校验

## 怎么跑

```bash
cd labs/lab-01
python3 lab01_formant_synth.py
```

只依赖 `numpy + matplotlib + 标准库 wave`。不联网。

## 输入

- 手工音素表：4 个元音 /a i u e/（各含 F1/F2/F3 目标值）+ 1 个摩擦音 /s/ + 静音段；
- 音段序列：`sil → a → i → u → e → s → a → sil`（总时长 1.64 s）；
- 合成参数：采样率 24 kHz、基频 120 Hz、三档共振峰带宽（60/90/120 Hz）。

## 产物

| 文件 | 说明 |
|------|------|
| `out/synth.wav` | 基频版合成波形（24 kHz, 16-bit PCM） |
| `out/synth_narrow.wav` | 带宽 ×0.5（窄带）版本 |
| `out/synth_base.wav` | 带宽 ×1.0（基准）版本 |
| `out/synth_wide.wav` | 带宽 ×2.0（宽带）版本 |
| `out/formant_check.csv` | 各元音 F1/F2 回收值与目标值对照 |
| `out/metrics.json` | 汇总指标（F0 误差、共振峰误差、代理谱距离等） |
| `out/spectrum.png` | 波形 + /a/ 频谱回收峰可视化 |

## 关键输出真实值

### 基频回收
- 目标 F0 = **120.0 Hz**，实测 = **120.0 Hz**，误差 **0.0%**。

### 共振峰回收（formant_check.csv）

| 音素 | 目标 F1 | 实测 F1 | 误差% | 目标 F2 | 实测 F2 | 误差% |
|------|---------|---------|-------|---------|---------|-------|
| a#1 | 730.0 | 711.3 | -2.56 | 1090.0 | 1071.2 | -1.73 |
| i#2 | 270.0 | 252.0 | -6.68 | 2290.0 | 2291.8 | +0.08 |
| u#3 | 300.0 | 371.2 | +23.75 | 870.0 | 831.1 | -4.47 |
| e#4 | 500.0 | 492.0 | -1.60 | 1500.0 | 1452.1 | -3.19 |
| a#6 | 730.0 | 711.3 | -2.56 | 1090.0 | 1071.2 | -1.73 |

- 平均绝对 F1 误差 = **7.43%**，平均绝对 F2 误差 = **2.24%**，最大单点误差 = **23.75%**（u#3 的 F1）。

### 24 kHz → 75 Hz 下采样对照（§17.2.1）
- 下采样因子 = **320×**（24000 / 75）；
- 1.64 s 音频 @75 Hz = **123 帧**，每帧 **320 采样点**，帧长 **13.33 ms**。

### 代理谱距离（§17.4：代理指标不能替代 MOS）
- narrow vs base = **1.01 dB**
- base vs base = **0.00 dB**
- wide vs base = **3.39 dB**

## 结论

1. 源-滤波器模型在 24 kHz 下能稳定合成可懂元音序列，F0 回收精确到 0.0%。
2. 共振峰回收在大部分元音上误差 <7%，但 /u/ 的 F1 出现 +23.75% 偏差——低元音的 F1 与 F2 间距小，平滑谱峰容易合并，导致抛物线插值偏移。
3. 带宽变化对 log 谱距离的影响是非对称的：窄带 1.01 dB vs 宽带 3.39 dB，说明该代理指标对「峰变宽」更敏感，但不能反映听感自然度差异。

## 反思

- 手工音素表只有 4 个元音，未覆盖双元音和协同发音，与真实 TTS 的语料规模差距极大；本 lab 只验证「合成-分析闭环」是否自洽。
- 代理谱距离（log spectral distance）在 §17.4 中被明确列为不能替代 MOS 的自动指标；本实验的 narrow/wide 对比再次印证：数值差异 ≠ 听感差异。
- /u/ 的 F1 回收误差提示：在低元音上仅用前 2 个谱峰可能不够，后续可引入 F3 或改用 LPC 根估计。
