# 第 17 章 文本转语音 · 术语表

> 30 条。释义尽量贴 raw 正文原话，`§` 为首次出现位置。标记说明：⭐ 本章核心机制；🔧 工程实现细节；📏 评估口径。

## A. 任务与系统
| 术语 | 英文 | 释义 | 位置 |
|---|---|---|---|
| 文本转语音 | text-to-speech, TTS | 根据给定文本生成相应语音波形的任务，即自动语音识别的逆过程 | §17 |
| 语音合成 | speech synthesis | TTS 的同义称呼，强调「造出语音」而非「转换格式」 | §17 |
| 零样本 TTS ⭐ | zero-shot TTS | 目标说话人音色在训练中从未出现过，仅凭少量参考语音即可合成该音色语音的 TTS 任务 | §17.1 |
| 音色/说话人提示 | speaker prompt | 约 3 秒的参考语音，作为条件输入决定合成语音的音色 | §17.1 |
| 口语语言模型 | spoken language model | 接收文本或语音输入、生成文本或语音输出，完成语音翻译、说话人日志、口语问答等任务 | §17.2 |
| 文本前端 | text analysis / front-end | 把原始文本转成音素、韵律边界、重音标记的分析模块，借鉴 NLP 技术 | §历史注记 |

## B. 音频词元化
| 术语 | 英文 | 释义 | 位置 |
|---|---|---|---|
| 音频词元化器 ⭐ | audio tokenizer | 以波形为输入、经矢量量化的离散词元中间表示重建同一波形的模型 | §17.2 |
| 编解码器 🔧 | codec (coder/decoder) | 把模拟语音信号编码为可高效存储与传输的压缩数字表示的机制，本书用它把语音转成离散词元 | §17.2 |
| 编码器 🔧 | encoder | 用下采样卷积把波形映射为 τ 个嵌入的模块，24 kHz→75 Hz 即 320 倍下采样 | §17.2.1 |
| 解码器 🔧 | decoder | 用上采样卷积把量化后的嵌入还原为有损波形的模块，等价于传统声码器 | §17.2.1 |
| 下采样/上采样 | downsampling / upsampling | 沿时间轴压缩或扩展序列长度，由步长大于 1 的卷积实现 | §17.2.1 |
| 嵌入维度 D 🔧 | embedding dimension | 每个时间帧对应向量的长度，ENCODEC 中 D = 256 | §17.2.1 |
| 帧率 | frame rate | 每秒嵌入数，ENCODEC 为 75 Hz，即每帧 13.3 ms | §17.2.1 |

## C. 矢量量化
| 术语 | 英文 | 释义 | 位置 |
|---|---|---|---|
| 矢量量化 ⭐ | vector quantization, VQ | 把连续向量化为离散词元的技术，使语音能像语言模型中的词元序列那样被建模 | §17.2.2 |
| 质心 | centroid | 某一簇内所有向量的几何中心点，k-means 迭代更新它作为该簇代表 | §17.2.2 |
| 码字 🔧 | codeword | 矢量量化中代表某个聚类质心的矢量，解码时用它代替原始矢量重建信号 | §17.2.2 |
| 码本 / 码 🔧 | codebook / code | 由聚类 id（词元）及其对应码字构成的列表称为码本，其中单个聚类 id 本身称为码 | §17.2.2 |
| 分配步骤 | assignment step | k-means 中把每个矢量指派给平方欧氏距离最近的质心所在簇 | §17.2.2 |
| 更新步骤 | update step | k-means 中用簇内均值重新计算码字，与分配步骤交替迭代至收敛 | §17.2.2 |
| 指数移动平均 🔧 | EMA | 端到端训练时替代迭代 k-means 的在线均值更新方式 | §17.2.2 |
| 残差矢量量化 ⭐ | residual vector quantization, RVQ | 用多个码本逐级量化上一级残差的矢量量化变体，从而获得更精细的离散表示 | §17.2.3 |
| 残差 | residual | 原始矢量与其码字之差，代表矢量量化未能捕捉的那部分信息 | §17.2.3 |

## D. 训练与生成
| 术语 | 英文 | 释义 | 位置 |
|---|---|---|---|
| 重构损失 | reconstruction loss | 衡量重构波形与输入波形相似程度的损失，可用波形或梅尔频谱上的 L1/L2 | §17.2.4 |
| 对抗损失 | adversarial loss | 让生成器与判别器相互博弈来训练模型，使生成音频尽可能逼真 | §17.2.4 |
| 直通估计器 ⭐ | straight-through estimator | 反传时跳过不可微的量化步骤，把输出端梯度原样复制回输入端 | §17.2.4 |
| 自编码器 | autoencoder | 学习映射到自身的模型，输入输出是同一段波形 | §17.2.4 |
| 自回归生成 | autoregressive generation | 逐帧从左到右生成第一级量化器编码的方式 | §17.3 |
| 非自回归生成 | non-autoregressive generation | 条件于整段第一级编码，并行生成其余七级编码的方式 | §17.3 |
| 注册语音 | enrollment / prompt speech | 推理时提供的、来自未见说话人的参考语音，决定输出音色 | §17.3 |

## E. 评估与其他任务
| 术语 | 英文 | 释义 | 位置 |
|---|---|---|---|
| 平均意见得分 📏 | MOS | 听者对合成语音按 1–5 分打分并取平均得到的评价指标 | §17.4 |
| 比较平均意见得分 📏 | CMOS | 让听者在两个系统的合成语音之间表达偏好，得分范围 -3 到 3 | §17.4 |
| 词错误率 📏 | WER | 把合成语音送入 ASR 后算出的错误率，用作稳健性代理指标 | §17.4 |
| 说话人日志 | speaker diarization | 判定长音频中每位说话人发言起止时刻的任务 | §17.5 |
| 说话人验证 | speaker verification | 判断某段语音是否属于某个特定说话人的二值判定 | §17.5 |
| 语种识别 | language identification | 根据输入音频判断其中所说的是哪一种语言 | §17.5 |
| 唤醒词检测 | wake word detection | 检测用于唤醒语音助手的一个词或短语，通常部署在端侧小设备 | §17.5 |
| 语音活动检测 🔧 | VAD | 找出音频中连续语音片段的预处理步骤，日志系统的第一步 | §17.5 |

> 记号约定：⭐ 表示本章机制主干（必须能复述原理），🔧 表示实现细节（查表即可），📏 表示评估口径（跨章通用）。
