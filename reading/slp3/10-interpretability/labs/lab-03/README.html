lab-03 · 稀疏自编码器（SAE）λ 扫描

定位：书稿 §10.4「稀疏自编码器」只有标题、正文为空。本 lab 是书外补白，用来亲手观察「重建—稀疏—特征恢复」的权衡；它不声称复现书中方法，也不把结论冒充成书里的观点。

目的

对应 actions.md 学习行动 3，回答三个问题：

  1. 在已知真特征的「叠加」数据上，L1 系数 λ 如何改变重建误差（MSE）与平均激活特征数（L0）？
  2. 能否选出一个兼顾稀疏与重建的 λ？它的代价是什么？
  3. 重建好、L0 接近真实 k，是否意味着字典原子真的对齐了真特征？

输入

不依赖外部数据，全部由脚本内固定种子生成（numpy.random.default_rng(11)）：

数据生成：A = S @ F + noise，其中 F 是 40 个单位范数随机方向，S 每行只有 4 个非零。

结论

  1. λ 控制的是「重建 ↔ 稀疏」的单调权衡：λ 从 0 增到 2，L0 从 79.7 降到 4.14，MSE 从 3.7e-5 升到 2.7e-3。没有免费的午餐。
  2. λ=0.5 是本次数据上的折中点：L0=5.45 已接近真实 k=4，MSE 仍只有 4.87e-4，死特征仅 5%。λ=1/2 虽然 L0 更接近 4，但 MSE 翻倍、死特征升到 17.5%/22.5%，是「为稀疏而稀疏」。
  3. 重建好 ≠ 特征恢复：所有 λ 下真特征的平均最佳余弦只有 0.28–0.42，没有任何真特征被某个字典原子以 >0.8 的余弦对齐；λ=0.5 的子空间重叠也只有 0.157。字典用另一组基重建了数据，但没有恢复生成数据的真基。
  4. 这正好说明「SAE 特征可解释」需要额外证据：只看 MSE 与 L0 曲线会得出「λ=0.5 很好」的结论；加上方向/子空间诊断后，必须承认「它只是一个好的重建器，不是一个可靠的解耦器」。这也是 §10.4 正文缺失时最该保留的警惕。

局限

  • 可辨识性：数据是随机稠密真特征、每样本恰好 4 个非零；同一个 4 维子空间内存在旋转自由度，SAE 可以用不同基达到同样的 L0 与 MSE。低恢复度部分是数据/目标函数的可辨识性问题，不全是优化失败。
  • 训练预算小：1000 步、单一种子、全批量 Adam；没有学习率调度、没有死特征重采样、没有 decoder 单位范数约束（只在初始化时归一化）。
  • 只评估合成数据：没有真实 LLM 激活，也没有人工「特征是否可解释」评分；不能据此推断真实 SAE 的表现。
  • 子空间诊断的近似：真特征子空间用生成时的 S 精确取出；字典子空间用「激活最大的 4 个原子」近似，若真实重建用了第 5 个原子，重叠度会被低估。
  • 实现修正记录：第一版把编码器/解码器矩阵方向写反（A @ We 中 We 是 (M_SAE, D)，与 A 的 (N, D) 不匹配），运行时报 matmul 维度错误。修正为编码器 Wd 形状 (D, M_SAE)、解码器 We = Wd.T 形状 (M_SAE, D) 后跑通。这类形状错误在 numpy 里没有类型检查，先打印 shape 比反复盯公式更快。

反思

我原来以为「MSE 低 + L0 接近真实 k」就说明 SAE 学对了。子空间诊断打脸：它可能只是用另一组基把同样的子空间重建出来，单个原子与真特征的余弦仍然很低。以后读 SAE 论文，我会先问三个问题：除了重建与稀疏，怎么证明字典方向对应真特征？换一个种子/数据分布还成立吗？下游任务真的因此变好吗？如果只看 L0 曲线，很容易把「稀疏」误当成「可解释」。

另外，这次先遇到维度错误、再遇到「指标好看但恢复度差」，两个问题都不是靠调参解决的：前者要回到矩阵形状，后者要回到「我在测什么」。这比多跑几个 λ 更有价值。
