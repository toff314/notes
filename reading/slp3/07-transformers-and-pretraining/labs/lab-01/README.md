# Lab 01 · 缩放点积注意力、因果掩码与多头拼接

**对应行动**：actions.md 第 1 条。

## 运行

```bash
cd labs/lab-01
python3 attention_shapes.py
```

依赖：Python 3、numpy 2.4.6、matplotlib 3.10.9。

## 配置

- N=6 个词元，d=8，A=2 个头，每头 dk=dv=4。
- 随机初始化查询、键、值、输出投影（固定种子 7）。
- 对比有掩码与无掩码两种注意力；再复制输入、只改动位置 3–5，检查前三个输出是否变化。

## 产物

| 文件 | 内容 |
|---|---|
| `out/checks.json` | 形状、行和、掩码、因果性、参数量断言 |
| `out/attention_weights.csv` | 第一个头的 6×6 注意力权重 |
| `out/attention_heatmap.png` | 无掩码 vs 因果掩码的权重热图 |

## 关键输出

- 拼接形状 `[6, 8]`，输出形状 `[6, 8]`，与输入一致；每头权重形状 `[6, 6]`。
- 每行权重和的最大误差 `1.11e-16`。
- 掩码后上三角最大权重 `0.0`。
- 改动未来词元后，前三个输出最大差 `0.0`；不掩码时同样改动造成 `5.51` 的泄漏。
- A=2 与 A=1 的注意力投影参数都为 `256`；FFN 无偏置参数 `512`；整块 `768 = 12d²`。

## 结论

因果掩码把“未来位置”的 softmax 权重压到严格零，因此当前位置的输出只依赖自己与左侧历史；这正是 §7.3 所说“让窗口中的每个位置都能充当训练样本”的前提。多头在 dv=d/A 的约束下，拼接宽度仍为 d，投影总量约 4d²，与头数无关。

## 反思

我原来以为“掩码就是在 softmax 之后把上三角清零”，跑完才确认那样会破坏归一化：必须在 softmax 之前把分数设为 −∞，让分母也不包含未来位置。另一个反直觉点是“多头不增加注意力部分的总参数量”——它增加的是并行视角，不是参数预算。
