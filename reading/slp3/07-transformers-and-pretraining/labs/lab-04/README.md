## 关键输出

### 练习 7.1（d=512, dff=2048, L=12, A=8）

| 项 | 公式 | 数值 |
|---|---|---|
| 注意力层（WQ+WK+WV+WO） | `3d·dk·A + A·dv·d = 4d²` | 1,048,576 |
| 前馈层（无偏置） | `2·d·dff = 8d²` | 2,097,152 |
| 单块 | `4d² + 8d²` | 3,145,728 |
| 12 块 | `12Ld²` | 37,748,736 |

- 与 `12Ld²` **完全相等**（`matches: true`，差值 0）。
- `A=1/4/8/16` 的注意力参数都是 `1,048,576` → `attention_independent_of_A: true`。
- 前馈占整块 `66.7%`，与 §7.2.1「前馈占了大部分参数」一致。

### 练习 7.3 / 7.4（困惑度）

- 概率乘积 `1.0000000000000001e-20`。
- 路径一：`PPL = product^(-1/4) = 100000.0`。
- 路径二：平均交叉熵 `11.512925464970229` nat，`exp(...) = 100000.00000000001`。
- 两路径差约 `1.5e-11 < 1e-9` → `identity_holds: true`。

### 图 7.24 六模型对比

| 模型 | L | d | 报告参数量 | 12Ld² | 比值 |
|---|---|---|---|---|---|
| GPT-2 XL | 48 | 1600 | 1.5B | 1.475B | 0.983 |
| GPT-3 | 96 | 12288 | 175B | 173.9B | 0.994 |
| Qwen3-0.6B | 28 | 1024 | 0.6B | 0.352B | 0.587 |
| Qwen3-32B | 64 | 5120 | 32B | 20.1B | 0.629 |
| Llama 3.1 8B | 32 | 4096 | 8B | 6.44B | 0.805 |
| Llama 3.1 405B | 126 | 16384 | 405B | 405.9B | 1.002 |

- **最准**：Llama 3.1 405B（+0.2%）与 GPT-3（−0.6%）——大 `d`、词表占比小，`12Ld²` 主导。
- **偏差最大**：Qwen3-0.6B（−41%）——词表 152K，嵌入 `|V|·d ≈ 1.56×10⁸`，与 `12Ld² ≈ 3.52×10⁸` 同量级；再加 GQA 与 SwiGLU 门控，公式必然低估。
- 偏差方向统一为「低估」，说明 `12Ld²` 是**主干下界**，不是总参数上界。

## 结论

`12Ld²` 不是普适常数，而是三个假设的产物：**dff=4d、标准多头（无 GQA）、忽略嵌入与偏置**。在 GPT-3 这类老式配置上它几乎精确；在 Qwen3 这类大词表 + GQA + SwiGLU 的新配置上会低估 20–40%。因此看到「XX B 参数」时，先确认口径是否含嵌入，再用 `12Ld²` 判断量级，而不是反过来用公式否定官方数字。

困惑度部分验证了两个等价写法：`PPL = 概率倒数开 n 次方 = exp(平均负对数似然)`。这也解释了为什么 PPL 对分词敏感——换分词器会同时改变 `n` 与每个词元的概率。

## 反思

我原来把 `12Ld²` 当成「Transformer 参数量公式」。跑完才意识到它是一道**教材练习的近似**：推导时明确说了「忽略偏置与层归一化」，而词表嵌入在推导里根本没出现。真正让我改观的是 Qwen3-0.6B：`d` 只有 1024，`12Ld²` 给出的 0.35B 连官方 0.6B 的六成都不到，缺口几乎全在嵌入表。以后估算参数量，我会先问三句：dff 是不是 4d？有没有 GQA？词表多大？
