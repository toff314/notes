Lab 04 · 12Ld² 参数账、困惑度与模型规模表

对应行动：actions.md 第 4 条（ref. 练习 7.1、7.3，图 7.24）。

目的

把三件「纸上算术」变成可复算的脚本：

  1. 参数账（练习 7.1）：按 dk=dv=d/A、dff=4d 逐项统计注意力层、前馈层与整块参数，验证 12Ld²，并检查注意力参数是否与头数 A 无关。
  2. 困惑度（练习 7.3）：用四个条件概率复算 PPL，并验证 PPL = exp(平均交叉熵)（练习 7.4）。
  3. 规模感（§7.8 图 7.24）：把六个开放模型的配置抄成表，比较 12Ld² 与报告参数量的偏差，定位偏差来源。

结论

12Ld² 不是普适常数，而是三个假设的产物：dff=4d、标准多头（无 GQA）、忽略嵌入与偏置。在 GPT-3 这类老式配置上它几乎精确；在 Qwen3 这类大词表 + GQA + SwiGLU 的新配置上会低估 20–40%。因此看到「XX B 参数」时，先确认口径是否含嵌入，再用 12Ld² 判断量级，而不是反过来用公式否定官方数字。

困惑度部分验证了两个等价写法：PPL = 概率倒数开 n 次方 = exp(平均负对数似然)。这也解释了为什么 PPL 对分词敏感——换分词器会同时改变 n 与每个词元的概率。

反思

我原来把 12Ld² 当成「Transformer 参数量公式」。跑完才意识到它是一道教材练习的近似：推导时明确说了「忽略偏置与层归一化」，而词表嵌入在推导里根本没出现。真正让我改观的是 Qwen3-0.6B：d 只有 1024，12Ld² 给出的 0.35B 连官方 0.6B 的六成都不到，缺口几乎全在嵌入表。以后估算参数量，我会先问三句：dff 是不是 4d？有没有 GQA？词表多大？

局限

  • 模型配置抄自图 7.24，未逐项核对官方模型卡；书中自己也声明「只能视为粗略近似」。
  • 12Ld² 与逐项求和都未计偏置、LayerNorm 的 γ/β、位置嵌入；这些在小模型上占比不可忽略。
  • 练习 7.3 的四个概率是题目给定值，不是真实语言模型输出；本 lab 只验证恒等式，不评价任何模型。
  • 未实现 GQA / SwiGLU 的精确参数拆分，偏差归因是定性的，没有逐项对账。
