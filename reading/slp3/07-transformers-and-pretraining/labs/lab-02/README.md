# Lab 02 · 位置嵌入 + 单层 Transformer 块（numpy）

**对应行动**：actions.md 第 2 条。

## 运行

```bash
cd labs/lab-02
python3 tiny_transformer.py
```

依赖：Python 3、numpy 2.4.6、matplotlib 3.10.9。无 PyTorch、无自动微分；前向与反向均为手写。

## 模型与数据

- 语料：4 个模板句循环 90 次，字符级词表 14 个字符。
- 上下文长度 N=16，模型维度 d=24，前馈维度 dff=48，单头因果注意力，参数量 5448。
- 块结构：RMSNorm → 单头因果注意力 → 残差 → RMSNorm → ReLU 前馈 → 残差 → 与 E 绑定的解嵌入。
- 优化：Adam（lr=0.01），batch=32，700 步；80% 窗口训练，20% 留出。
- 反向传播用有限差分做了 12 个参数点的校验；位置消融在推理时把学习到的位置表置零或打乱。

## 产物

| 文件 | 内容 |
|---|---|
| `out/summary.json` | 配置、损失、梯度校验、位置消融、生成样例 |
| `out/training_log.csv` | 每 25 步的训练/留出损失 |
| `out/gradient_check.csv` | 12 个参数点的解析梯度 vs 数值梯度 |
| `out/loss_curve.png` | 训练与留出损失曲线 |
| `out/samples.json` | 温度 0.8 + top-5 与贪心生成样例 |

## 关键输出

- 初始训练损失 `2.745`，训练结束 `0.159`，相对下降 `94.2%`；留出损失 `0.159`。
- 12 个参数点的梯度校验最大相对误差 `9.94e-8`。
- 位置消融（留出损失）：学习式 `0.159`；位置表置零 `1.965`；位置表打乱 `3.075`。
- 生成样例（温度 0.8、top-5）：`the mat. the dog sat on the log. a cat sat on a mat. a dog sat o`。

## 结论

在极小字符语料上，单层块已经能把“下一字符”损失压到 0.16 左右；但这不是“模型学会了英语”，而是语料高度重复，模型主要记住了模板。位置信息确实进入计算：把位置表置零或打乱后，留出损失从 0.159 升到 1.97/3.07，说明同一字符在不同位置被区分开了。梯度校验通过，说明手写反向传播与数值梯度一致，损失下降不是实现错误的偶然结果。

## 反思

我原来以为“位置嵌入只是辅助特征，去掉顶多小幅掉点”；实测掉了十几倍，才理解 §7.4 把它与词嵌入并列的原因。另一个收获是：小模型上 loss 很低并不值得兴奋，先看语料是否重复、再看生成是否只是复读模板。
