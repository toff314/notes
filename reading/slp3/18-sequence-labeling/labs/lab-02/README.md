# lab-02　CRF 特征模板 + 自写维特比（含 HMM 等价性检验）

## 怎么跑 / 方法

```bash
cd labs/lab-02 && python3 crf_templates.py
```

一件事做三遍，共用同一个解码器：

1. **特征模板**：`<y,x>` 发射、`<y_prev,y>` 转移、`<y,shape(x)>` 词形（`x` 全小写 / `Xx` 首字母大写 / `d` 数字 / `X` 其他）。7 句训练语料、5 个标签，特征空间 110 个槽（每个槽 = 模板实例 × 标签）。
2. **训练**：手写前向-后向算 logZ 与边缘概率，SGD 最大化对数似然（lr=0.08，L2=1e-3，400 轮），梯度 = 经验计数 − 期望计数。
3. **解码**：`viterbi(w, node)` 对 `unary + trans` 做动态规划；同一函数传入 `tags` 与 `start` 即可解 HMM。
4. 两个对照模型：`with_shape` 与 `no_shape`（去掉词形模板），测试句 `Zorbly bought a car` 与单词句 `Zorbly`（后者剥掉上下文，只看词形先验）。

## 关键输出 / 结果

```
with_shape nll [6.2078, 0.0978] all_ok True
    Zorbly bought a car  NNP VB DT NN ok=True
    Zorbly               NNP           ok=True
no_shape   nll [6.2078, 0.1346] all_ok False
    Zorbly bought a car  NNP VB DT NN ok=True
    Zorbly               DT            ok=False
HMM 当 CRF 用: ['NNP','MD','VB','DT','NN'] vs 同  score_diff=0.00e+00
```

| 观测 | 数值 |
|---|---|
| 训练 NLL（有词形） | 6.2078 → 0.0978 |
| 训练 NLL（无词形） | 6.2078 → 0.1346 |
| 词形权重 `Xx→NNP` | **+1.718** |
| 词形权重 `x→NNP` | **−1.507** |
| 词形权重 `x→VB` / `x→NN` | +0.799 / +0.782 |
| 最大转移权重 | `DT→NN` +2.347、`NN→VB` +1.958、`NNP→VB` +1.891 |
| HMM 换成 CRF 权重后的路径差 | 0 条，分数差 0.0 |

## 结论

- **模板确实学到了词形先验，但它的作用被上下文遮住了。** 在 `Zorbly bought a car` 上两个模型都对：`bought` 的发射把 VB 钉住，`NNP→VB`/`NN→VB` 的转移再把首词拉向 NNP，右上下文已经足够。把上下文剥掉（单词句 `Zorbly`）后，无词形模型按起始转移选了最高频的 DT，有词形模型靠 `Xx→NNP` 翻盘。这说明「特征有没有用」不能只看整句准确率，要构造让该特征单独负责的探针。
- NLL 的差距（0.098 对 0.135）比准确率更早暴露差别——两个模型在同一批测试句上打平，但似然不同，说明词形模板仍在改善置信度分配，只是没改变 argmax。
- **HMM 可以逐字写成 CRF**：把 log A 塞进 `(T,p,y)` 权重、log B 塞进 `(E,w,y)` 权重、log π 当起始项，同一个维特比得到同一条路径、同一个分数（差 0.0）。这条等式是本章结构的骨架：差别不在解码算法，在权重从哪来。
- 实现上的坑：我第一次跑等价性检验时，CRF 那侧用了 lab 自己的 5 标签集，漏掉 MD，结果路径变成 `NNP NN VB DT NN`、分数差 13.8。**「等价」要求标签集、起始项、特征定义三者同时对齐**，少一个就不是等价，而是另一个模型。

## 反思

- 我原以为 CRF 的复杂度主要在训练，写完才发现解码是免费的——`unary + trans` 的结构和 HMM 一模一样。真正贵的部分是对数似然的梯度：每次更新都要跑一遍前向-后向，语料一大就慢得明显。这解释了书上为什么强调「特征截断」：K 变小，每步的计算量直接线性下降。
- 手写梯度时我把经验计数写成「对每个位置累加 one-hot」，第一版忘了除以句长，导致长句把梯度放大数倍，训练直接发散成 nan。批量归一化的位置（按句数除）比学习率更影响稳定性。
- 词形模板的正负号很值得看：`Xx→NNP` 正、`x→NNP` 负，模型学到的是「首字母大写才可能是专名」这一条人类也认的规则。它不是黑箱，权重可以直接读成规则。
- 局限必须写清楚：7 句语料、5 个标签，这套数字只能证明机制成立，不能证明效果。真实的 NER 特征空间是十万量级，且要处理 OOV 与词典冲突。
