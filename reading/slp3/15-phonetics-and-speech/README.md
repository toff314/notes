## 知识块与主线

本章可以压成一句话：**语音识别的第一步不是「听懂」，而是把气压振动切成 25 ms 的小段、算出每段的频谱形状，再压成几十个数。**

| 块 | 节 | 一句话 |
|---|---|---|
| 1 | §15.1 | 音子 ≠ 字母：转写是必需的第一道工序，宽式记对立、窄式记细节 |
| 2 | §15.2 | 辅音 = 部位 × 方式 × 清浊；元音 = 高低 × 前后 × 圆唇；音节 = 首音 + 韵 |
| 3 | §15.3.1 | 突显是连续带，词重音改变词义，非重读元音弱化为 schwa |
| 4 | §15.3.2–3 | 韵律三层结构 + 调型；同词同重音仍可因音高走向不同而意义不同 |
| 5 | §15.4.1–2 | 波的四参数与数字化：采样（Nyquist）、量化（bit 数 = 动态范围） |
| 6 | §15.4.3 | F0 ≠ 音高、RMS ≠ 响度；dB 是功率比的对数 |
| 7 | §15.4.4–5 | 波形能直接读出塞音/擦音；频谱与语谱图把共振峰暴露出来 |
| 8 | §15.4.6 | 源（基频+谐波）× 滤波器（共振峰）= 语音频谱 |
| 9 | §15.5 | 分帧 → 加窗 → DFT → 梅尔滤波器组 → 取对数，五步得到对数梅尔 |
| 10 | §15.6 | DCT 去相关得倒谱；前 13 阶 + Δ + ΔΔ = 39 维 MFCC |
