1. MFCC 统治三十年，为什么现在又被「滤波器组 + 神经网络」取代

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：MFCC 不是"更好的特征"，只是"为 GMM 时代量身定做"的特征
  • 书籍锚点：《Speech and Language Processing》第 3 版 §15.6「MFCC 是一个 39 维特征向量」；同节说明「不同系数的方差往往互不相关」，以及倒谱取前 12 个系数的做法。
  • 为什么：命中 S1 + S3 + S4 + S6 —— ①S1：书里把 MFCC 当既定答案给出，没说清它的两个前提（对角协方差、DCT 去相关）在神经网络时代已不成立；②S3：牵涉 DCT 的 whitening 作用、Δ/ΔΔ 的补充、fbank 与 MFCC 在下游模型上的精度差；③S4：大众叙事是「MFCC 是语音的金标准」，而 Kaldi/ESPnet 的实践早已默认 fbank，反差点强；④S6：Davis & Mermelstein 1980、Kaldi 文档、Mohamed 2014（fbank vs MFCC）均可查。
  • 增益：① 相对本书：书中只给结论，本文用我的 lab-04 数据（倒谱距离比 5.3 vs 对数梅尔 3.2）说明 MFCC 的"抗 F0"是真实收益，同时用 lab-03 的 −5 dB 结果说明对数梅尔在噪声下也不差，给出"何时该用哪个"的判据；② 对读者：给出一张"特征选择决策表"（后端是 GMM 还是神经网络、是否在意音高、算力预算），避免无脑抄老流程。
  • 素材种子：历史溯源 {Davis & Mermelstein 1980}｜人物 {Mermelstein、Mohamed、Hinton}｜原理 {DCT 去相关、倒谱分离源与滤波器、对角协方差假设}｜争议 {MFCC 是否已被淘汰}
  • 缺口（下游必须自己搜）：fbank vs MFCC 在若干标准数据集上的 WER 对比数字；Kaldi 默认配置的原文；神经网络前端（waveform input）的现状。
  • 体量建议：标准长文（现象 → MFCC 的两个历史前提 → 我的对照实验 → 神经网络时代为何失效 → 决策表）
  • 待核：❓ 我的实验只有合成元音 4 类、20 次试验，样本量不足以支撑"fbank 更好"的一般结论，正文必须标注为"机制演示"而非"基准测试"。
  • 发布：⬜ 未发布 ｜ 链接：待填

2. 从波形到 39 维：手写一条语音特征流水线

  • 交付给：write-tech-tutorial（Mode A）
  • 主题串（可直接复制）：教程：不调 librosa，用 numpy 从零写出 MFCC——分帧、加窗、DFT、梅尔滤波、DCT、差分
  • 书籍锚点：§15.5「语音处理的第一步通常是把输入波形转换成一个声学特征向量序列」；§15.5.2 加窗；§15.5.3 DFT 与 FFT；§15.5.4 梅尔滤波器组与对数；§15.6 倒谱与 39 维。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书中给了公式与直觉，但没有可运行代码，也没给帧数、nfft、滤波器上下限这些工程取值；②S3：每一步都有坑（预加重要不要、nfft 与帧长关系、梅尔上下限截断、DCT 取正交归一、Δ 的窗口宽度）；③S6：HTK Book、Kaldi 文档、librosa 源码均可查。
  • 增益：① 相对本书：把六步流水线变成可跑的 120 行脚本，并用 lab-02/03/04 的真实数值（旁瓣 −17.96 → −37.45 dB、mel 低频 150.5 mel/100 Hz）逐段验证每一步；② 对读者：给出"数值自检清单"——每个中间产物该长什么样、量级多少，便于读者定位自己实现的 bug。
  • 素材种子：历史溯源 {FFT 1965 Cooley-Tukey、倒谱 1963 Bogert}｜人物 {Davis、Mermelstein、Cooley}｜原理 {DFT 定义、三角滤波器、DCT-II}｜争议 {是否需要预加重}
  • 缺口（下游必须自己搜）：HTK 与 Kaldi 的默认参数差异；librosa 的 mel 归一化方式（slaney vs htk）；预加重在神经前端时代的存废。
  • 体量建议：教程（环境 → 六步实现 → 数值自检 → 与库对比 → 常见 bug 表）
  • 待核：❓ 我的 mel 滤波器组上截止取 7733.5 Hz（16 kHz 的 0.483），与 librosa 默认的 fmax=8000 不同，教程里要说明差异来源。

3. 字母不是声音：英语拼写为什么是一笔糊涂账

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：科普：为什么英语拼写不能当发音用——从 c 的两种读法说到音位转写
  • 书籍锚点：§15.1「英语正字法的字母与音子之间的对应关系相当不透明」；「每个音子都用一个取自罗马字母表的符号来表示」；同节列出的发音词典规模（CELEX 160,595 词、CMU 134,000 词）。
  • 为什么：命中 S3 + S4 + S5 —— ①S3：涉及音子/音位区分、宽窄转写、ARPAbet 与 IPA 的取舍；②S4：大众直觉是"英语拼写虽然不规则但大致能读"，而数据（我的 lab-01：例词平均音子/字母比 0.825，只有 12/40 个词音子数等于字母数）直接反驳；③S5：直接落在背单词、发音纠正、TTS 前端等现实场景。
  • 增益：① 相对本书：书中一句"不透明"带过，本文用 40 行对照表把歧义拆成"一字母多音""多字母一音""有字母无音"三类，并给出首字母歧义统计（t → dh/t/th，c → ch/k）；② 对读者：给出"看到生词怎么猜发音"的三步法，以及为什么词典仍是必需。
  • 素材种子：历史溯源 {1066 诺曼征服后的拼写固化、Great Vowel Shift}｜人物 {Chomsky、Halle}｜原理 {音位 vs 音子、宽窄转写}｜争议 {英语拼写改革是否可行}
  • 缺口（下游必须自己搜）：Great Vowel Shift 的具体年代与证据；英语拼写改革运动（Simplified Spelling Board）的一手材料；其他语言正字法透明度的量化研究。
  • 体量建议：中篇（现象 → 三类不对应 → 语音学为何需要独立符号 → 现实影响 → 改革为何失败）
  • 待核：❓ "音子/字母比 0.825" 只来自书中 40 个例词，不能外推为英语整体统计，正文必须限定语料范围。

4. 音高不是频率：梅尔刻度背后的听觉生理

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：科普：为什么 MFCC 要在梅尔刻度上滤波——耳朵不是频谱仪
  • 书籍锚点：§15.4.3「人类的音高感知在 100 Hz 到 1000 Hz 之间最为准确，在这个范围内音高与频率呈线性相关」；§15.5.4「人的听觉并非对所有频带都同样敏感；它对较高频率的敏感度更低」。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书中给了结论与公式，没解释耳蜗的临界带（critical band）机制，也没说 mel 与 Bark 的关系；②S3：牵涉基底膜的行波、临界带带宽、mel 公式的两种常用形式；③S6：Stevens & Volkmann 1940、Zwicker 1961、O'Shaughnessy 的教材均可查。
  • 增益：① 相对本书：用 lab-03 的实测把"非线性"量化——0–100 Hz 跨 100 Hz 得 150.5 mel，而 7000–7100 Hz 同样 100 Hz 只增 14.5 mel，相差 10 倍；② 对读者：解释为什么"高频分辨率低"在语音里几乎不损失信息（共振峰主要在 4 kHz 以下），以及为什么 8 kHz 电话语音仍够用。
  • 素材种子：历史溯源 {mel 刻度 1937 Stevens}｜人物 {Stevens、Volkmann、Zwicker}｜原理 {基底膜行波、临界带、mel/Bark 换算}｜争议 {mel 是否仍是最好的人耳模型}
  • 缺口（下游必须自己搜）：mel 与 Bark 的换算对照表；临界带在 1 kHz 以上的实测带宽；gammatone 滤波器组的生理依据。
  • 体量建议：中篇（现象 → 耳蜗机制 → mel 公式 → 我的滤波器组实测 → 工程含义）
  • 待核：❓ "共振峰主要在 4 kHz 以下"需引用具体研究，不能只凭书中一句"电话只传 4 kHz"反推。
  • 发布：⬜ 未发布 ｜ 链接：待填

5. 一个乘法解释两件事：源-滤波器模型与倒谱

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：原理：语音频谱 = 源 × 滤波器——这个乘法如何同时解释音高、音色与 MFCC
  • 书籍锚点：§15.4.6「声门产生的脉冲（源）如何被声道（滤波器）塑形」；「结果是，不同的元音会使不同的谐波被放大」；§15.6「倒谱可以看作是谱的对数之谱」。
  • 为什么：命中 S1 + S3 + S4 —— ①S1：书中把源-滤波器当直觉讲，没写出"乘积 → 对数 → 相加 → 再傅里叶"的完整链条；②S3：涉及卷积定理、同态信号处理、倒谱的 quefrency 单位；③S4：多数教程把 MFCC 当黑盒，而它其实是这条链的必然产物，反差强。
  • 增益：① 相对本书：用 lab-04 的实测（同一滤波器换 F0 时倒谱距离 3.076、对数梅尔 5.250；换元音时 16.205 vs 16.691，比值 5.3 vs 3.2）把"分离"从比喻变成数字；② 对读者：给出一条可自证的推理链——若源与滤波器真是相乘，则倒谱距离对 F0 应更不敏感，实测比值正好支持。
  • 素材种子：历史溯源 {Fant 1960 源-滤波器理论、Bogert 1963 倒谱}｜人物 {Fant、Bogert、Oppenheim}｜原理 {卷积定理、同态解卷积、quefrency}｜争议 {源-滤波器是否过于简化（鼻腔耦合、声道壁振动）}
  • 缺口（下游必须自己搜）：Fant 1960 的原书；同态信号处理（Oppenheim）的推导；对源-滤波器模型局限性的实验证据。
  • 体量建议：短评/中篇（乘法 → 对数 → 倒谱 → 我的两组距离 → 模型局限）
  • 待核：❓ 我的合成元音只有 5 个谐波（脚本取 k=1..5），与真实语音的几十个谐波差距大，结论需限定为"机制演示"。
  • 发布：⬜ 未发布 ｜ 链接：待填
