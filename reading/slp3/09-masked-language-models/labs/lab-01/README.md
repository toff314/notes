# lab-01 · BERT 掩码策略模拟：15% / 80 / 10 / 10 的账

## 目的

对应 `actions.md` 第 1 条。验证三件事：

1. 「15% 选中、其中 80% 换 `[MASK]`、10% 随机词、10% 原样」换算到整篇语料后，`[MASK]` 率是否约为 12%、随机词率与原样率是否各约 1.5%；
2. 「原样保留」是否真的意味着目标词没有泄漏进输入；
3. 在不同策略下，仅统计「目标已移出输入」的位置时，双向 bigram 上下文的可预测性是否稳定。

## 输入

- 脚本内生成的模板语料：6,000 句 × 7 词元 = 42,000 词元，词表 26。
- 生成模板 5 种（DET-ADJ-NOUN-VERB-DET-NOUN-PUNCT 等），随机种子 `20261020`。
- 不依赖任何外部数据；仅用 Python 标准库 + numpy + matplotlib。

## 运行

```bash
cd labs/lab-01
python3 lab01_mask_policy.py
```

关键输出（本机实际运行）：

```text
语料: 6000 句, 词表 26, 总词元 42000

掩码比例（选中后）
  BERT 80/10/10: mask=0.799 random=0.102 keep=0.099 | 占全文 mask=0.1188 泄漏=0.107
  全掩码 100/0/0: mask=1.000 random=0.000 keep=0.000 | 占全文 mask=0.1521 泄漏=0.000
  不掩码 0/50/50: mask=0.000 random=0.494 keep=0.506 | 占全文 mask=0.0000 泄漏=0.542

  全掩码 100/0/0: n=6389 top1=0.356 top5=0.809

```

## 产物

| 文件 | 内容 |
|---|---|
| `out/masking_stats.csv` | 三种策略的选中率、`[MASK]`/随机/原样占比、全文 `[MASK]` 率、泄漏率、随机碰撞率 |
| `out/predictability.csv` | 三种策略下的 top-1 / top-5 命中率与参与统计的位置数 |
| `out/samples.json` | 80/10/10 策略下的 12 个样例（目标词、top-3 预测、是否仍在输入中） |
| `out/masking_rates.png` | 左图：选中后处理方式占比；右图：双向 bigram 的 top-1 / top-5 |

## 结论

- **比例账对得上**：80/10/10 的实测 `[MASK]` 占全文 11.88%，随机词约 1.51%，原样约 1.48%，与 12% / 1.5% / 1.5% 的期望差均小于 0.3 个百分点；选中率 14.87% 也接近 15%（伯努利抽样带来的正常波动）。
- **「原样保留」仍然泄漏**：80/10/10 的泄漏率 10.7%，不是 10%——多出来的部分来自随机替换恰好抽中目标词（随机碰撞率 7.2% 乘以 10% 的随机分支）。`0/50/50` 的泄漏率更高达 54.2%，因为它有一半位置原样保留，另有约 7.4% 的随机碰撞；这说明「不换 `[MASK]`」不等于「目标不在输入里」。
- **可预测性差距不大**：在剔除泄漏位置后，三种策略的 top-1 都在 0.354–0.359、top-5 都在 0.796–0.809。差异主要来自「有多少位置被泄漏」，而不是「上下文模型在不同策略下变强/变弱」。
- **全掩码的输入 `[MASK]` 率最高**：100/0/0 达到 15.21%，而 80/10/10 只有 11.88%，这正是 BERT 要引入 10% 随机词与 10% 原样以缩小预训练/推理分布差的原因。

## 局限

- 语料是模板生成的，词表只有 26，双向 bigram 只是 Transformer 的极粗替身；top-1 的绝对值不能与真实 BERT 的 MLM 准确率比较。
- 每句固定 7 个词元，`[MASK]` 率对短句敏感；脚本用伯努利抽样而非 BERT 原实现的 `round`，所以选中率会有小幅波动。
- 只跑了一个随机种子；结论是「机制对账」，不是统计推断。
- 没有真实子词切分，`[MASK]` 直接替换整词，未覆盖 WordPiece 把一个词切成多片的情况。
