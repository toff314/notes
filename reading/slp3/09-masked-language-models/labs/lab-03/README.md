# lab-03 · BIO 标注、子词对齐与实体级评估

## 目的

对应 `actions.md` 第 3 条。把 §9.5.2–§9.5.4 的三件事串成一条可运行链路：

1. 词级 BIO 标签如何复制到 WordPiece 式子词，又如何用首子词解码回词级；
2. 词级准确率与实体级 P/R/F1 在「边界错、类型错、随机噪声」三种情况下会差多少；
3. 句子级自助法给出的 95% 区间有多宽，为什么小测试集上的分数差不能直接当结论。

## 输入

- 脚本内 6 个手写句子，共 42 个词级标签，覆盖 PER / LOC / ORG / GPE / TIME / MONEY 六类实体。
- 一个简化的 WordPiece 切分表（`PIECES`）加「长度 >8 则前 4 字符 + `##` 后缀」的兜底规则；例如 `Sanitas → San + ##itas`、`Villanueva → Villan + ##ueva`。
- 四个预测变体：gold、boundary（把 `Villanueva` 改成 `O`，模拟「Jane 而非 Jane Villanueva」）、type（把 ORG 改成 LOC）、noise15%（15% 词元随机换标签）。
- 随机种子 `11`；自助重采样 2,000 次；仅用 Python 标准库 + numpy + matplotlib。

## 运行

```bash
cd labs/lab-03
python3 lab03_bio_alignment.py
```

## 结论

- **往返无损，但只对金标准成立**：词级 → 子词复制 → 首子词解码的一致率是 1.000（42/42）。这证明流程本身可逆，但**不能**证明模型错误会被掩盖——首子词一旦预测错，整词就错；中间子词错才可能被忽略。
- **边界错与类型错都只掉一点词级分，却各记 1 FP + 1 FN**：boundary 变体的词级准确率仍有 0.979，实体 F1 降到 0.917；type 变体词级 0.938、实体 F1 0.917。原因是 `Jane Villanueva` 只标 `Jane` 时，`Villanueva` 从 `I-PER` 变 `O`，同时产生一个 `O` 的假阳性与一个 `I-PER` 的假阴性。
- **随机噪声把差距拉大**：noise15% 的词级准确率 0.760 看起来「还行」，实体级 P 只有 0.400、F1 0.500（8 TP / 12 FP / 4 FN）。词级指标掩盖了边界与类型的连锁错误，这正是 §9.5.4 说「响应单位是实体而非词」的实证。
- **区间太宽，不能宣称优劣**：6 句、2,000 次句子级重采样得到 95% 区间 [0.242, 0.846]，宽度约 0.60。任何两个系统在这个测试集上差 0.1 都可能只是抽样波动；要比较必须增加实体数或做配对检验。

## 局限

- 数据只有 6 句、42 个词标签、12 个实体，bootstrap 的分布是离散且极宽的；区间只能说明「不确定性大」，不能当作真实 NER 的置信区间。
- 分词器是手写 `PIECES` + 长度规则，不是真正的 WordPiece；`Mt.`、`Corp.` 等标点的切分与真实模型可能不同。
- 解码只实现「首子词 argmax」，未实现「子词概率平均/最大」与 CRF 全局约束；因此没有测到非法 BIO 转移的影响。
- noise15% 用固定种子生成一次，换种子后具体 FP/FN 会变；结论是机制性的，不是某个固定分数。
- 未训练任何神经模型，「预测变体」是人为构造的，用来隔离评估口径的影响。
