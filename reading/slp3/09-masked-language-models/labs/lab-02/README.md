# lab-02 · 玩具掩码语言模型：损失口径与上下文增益

## 目的

对应 `actions.md` 第 2 条。用一个不依赖深度学习框架的玩具模型，把 §9.3.1 的两句话跑成可观察的数字：

1. MLM 的损失只对被选中的位置计算，未选中位置不产生梯度；
2. 上下文确实比一元频率提供额外信息，但一个「词袋双塔」模型的能力有明确上限。

## 输入

- 脚本内生成的模板语料：训练 4,000 句、验证 1,000 句，每句 7 个词元，词表 26。
- 名词按语义类（animate / vehicle / nature / object）选择动词，使上下文真的有信息。
- 每句随机挖掉 **1 个**位置（约 1/7 = 14.3%，接近 BERT 的 15%），其余 6 个词作为上下文。
- 随机种子 `7`；仅用 Python 标准库 + numpy + matplotlib。

## 运行

```bash
cd labs/lab-02
python3 lab02_toy_mlm.py
```

关键输出（本机实际运行，300 epoch，约 73 秒）：

```text
训练 4000 句 × 7 词，词表 26
epoch   0 train=2.325 dev=1.911 top1=0.314 top5=0.682
epoch 299 train=1.741 dev=1.766 top1=0.333 top5=0.702

玩具 MLM: loss=1.766 top1=0.333 top5=0.702
一元基线: loss=2.889 top1=0.166 top5=0.513
```

## 产物

| 文件 | 内容 |
|---|---|
| `out/loss.csv` | 每 10 个 epoch 的训练/验证损失与 dev top-1/top-5 |
| `out/metrics.csv` | 玩具 MLM 与一元基线的 loss / top-1 / top-5 |
| `out/rank_hist.csv` | 验证集 1,000 个目标词的名次分布（rank 0–9 与 ≥10） |
| `out/predictions.json` | 12 个样例的上下文、目标词、top-3 预测与目标概率 |
| `out/loss_and_topk.png` | 左图：损失曲线；右图：top-1 / top-5 与一元基线对照 |

## 结论

- **上下文有效**：玩具 MLM 的 dev loss 1.766，比一元基线 2.889 低约 1.12 nat；top-1 从 0.166 提到 0.333，top-5 从 0.513 提到 0.702。这说明「看其余 6 个词」确实比「只背词频」多出信息。
- **损失确实只算被挖掉的位置**：训练循环对每个样本只计算 `target` 的负对数概率，再按 batch 平均；其余 6 个词元只参与上下文向量，不进入损失。这与式 9.4「除以 |M|」在「每句 |M|=1」的特例下一致。
- **上限明显**：top-1 停在 0.333 左右。原因是模型把上下文词向量做**均值**，丢掉了词序与位置结构；`rank_hist.csv` 中仍有 74/1000（7.4%）的样本排名 ≥10，主要是仅凭词袋无法区分的同类别词。
- **不能把玩具数字外推**：1.766 的 loss 不是 BERT 的 perplexity，0.333 也不是 BERT 的 MLM 准确率；它只证明「目标函数可以这样落地」与「上下文有增益」两件事。

## 局限

- 玩具模型是位置无关的词袋双塔，没有 Transformer 的多头注意力、层归一化与残差；它无法学习词序，因此不能用来评估真实 MLM 的能力。
- 每句只挖 1 个位置，未测试 `|M|>1` 时损失分母的变化；若要多掩码，需要把每个位置的损失求和后除以 `|M|`。
- 词表只有 26，且语料由模板生成；类别信号过强，top-1 的上限受模型结构限制而非数据限制。
- 单随机种子、单学习率（0.05）、固定 300 epoch；没有早停与超参搜索。
- 没有子词切分，`[MASK]` 的最小单位就是整词。
