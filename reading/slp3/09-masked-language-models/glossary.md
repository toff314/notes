| 编码器（encoder） | 「以词元序列为输入，并为每个词元输出一个向量表示」 | §9.1 | 等长进、等长出，每个位置一个上下文化向量；不负责往下写。 |
| 解码器（decoder） | 「逐个迭代地生成输出词元」「信息流是从左到右的」 | §9.1 | 只能看左边，边写边定；GPT/Claude/Llama 都是它。 |
| 编码器-解码器 | 「输入词元与输出词元之间的关系要松散得多」 | §9.1 | 允许两边词表不同、长度不同；翻译与语音识别的主场。 |
| 掩码语言模型 | 「遮蔽掉一个词，并学习通过观察两侧周围的词来预测它」 | §9.1 | 用挖空-还原代替下一词预测的双向模型。 |
| 双向注意力 | 「词元 i 的注意力可以关注其后的词元 i+1 等等」 | §9.2.1 | 把 `QKᵀ` 上三角的 `−∞` 拿掉，整行都能被 softmax 看到。 |
| 因果掩码 | 「使注意力无法看到未来的词元」 | §9.2.1 | 上三角置 `−∞`，保证第 i 行只看 1..i；双向模型删的就是它。 |
| 完形填空任务（cloze） | 「学习执行填空任务」（Taylor，1953） | §9.3 | 给残缺句子补缺项；来自语言测试，不是神经网络原创。 |
| 去噪（denoising） | 「以某种方式破坏……系统的目标就是去除噪声」 | §9.3 | 先弄坏再还原的总称；掩码、替换、重排、删除都算。 |
| 掩码语言建模（MLM） | 「随机遮盖……一定比例的词元……预测这些被遮盖词元」 | §9.3.1 | 只对选中位置算损失的预训练目标。 |
| `[MASK]` | 「词表中名为 [MASK] 的特殊词元」 | §9.3.1 | 训练时才会出现的占位符；下游推理通常见不到。 |
| 下一句预测（NSP） | 「判断输入的两个句子在语料库中是否原本相邻」 | §9.3.2 | BERT 的辅助二分类目标；RoBERTa 证明可删。 |
| `[CLS]` | 「被加在输入句对的最前面」 | §9.3.2 | 没有词义的汇总位；靠 NSP 被训练成句向量。 |
| `[SEP]` | 「被放在两个句子之间以及第二句最后一个词元之后」 | §9.3.2 | 句对任务的分隔符，微调时沿用同一格式。 |
| 段嵌入（segment embedding） | 「第一/第二段嵌入」与词嵌入、位置嵌入相加 | §9.3.2 | 告诉模型这个词属于第几句；与位置嵌入同维相加。 |
| 多语言诅咒 | 「与在较少语言上训练的模型相比，它在每种语言上的性能都会下降」 | §9.3.3 | 语言越多，每种语言分到的模型容量越薄。 |
| 微调（fine-tuning） | 「在预训练模型之上加入……专用头」 | §9.4 | 主干基本不动，只换最后一公里。 |
| 分类头（classifier head） | 「接收模型输出向量并据此作出该任务的判断」 | §9.4.1 | 一个小矩阵把 `h_CLS` 映射到标签空间。 |
| 迁移学习 | 「从一个任务或领域获取知识，然后把它应用（迁移）到求解一个新任务」 | 章首 | 预训练-微调是它在 NLP 里的具体形态。 |
| 词元 / 子词 | 输入「先经过词元化……在子词词元而非词上进行」 | §9.2.1 | 模型的最小输入单位，不等于语言学上的词。 |
| BIO 标注 | 「B 标记实体片段的起始，I 标记片段内部的词元，O 标记片段之外」 | §9.5.2 | 用逐位置状态表示括号；n 类实体共 2n+1 个标签。 |
| IO 标注 | 「通过取消 B 标签而丢失了一些信息」 | §9.5.2 | ⚠️ 与 BIO 的区别：相邻同类实体会粘成一个，边界丢失。 |
