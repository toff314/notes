# lab-05　中文内涵框架手工构建

对应行动：`actions.md` 第 5 条。对应书中 §23.9（内涵框架）。

## 怎么跑

```bash
cd labs/lab-05
python3 lab05_connotation_frames.py
```

依赖：标准库 csv（无需 numpy）。

## 输入

手工选择 5 个中文动词：侵犯、幸存、批评、感谢、等待。选择依据：
- 侵犯、幸存：直接对应书中 violate/survive 两个例子，可对照验证方向。
- 批评：情感方向高度依赖语境（建设性 vs 恶意），用于测试框架的表达能力。
- 感谢：主宾双正面，测试非对立结构。
- 等待：低能动性，对应书中 Sap et al. 2017 对 waited 的标注。

## 产物

| 文件 | 内容 |
|---|---|
| `out/connotation_frames.csv` | 5 个动词的内涵框架表（Role1/Role2 情感、权力关系、能动性、例句、分析） |

## 结论

1. **survive/violate 方向与书中一致**：手工标注的侵犯（施事负面/受事正面）和幸存（主语正面/宾语负面）与书中图 23.14 完全对应，验证了中文动词在论元情感方向上可以与英文平行。
2. **「批评」展示了语境依赖**：批评者的情感方向取决于语境——建设性批评中主语是正面（监督者），恶意批评中主语是负面（攻击者）。这说明内涵框架对多义动词需要更细的义项区分（类似 SentiWordNet 对同义词集的处理）。
3. **「感谢」是非对立结构**：主宾双正面，权力关系上被感谢者高于感谢者。这说明内涵框架不只是「谁好谁坏」，还包括「谁强谁弱」的权力维度。
4. **「等待」的能动性标注**：低能动性对应书中 Sap et al. 2017 对 waited 的标注，验证中文动词也能套用这一维度。

## 反思

手工构建 5 个动词比预期更花时间，因为每个动词的论元角色和情感方向都要仔细斟酌。最难的是「批评」——它不像 survive/violate 那样有明确的受害者/幸存者结构，而是高度依赖语境。这让我意识到：**内涵框架的自动构建（Rashkin 2016 的有监督方法）必须先把动词按义项细分，否则分类器会学到混合信号**。书中没有展开这一点，但手工构建时立刻暴露出来。
