1. Potts 图：为什么「好」和「极好」不是同一种正面

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：词的情感不只有正负——Potts 图如何用分布形状区分「好」与「极好」
  • 书籍锚点：《Speech and Language Processing》第 3 版 §23.5「强正面程度词的曲线呈字母 J 形，而强负面程度词看起来像倒 J 形」；「弱正面和弱负面程度词呈驼峰形」。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书中给结论和形状分类，但没给构建 Potts 图的完整代码与调参细节；②S3：涉及似然估计、归一化、分布形状分析，有足够纵深；③S6：Potts 2011 原始论文、IMDb 数据集均可查。
  • 增益：① 相对本书：把「J 形/倒 J 形/驼峰形」的类型学落成可运行代码（我的 lab-01），并复算 P(disappointing|1)=.0003 作为锚点；② 对读者：拿到一份能在自己语料上画 Potts 图的教程，并理解「均值相同、形状不同」的词为什么不能混用。
  • 素材种子：历史溯源 {Osgood 1957 的因子分析}｜人物 {Potts、Mohammad}｜原理 {P(w|c) 似然估计、归一化、分布形状}｜争议 {二元极性是否丢失了强度信息}
  • 缺口（下游必须自己搜）：Potts 2011 的完整实验设置；不同语料（中文 vs 英文）上 Potts 图形状的差异；Potts 图在情感组合性建模中的具体用法。
  • 体量建议：标准长文（现象 → 分布表示 → 构建代码 → 形状类型学 → 应用 → 局限）
  • 待核：❓ 我的 lab-01 用合成数据复算，数值与书中一致但语料规模差 5 个数量级；正文必须注明语料条件，不可外推。
  • 发布：⬜ 未发布 ｜ 链接：待填

2. 种子词选错，整个词表就废了：半监督情感词表的命门

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：5 个种子词决定 5000 个词的极性——半监督情感词表如何被种子词劫持
  • 书籍锚点：§23.4.1「Hellrich 等（2019）指出，在为不同历史时期建模态度时，从一部大型现代态度词典出发，要优于使用为跨时间稳定而调校过的小种子集」；Hamilton 等（2016a）为通用/Twitter/金融分别定义种子词。
  • 为什么：命中 S1 + S4 + S5 —— ①S1：书中给结论和一个例子，但没系统分析种子词数量和选择对结果的影响；②S4：大众直觉是「有种子词就能扩展」，而书中明确说种子词选择决定成败；③S5：直接落在领域适配（金融 vs Twitter）上，有现实工程意义。
  • 增益：① 相对本书：用 lab-02 的语义轴实验展示「换一组种子词，top-20 排名大变」，把「种子词是命门」从一句提醒变成可复现的实验；② 对读者：给出「如何选种子词」的检查清单（领域相关性、极性纯度、数量、多样性），而不是一句「选好种子词很重要」。
  • 素材种子：历史溯源 {Turney & Littman 2003 的 PMI-IR 方法}｜人物 {Hamilton、Hellrich、Turney}｜原理 {语义轴、质心、余弦投影}｜争议 {大种子词表 vs 小种子词集哪个更稳}
  • 缺口（下游必须自己搜）：Hellrich 2019 的完整实验设计；不同领域（法律、医疗）的种子词案例；中文语义轴的种子词选择研究。
  • 体量建议：标准长文（现象 → 语义轴原理 → 种子词实验 → 领域适配 → 检查清单）
  • 待核：❓ 我的 lab-02 用 5 对种子词在小语料上实验，规模不足以给出普适结论；正文需标注「小语料结果，方向性参考」。
  • 发布：⬜ 未发布 ｜ 链接：待填

3. 对数几率比信息狄利克雷先验：找两个语料的差异词，为什么简单方法会骗你

  • 交付给：write-tech-tutorial（Mode A）
  • 主题串（可直接复制）：论文：用 Monroe 2008 方法找语料差异词——为什么你需要狄利克雷先验和 z 分数
  • 书籍锚点：§23.5.1「简单的对数似然或对数几率方法的问题在于，它们会过分强调极罕见词的差异，而且往往还会过分强调极高频词的差异」；式 23.9–23.11 的完整公式；图 23.12 的 Yelp 一星 vs 五星应用。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书中给公式和直觉，但没给完整实现和调参细节；②S3：涉及狄利克雷先验、对数几率比、z 分数、方差估计，统计纵深足；③S6：Monroe 2008 原始论文、Yelp 数据集均可查。
  • 增益：① 相对本书：把式 23.9–23.11 落成可运行代码（我的 lab-03，50 行核心逻辑），并展示「不加先验 vs 加先验」的差异词排序对比；② 对读者：拿到一份能直接套用到自己语料对的教程，并理解为什么「零计数导致无穷大」不是理论问题而是实践灾难。
  • 素材种子：历史溯源 {Monroe 2008 的政治文本分析}｜人物 {Monroe、Jurafsky}｜原理 {狄利克雷先验、对数几率比、z 分数}｜争议 {背景语料的选择对结果的影响}
  • 缺口（下游必须自己搜）：Monroe 2008 的原始数据集；不同背景语料（Wikipedia vs Brown）对 z 分数排序的影响；中文语料的对数几率比适配（分词影响）。
  • 体量建议：教程（环境 → 语料对 → 简单方法 → 狄利克雷修正 → z 分数 → 可视化 → 调参陷阱）
  • 待核：❓ 我的 lab-03 用合成语料（50 正 + 50 负），规模远小于书中 90 万条 Yelp；正文必须注明「方法验证，非效果验证」。

4. 内涵框架：动词本身携带了对主语和宾语的态度

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：「侵犯」和「幸存」本身就是态度——内涵框架如何结构化谓词的情感
  • 书籍锚点：§23.9「通过使用（23.15）中的动词 violate，作者表达了对 B 国的同情，把 B 国描绘成受害者，并表达了对施事方 A 国的敌意」；「对于 survive，作者和读者对 Role1（主语）持正面情感，对 Role2（直接宾语）持负面情感」。
  • 为什么：命中 S1 + S3 + S5 —— ①S1：书中给直觉和例子，但没给构建内涵框架的完整流程；②S3：涉及谓词-论元结构、情感方向标注、权力/能动性维度，有语言学纵深；③S5：直接落在新闻立场分析、舆论监控上，有现实落点。
  • 增益：① 相对本书：用 lab-05 手工构建 5 个中文动词的内涵框架表，把书中两个英文例子扩展到中文，并讨论中文动词论元结构的差异；② 对读者：拿到一份「如何从依存句法+情感词表自动构建内涵框架」的操作指南。
  • 素材种子：历史溯源 {Rashkin 2016/2017 的原始框架}｜人物 {Rashkin、Sap、Field}｜原理 {谓词-论元结构、情感方向、权力差异}｜争议 {手工构建 vs 有监督学习的成本与质量}
  • 缺口（下游必须自己搜）：Rashkin 2016 的标注指南；中文动词论元结构的情感方向数据库；内涵框架在中文新闻分析上的应用案例。
  • 体量建议：中篇（现象 → 理论 → 手工构建 → 自动扩展 → 应用 → 局限）
  • 待核：❓ 我的 lab-05 只有 5 个动词、2 个例句，是方法演示不是数据验证；正文必须明确区分「手工示例」与「可扩展系统」。

5. 情感词表不是词典：固定词表为什么注定反语境

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：「厉害」到底是夸还是骂——固定情感词表为什么处理不了语境
  • 书籍锚点：§23.1「在这类基于词表的态度模型中，一个词的情感含义通常是固定的，与使用该词的语言语境、说话者的方言或文化无关」；§23.8 以实体为中心的方法作为「补洞」方案。
  • 为什么：命中 S4 + S5 + S6 —— ①S4：大众直觉是「查词典就知道情感」，而书中明确说固定词表忽略语境；②S5：直接落在中文产品评论、社交媒体分析上，「厉害」「棒」「绝」的极性翻转是常见痛点；③S6：Barrett 2007 的建构主义、第 5 章上下文嵌入均可查。
  • 增益：① 相对本书：把「反语境」从一句限定扩展成可操作的诊断清单——哪些词类最容易语境翻转、怎么用上下文嵌入补救；② 对读者：给出「何时该用固定词表、何时该换上下文嵌入」的决策树。
  • 素材种子：历史溯源 {Osgood 1957 的静态空间假设}｜人物 {Barrett、Mohammad、Field}｜原理 {分布语义、上下文嵌入、词义消歧}｜争议 {静态词表是否仍有存在价值}
  • 缺口（下游必须自己搜）：中文语境翻转词的系统研究；上下文嵌入在情感分析上的增益数据；固定词表+规则在特定场景（法律文本）的优势案例。
  • 体量建议：短评/中篇（现象 → 静态假设 → 中文例子 → 上下文补救 → 决策树）
  • 待核：❓ 「厉害」等词的极性翻转频率需要真实语料统计，不能仅凭直觉举例。
