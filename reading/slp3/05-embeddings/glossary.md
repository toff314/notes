# 《Speech and Language Processing》第 3 版 · 第 5 章 · 术语表

|---|---|---|---|
| 分布假设 distributional hypothesis | 出现在相似语境中的词往往具有相似的含义 | §5.1 | 用「邻居像不像」代替「定义是什么」，是整个向量语义的地基 |
| 词元 lemma | 词典中作为词条收录、代表一组屈折形式的词 | §5.1 | 词表里的「户口名」，mice 挂在 mouse 名下 |
| 引用形式 citation form | 词典中为词条选定的规范书写形式 | §5.1 | 词元的书写样式，名词取单数、动词取不定式 |
| 词形 wordform | 词元在句子中实际出现的具体屈折形式 | §5.1 | 文本里真正跑出来的那个字符串 |
| 词义 word sense | 词元含义中的每一个侧面 | §5.1 | 一个词元下的多个义项，mouse 既是鼠也是鼠标 |
| 同义关系 synonym | 两词各自的某个词义相同或几乎相同 | §5.1 | 严格同义几乎不存在，只剩「大致可换」 |
| 对比原则 principle of contrast | 语言形式上的差异总是与某种意义差异相关联 | §5.1 | 换了说法就一定换了意味，所以没有绝对同义词 |
| 相似度 similarity | 衡量两个词的意义接近程度 | §5.1 | cat 与 dog 不像同义，但共享大量语境 |
| 关联性 relatedness | 词之间除相似之外的意义联系 | §5.1 | coffee 与 cup 不相似，却总在同一场景出现 |
| 语义场 semantic field | 覆盖某个特定语义领域、彼此有结构关系的一组词 | §5.1 | 医院词场：surgeon/scalpel/nurse 一族 |
| 主题模型 topic models | 对大量文本做无监督学习、归纳成组关联词 | §5.1 | LDA 一类方法，产出「文档在谈什么」的词团 |
| 内涵 connotation | 词义中与情感、情绪、观点、评价相关的方面 | §5.1 | 字面之外的褒贬色彩，fake vs replica |
| 情感 sentiment | 语言所表达的正面或负面评价态度 | §5.1 | 内涵的可计算版本，情感分析的对象 |
| 向量语义 vector semantics | 把词表示为多维语义空间中的一个点 | §5.2 | 词义变成坐标，比较词义变成比较几何位置 |
| 嵌入 embeddings | 由语料中词的邻接分布学习得到的稠密数值向量 | §5.2 | 短而稠密、维度不可命名的词坐标 |
| 词-上下文矩阵 word-context matrix | 行是目标词、列是上下文词、单元格是共现次数 | §5.3 | 每个词的「邻居指纹表」，可读但极稀疏 |
| 稀疏向量 sparse vector | 大多数分量为零的向量表示 | §5.3 | 维度=词表大小，非零项寥寥无几 |
| 点积 dot product | 两个同维向量对应分量相乘后求和 | §5.4 | 方向与长度混在一起的相似度原始分 |
| 向量长度 vector length | 各维取值平方和的平方根 | §5.4 | 向量在空间中的「大小」，与词频高度相关 |
| 余弦 cosine | 两个向量夹角的余弦，等于长度归一化后的点积 | §5.4 | 只比方向不比长短，词义比较的标准度量 |
| 单位向量 unit vector | 长度为 1 的向量，由向量除以自身长度得到 | §5.4 | 归一化后点积与余弦等价，省一次除法 |
| skip-gram | 用目标词预测其上下文词的 word2vec 算法 | §5.5 | 拿「猜邻居」当训练任务，产物是权重 |
| SGNS | 带负采样的 skip-gram（skip-gram with negative sampling） | §5.5 | skip-gram 的实用训练法：真邻居 + k 个随机词 |
| 静态嵌入 static embeddings | 每个词只学一个固定向量，不随上下文变化 | §5.5 | 一词一坐标；BERT 那种随句子变的叫动态嵌入 |
| 自监督 self-supervision | 直接以连续文本自身作为监督信号 | §5.5 | 标签不用人标，后一个词/邻居就是标签 |
| 目标词嵌入 target embedding | 词作为中心词时的向量，存于矩阵 W | §5.5.2 | 「我说别人」视角的坐标 |
| 上下文词嵌入 context embedding | 词作为上下文词时的向量，存于矩阵 C | §5.5.2 | 「被别人说」视角的坐标，常与 W 相加使用 |
| fasttext | 用子词 n-gram 表示词的 word2vec 扩展 | §5.5.3 | 整词没见过就退到字符片段，专治未登录词 |
| GloVe | 基于词-词共现概率之比的全局向量模型 | §5.5.3 | 用全局共现比值拟合，和 word2vec 殊途同归 |
| t-SNE | 把高维向量投影到二维的可视化方法 | §5.6 | 看图用的降维，局部可信、全局距离不可信 |
| 一阶共现 first-order co-occurrence | 两词因通常彼此邻近而具有的关联 | §5.7 | 搭配关系：wrote–book |
| 二阶共现 second-order co-occurrence | 两词因拥有相似邻居而具有的关联 | §5.7 | 可替换关系：wrote–said，同义词的来源 |
| 平行四边形模型 parallelogram model | 用向量差表示类比关系、按偏移找目标词 | §5.7 | b−a+a* 找最近邻，必须排除输入词本身 |
| 分配伤害 allocational harm | 系统不公平地把资源分配给不同群体 | §5.8 | 招聘/信贷被扭曲，可量化可追责 |
| 表征伤害 representational harm | 系统贬低甚至无视某些社会群体 | §5.8 | 群体形象被固化，难量化但更长远 |
| 去偏 debiasing | 通过变换空间或改训练过程削弱偏见 | §5.8 | 只能削弱不能消除，公平与精度存在硬冲突 |

| 语义特征 semantic feature | 表示某种基本意义的符号（如 +female、+adult） | §5.9（历史注记） | 人工定义维度时代的老做法，与学出来的维度只有抽象对应 |
