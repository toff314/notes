1. 「国王−男人+女人≈王后」为什么经常不成立

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：词向量的类比为什么一半是神话——从 king−man+woman 的三类失败说起
  • 书籍锚点：《Speech and Language Processing》第 3 版 §5.7「在 word2vec 或 GloVe 嵌入空间中，平行四边形算法返回的最近值通常实际上并不是 b*」；§5.7 还给出「cherry:red :: potato:x 返回 potato 或 potatoes」的具体反例。
  • 为什么：命中 S3 + S4 + S6 —— ①S3：涉及负采样目标、向量差的几何含义、排除输入词的工程细节，有足够纵深；②S4：大众叙事是「向量能做算术」，而书里明确说该方法在高频/小距离/特定关系之外表现不好，并引 Linzen 2016、Peterson 2020 的批评，反差强；③S6：Levy & Goldberg (2014)、Linzen (2016)、Peterson et al. (2020) 均可查。
  • 增益：① 相对本书：书中把失败压缩成一段「注意事项」，本文用我自己的 lab-02 实验（20 题、15 中、5 败全因返回输入词）把失败模式拆成可复现的三类；② 对读者：给出「如何正确评测一次类比」的检查清单，避免把实现缺陷当成模型缺陷。
  • 素材种子：历史溯源 {Rumelhart & Abrahamson 1973 的平行四边形模型}｜人物 {Mikolov、Levy、Goldberg、Linzen}｜原理 {b−a+a* 的几何解释、负采样目标}｜争议 {类比是否真是「推理」}
  • 缺口（下游必须自己搜）：Mikolov 2013c 原始报告中的类比准确率数字；GoogleNews 向量上的复现结果；Peterson 2020 的实验设计细节。
  • 体量建议：标准长文（现象 → 机制 → 我的实验 → 三类失败 → 正确评测方法 → 认知科学争议）
  • 待核：❓ 书中「3 个输入词之一或其形态变体」的比例，需要用公开向量在新数据上复核，不能只引用我的合成语料结果。
  • 发布：⬜ 未发布 ｜ 链接：待填

2. 词向量里的偏见：是照镜子还是放大镜

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：词向量不只照出偏见，还把它放大了——分配伤害与表征伤害的分野
  • 书籍锚点：§5.8「与 ‘computer programmer’ - ‘man’ + ‘woman’ 最接近的职业是 ‘homemaker’」；「偏见比在实际劳动力就业统计中更加夸张（Garg 等，2018）」；「这类去偏方法可能减少嵌入中的偏见，但并不能消除它」。
  • 为什么：命中 S4 + S5 + S6 —— ①S4：大众直觉是「模型只是反映数据」，书中明确说会放大，反差点强；②S5：直接落在招聘、信贷等现实系统上，分配伤害可追责；③S6：Bolukbasi 2016、Caliskan 2017、Garg 2018、Gonen & Goldberg 2019 均可查。
  • 增益：① 相对本书：书里把「放大」作为一句结论给出，本文可以补上「为什么优化目标会放大弱信号」的机制解释，并把分配伤害/表征伤害的区分讲透；② 对读者：给出一套可执行的最小审计流程（词表、余弦差、置换检验、样本量报告），并说明小语料为何会得出假发现。
  • 素材种子：历史溯源 {IAT 内隐联想测验 1998}｜人物 {Bolukbasi、Caliskan、Crawford、Gonen}｜原理 {嵌入放大的统计机制、去偏的线性投影}｜争议 {去偏是否只是掩盖}
  • 缺口（下游必须自己搜）：Bolukbasi 去偏后在下游任务上的精度损失数据；Gonen & Goldberg 对「去偏后偏见仍可线性解码」的复现；中文语料上的对应研究。
  • 体量建议：标准长文（现象 → 两个伤害概念 → 放大机制 → 去偏的极限 → 审计清单 → 我的负结果实验）
  • 待核：❓ 「放大」的具体倍数在不同语料/算法上差异很大，不能给单一数字；我的 lab-05 在本语料上不可复现，正文必须如实标注。
  • 发布：⬜ 未发布 ｜ 链接：待填

3. 从共现计数到 PPMI-SVD：一次可复现的词向量实验

  • 交付给：write-tech-tutorial（Mode A）
  • 主题串（可直接复制）：论文：不训练神经网络也能得到词向量——共现矩阵、PPMI 与截断 SVD 的完整实现
  • 书籍锚点：§5.3 词-上下文矩阵与「|V| × |V|」；§5.4 余弦；§5.5.3「word2vec 可以看作是以特定的（PPMI）加权方式隐式地优化某个计数矩阵的函数」；§5.9（历史注记）LSA 用 SVD 取前 300 维。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书中只给直觉和 3 维玩具表，没给完整实现与调参细节；②S3：涉及平滑、PPMI 截断、SVD 缩放、归一化等一串工程决策；③S6：Levy & Goldberg 2014/2015、Deerwester 1990、Landauer & Dumais 1997 均可查。
  • 增益：① 相对本书：把「计数派 vs 预测派等价」这一结论落成可运行代码（我的 lab-01，60 行以内核心逻辑），并复算书中 .018/.996 两个余弦作为正确性锚点；② 对读者：拿到一份能在自己的小语料上跑通、并知道每一步为什么这么做的教程。
  • 素材种子：历史溯源 {LSA/LSI 1988–1997}｜人物 {Deerwester、Landauer、Levy、Goldberg}｜原理 {PMI 的信息论含义、SVD 与共现矩阵的低秩近似}｜争议 {计数派是否已被神经网络淘汰}
  • 缺口（下游必须自己搜）：Levy & Goldberg 2015 的完整超参数表；不同加权（PPMI^0.5、SVD 幂次缩放）的对比数据；中文分词对共现统计的影响。
  • 体量建议：教程（环境 → 语料 → 共现 → PPMI → SVD → 近邻 → 书中数值复算 → 调参陷阱）
  • 待核：❓ 我的实现用列和 +1 平滑，属于工程简化，需与论文原始设定对齐后再写进教程。

4. 窗口大小就是你对「相似」的定义

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：调窗口大小不是在调参，是在选择你要哪一种「相似」
  • 书籍锚点：§5.7「当向量由短上下文窗口计算时，与目标词 w 最相似的词往往是词性相同的语义相似词」；同节 Hogwarts 在 ±2 与 ±5 下的近邻从「其他虚构学校」变成「Dumbledore、Malfoy、half-blood」。
  • 为什么：命中 S1 + S3 + S5 —— ①S1：书中给结论与一个例子，但没有说明效应强度依赖语料规模；②S3：牵涉一阶/二阶共现、停用词、语料体裁；③S5：检索、推荐、聚类都直接受此影响，是能落地的工程选择。
  • 增益：① 相对本书：用 lab-03 的实测（top-10 平均 Jaccard 仅 0.27，短窗前排被虚词占据）指出该结论的适用条件；② 对读者：给出「按业务选窗口」的决策表（同义改写/主题聚类/句法类比各选什么），而不是一句「通常取 ±2 到 ±10」。
  • 素材种子：历史溯源 {Schütze 1992 的词义消歧窗口实验}｜人物 {Levy、Goldberg、Hamilton}｜原理 {一阶/二阶共现、动态窗口}｜争议 {短窗真的更「句法」吗}
  • 缺口（下游必须自己搜）：不同语料规模下窗口效应的定量曲线；中文（无空格、依赖分词）上的窗口定义差异。
  • 体量建议：中篇（现象 → 一阶/二阶 → 我的对照实验 → 语料依赖性 → 决策表）
  • 待核：❓ 「短窗偏句法」需要词性标注数据来验证，我的实验只观察了近邻内容，未做词性统计。
  • 发布：⬜ 未发布 ｜ 链接：待填

5. 为什么是余弦而不是点积：长度、词频与归一化的三重身份

  • 交付给：write-zhihu-tech（Mode A）
  • 主题串（可直接复制）：观点：向量检索里那个「除以模长」，到底除掉了什么
  • 书籍锚点：§5.4「作为相似度度量，这个原始点积存在一个问题：它偏爱长向量」；「更频繁出现的词往往与更多词共现……因此它们的向量更长」；「对于单位向量，点积与余弦相同」。
  • 为什么：命中 S1 + S3 + S6 —— ①S1：书里只给一句「点积偏爱长向量」，没有区分「原始计数向量」与「PPMI/SVD 向量」；②S3：涉及 PMI 的对数压制、SVD 截断、方向归一化三处不同的「去长度」；③S6：Levy & Goldberg 的 PPMI 分析、信息检索中的向量空间模型均可查。
  • 增益：① 相对本书：用 lab-04 实测「原始计数 r=0.72、PPMI-SVD r=0.25」，说明归一化不是一步而是三步；② 对读者：纠正「加个 normalize 就公平了」的工程直觉，给出排查长尾偏置的具体做法。
  • 素材种子：历史溯源 {Salton 的向量空间模型、idf}｜人物 {Salton、Spärck Jones}｜原理 {点积的几何、PMI 的对数、SVD 的低秩}｜争议 {内积检索（MIPS）为何仍流行}
  • 缺口（下游必须自己搜）：大规模向量库（FAISS/HNSW）中内积与余弦的等价变换细节；推荐系统里 popularity bias 的对照研究。
  • 体量建议：短评/中篇（一个反直觉现象 → 三层归一化 → 实测 → 工程建议）
  • 待核：❓ 我的相关系数基于 9,855 token 的技术语料，数值不可外推；正文需注明语料条件。
