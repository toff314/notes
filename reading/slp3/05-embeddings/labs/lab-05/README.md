# lab-05　性别—属性偏差审计：能复现书中结论吗

对应行动：`actions.md` 第 5 条。对应书中 §5.8（偏见与放大、分配伤害/表征伤害）、§5.9（语料与随机性让结论不稳定）。

## 怎么跑

```bash
cd labs/lab-05
python3 lab05_bias_audit.py
```

脚本复用 lab-04 的 `build()` / `load_sentences()`（同一份本章英文原文，窗口 ±5，PPMI-SVD 秩 50），因此需先有 lab-04 目录存在（不要求先运行，只是 import 函数）。

## 方法（照 Caliskan 等 2017 的 IAT 式做法）

- 两组词：男性词 `man/male/he/his/him/boy/father/king`，女性词 `woman/female/she/her/girl/mother/queen`。
- 两组属性：科学 `computer/science/algorithm/math/engineering/data`，人文 `art/poetry/emotion/family/home/literature`。
- 指标：组内所有词对的平均余弦；用「男−女」的差值衡量刻板关联的方向与强度。
- **关键补充**：置换检验。从词表随机抽同样大小的词组 1,000 次，得到「纯噪声能产生多大差值」的零分布，再看观测值的 p 值。

## 产物

| 文件 | 内容 |

| `out/bias_audit.csv` | 4 行：男/女 × 科学/人文 的平均余弦与差值 |

## 结论

1. **本语料无法复现书中的偏见结论**。观测到的「男—科学」差值只有 +0.016，而随机词组能产生的差值均值就有 0.060（标准差 0.049），置换 p = 0.813；「女—人文」的 +0.042 对应 p = 0.619。两者都完全落在噪声范围内。
2. **根因是样本量与体裁，不是方法**。词表里 7 个性别词有 4 个出现 0 次，能进入向量的男女各只有 3 个；属性词「人文」只剩 1 个（`family`）。在一份讲 NLP 的技术章节里，本来就不该期待出现职业—性别的社会统计。
3. **这恰好印证 §5.9**：嵌入结论强烈依赖语料。Bolukbasi 等用的是新闻文本（数十亿词），Garg 等用的是百年历史文本；用 1 万词的技术章节做同样的审计，得到的只能是「无结论」。
4. **方法仍然可用**：脚本产出的差值、置换 p 值、词频三件套，换成新闻语料即可直接复用；先报样本量再报 p 值，是避免「用一个噪声差值讲故事」的最低要求。

## 反思

我原本以为只要按书中配方（性别词 × 职业/属性词，算余弦差）就能在任意语料上「看到偏见」。跑完才发现，小语料上的差值几乎完全由噪声决定——如果不做置换检验，我会把 +0.042 当成一个「发现」写进笔记，而它连随机水平都没超过。

另一个收获是意识到「审计偏见」本身也需要评估：它和 §5.9 说的词向量评估一样，有内部指标（差值大小）和外部效度（是否对应真实社会统计）。书中给出的是后者，我这里只能做到前者的一半，所以结论只能写「不可复现」而不是「没有偏见」。
