# lab-02　言语行为四分类规则分类器

对应行动：`actions.md` 第 2 条。对应书中 §26.1.2（言语行为、Bach & Harnish 四分类）。

## 怎么跑

```bash
cd labs/lab-02
python3 lab02_speech_act_classifier.py
```

依赖：仅 Python 3 标准库。

## 输入

14 句手工标注的测试集（`TEST_SET`），覆盖断言、指令、承诺、回应四类，并包含 2 个难点样本（反问句「你难道不能早点说吗？」、弱指令「我希望你能理解我的处境」）。

| 文件 | 内容 |
|---|---|
| `out/confusion_matrix.csv` | 4×4 混淆矩阵 |
| `out/predictions.csv` | 逐条预测结果 |

## 结论

1. 关键词 + 句法模式的规则分类器在 14 句上准确率 13/14 = 0.9286。
2. 唯一失败是「我需要在五月出行。」被误判为承诺（因为包含「要」字），实际是断言。这说明同一词素在不同语境中功能不同。
3. 两个难点样本（反问句、弱指令）都被正确识别——反问句因为包含「难道」被规则捕获，弱指令因为包含「我希望你能」被捕获。

## 反思

关键词匹配的局限在于同一个词在不同语境中功能不同。「要」在「我要订一张票」中是承诺，在「我需要在五月出行」中只是需求陈述。这让我意识到书中说「言语行为表达了说话者意图中的一个重要组成部分」——意图需要语境，不只是文字。要让系统真正识别言语行为，必须结合上下文和语调，而不仅是句法模式。
