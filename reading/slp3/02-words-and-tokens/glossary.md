# 《Speech and Language Processing》第三版 · 第 2 章 · 术语表

| 术语 | 书上定义（缩引） | 出处 | 我的话 |
|---|---|---|---|
| 词类型（word type） | 语料库中彼此不同的词构成的集合里的成员 | §2.1 | 去重后的词，用来衡量词表有多大 |
| 词例（word instance） | 文本中词每出现一次就计一个的计数单位 | §2.1 | 不去重的计数，用来衡量文本有多长 |
| 词元（token） | 词元化切分所得的单位 | §2.4 | 流水线实际处理的单位，可能与词、语素、字符都不同 |
| 词表（vocabulary） | 某语言中可能出现的词的集合，大小记作 \|V\| | §2.1 | 一个被观测范围限定的词集合，不是固定常量 |
| Heaps 定律 | \|V\| = kN^β，0 < β < 1 | §2.1 | 看得越多、新词越多，增长速度慢于线性 |
| 语素（morpheme） | 语言中最小的能承载意义的单位 | §2.2 | 对比切分得到的最小意义块 |
| 词根（root） | 词中承载主要意义的核心语素 | §2.2 | 去掉所有附加成分后剩下的意义主干 |
| 词缀（affix） | 附着在词根上、增添附加意义的语素 | §2.2 | 必须依附词根才能出现的构件 |
| 屈折语素 | 主要承担句法功能、能产且常强制的语法语素 | §2.2 | 改语法范畴不改词性，如 -ed、-s |
| 派生语素 | 适用范围窄、常改变语法类别、意义不易预测的语素 | §2.2 | 造新词，如 -ful、-ly |
| 附着词（clitic） | 句法上像词、形式上缩减并依附另一词的成分 | §2.2 | 有词的语法作用，没有词的独立形式 |
| 码点（code point） | Unicode 为每个字符分配的唯一编号 | §2.3.1 | 字符的抽象身份证号，如 U+0061 |
| 字形（glyph） | 字符在具体字体中呈现的视觉形状 | §2.3.1 | 同一码点换字体就换样子 |
| UTF-8 | 变长编码，前 128 个码点与 ASCII 相同 | §2.3.2 | 常用字符 1 字节，罕见字符 2–4 字节 |
| 子词（subword） | 比完整词更小的词片段，可由已知子词拼出未登录词 | §2.4 | BPE 学出来的中间单位，大小介于字符与词之间 |
| 未登录词（OOV） | 训练语料中未出现、测试时首次遇到的词 | §2.4 | 词表覆盖不到的词，子词方案用来缓解它 |
| 预词元化（pretokenization） | 运行 BPE 前用正则按空格、标点切分并剥离附着词 | §2.4.3 | 先划好「不许跨过的边界」，再让 BPE 在块内合并 |
| 字节对编码（BPE） | 反复合并语料中最频繁相邻词元以生成子词词表 | §2.4 | 用合并次数换词表大小的贪心压缩算法 |
| 正则表达式 | 刻画字符串集合的代数记号语言 | §2.6 | 描述「哪一类字符串」而非某一个字符串 |
| 贪婪匹配 | 量词默认匹配尽可能长的字符串 | §2.6.4 | 能多拿就多拿，除非加 ? 改成非贪婪 |
| 捕获组 | 用圆括号把匹配子串存入编号分组 | §2.6.7 | 给命中的片段编址，供替换与反向引用 |
| 前瞻（lookahead） | 零宽断言，向右试探模式是否成立而不消耗字符 | §2.6.8 | 只看不取，用来排除特殊情况 |
| 最小编辑距离 | 把一字符串变成另一字符串所需的最少编辑操作次数 | §2.9 | 用插入、删除、替换的代价衡量「有多像」 |
| 对齐（alignment） | 两个序列的子串之间的对应关系 | §2.9 | 把编辑操作逐字摆出来的路径 |
| 动态规划 | 以表格组合子问题解来求解大问题的算法类别 | §2.9.1 | 记下重复子问题的答案，避免重复搜索 |
| 回溯（backtrace） | 从矩阵末端沿指针返回起点，还原最优路径 | §2.9.1 | 填表时留箭头，取答案时逆着箭头走 |
