# lab-01：从零实现单隐藏层网络并在 XOR 上训练

**对应**：§6.1（单元）、§6.2（XOR 与隐藏层）、§6.3（前向公式）、§6.6.3–§6.6.4（反向传播）。
**行动**：`actions.md` 第 1 条。

## 运行

```bash
cd labs/lab-01
python3 xor_mlp.py
```

只依赖标准库 + numpy + matplotlib；全部随机性由 `SEED=7` 固定。

## 实现要点

- 网络 2-8-1：隐藏层 ReLU，输出层 sigmoid，损失为二分类交叉熵。
- 前向：`z1 = xW1+b1 → a1 = ReLU(z1) → z2 = a1W2+b2 → ŷ = σ(z2)`。
- 反向：`dz2 = (ŷ−y)/m`，再依次求 `dW2/db2`、`da1`、`dz1 = da1·1[z1>0]`、`dW1/db1`。
- 有限差分：中心差分 `(L(θ+ε)−L(θ−ε))/(2ε)`，`ε=1e-6`，自动挑选解析梯度最大的 6 个参数作为探针。
- 偏置初始化为小随机数（σ=0.01）而非 0：这不是常规必需，但能避开 ReLU 在 z=0 的折点，使初始化时的数值校验有意义。

## 结论

1. 损失在约 1000 epoch 内从 0.76 降到 1e-2 以下，之后缓慢压到 7.6e-4；`out/loss_curve.png` 呈典型的长尾。
2. `out/decision_boundary.png` 中 0.5 等值线把 (0,1)、(1,0) 两个红点与 (0,0)、(1,1) 两个蓝点分开，四组概率都远离 0.5，说明网络学到的是"异或"而不是记住样本。
3. 有限差分与解析梯度在初始化时相对误差 4.45e-10，训练后 2.70e-08，二者都在 1e-6 以下，可排除"反向公式写错但碰巧收敛"的可能。

## 反思

我原来以为"2 个隐藏单元就能做 XOR"（书上的图确实只画了 2 个），于是先用 4 个单元训练，结果 12 个种子里只有 8 个收敛，我这次抽到的种子停在了 0.75：一个隐藏单元死掉，两个正例被算成同一个值。加到 8 个单元后 12/12 收敛。现在我更愿意把"能表示"和"能优化到"分开说：书上的 2 个单元是一组**存在性**证明，不是训练建议。

另一个意外是零偏置：它让 `z1` 正好落在 ReLU 的 0 点，有限差分左右两侧斜率不同，相对误差一度到 0.25。改成小随机偏置后降到 4e-10。这提醒我，梯度校验失败不一定是公式错，也可能是踩到了不可导点。
