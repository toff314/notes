# 《Speech and Language Processing》第 6 章 · 术语表

> 页码口径：中文版无印刷页码，统一用节号。定义一列是**缩引**，逐字引用见 `book-notes.md` 摘录区。
> 「我的话」一列刻意避开书中原句，用于自测时快速回忆。

| 术语 | 书上定义（缩引） | 节号 | 我的话 |
|---|---|---|---|
| 神经单元 | 取输入的加权和、加偏置，再施加非线性函数，产生一个输出 | §6.1 | 一台"打分 + 弯折"的小机器：先算 z，再算 a |
| 偏置项 | 加权和之外额外加入的一个可学习常数，用于平移激活阈值与决策边界 | §6.1 | 不改变方向、只挪门槛的旋钮 |
| 激活 | 单元对加权和施加非线性函数之后的输出值 | §6.1 | 线性得分被非线性"塑造"后的结果，记作 a |
| sigmoid | 把任意实数压缩到 0 与 1 之间 | §6.1 | 二分类输出层的老朋友，形状像 S，两端会饱和 |
| tanh | 取值范围 -1 到 +1 的 sigmoid 变体，输出以 0 为中心 | §6.1 | 把 sigmoid 的中心从 0.5 挪到 0，隐藏层更爱用 |
| ReLU | 输出取输入与 0 中的较大者，正区间线性、负区间恒 0 | §6.1 | 负的归零、正的原样放行；便宜且不容易饱和 |
| 饱和 | 激活函数在高输入处的输出趋于恒定、导数接近 0 | §6.1 | 曲线被压平，梯度传不回去的状态 |
| 梯度消失 | 反向传播时误差信号因逐层乘以接近 0 的梯度而不断衰减 | §6.1 | 越往输入走，误差越像漏气，浅层几乎收不到更新 |
| 感知机 | 输出 0/1、以阶跃函数作激活的简单神经单元 | §6.2 | 只会用一条直线切空间的古董分类器 |
| 决策边界 | 由权重和偏置确定的直线或超平面，把输入空间划成两类 | §6.2 | 分类器"切开世界"的那条线；XOR 找不到这条线 |
| 线性可分 | 存在一条直线或超平面能把正例与负例完全分开 | §6.2 | 能用一刀切干净；XOR 不属于这一类 |
| 前馈网络 | 信息从输入层经隐藏层单向流向输出层、不含循环连接 | §6.3 | 只许往上走、不许回头的多层网络 |
| 多层感知机（MLP） | 对多层前馈网络的通行叫法，单元并非真正的感知机 | §6.3 | 历史遗留的错名；今天指任何多层非线性网络 |
| 隐藏层 | 位于输入与输出之间、对输入做加权求和与非线性变换的层 | §6.3 | 把原始输入换成"更好用坐标"的中间层 |
| 全连接 | 相邻两层任意一对单元之间都有连接 | §6.3 | 每个输出都看全部输入，矩阵乘法正好表达 |
| 权重矩阵 | 把一层所有单元的权重合在一起形成的矩阵 | §6.3 | 一整层的"旋钮阵列"，形状决定乘法顺序 |
| 归一化 | 把一组实数转换成编码概率分布的向量（0–1 且和为 1） | §6.3 | 把任意分数变成"加起来等于 1"的占比 |
| softmax | 把实数向量转换为概率分布的函数 | §6.3 | 先取指数拉开差距，再除以总和；输出层常用 |
| logits | 输出层归一化之前的未归一化得分，即 z[n] | §6.3.1 | softmax 的原料；可正可负，不是概率 |
| 嵌入矩阵 | 把词表中每个词元映射为稠密向量的查找表 | §6.5 | 一行一个词向量；查表就是按索引取行 |
| 独热向量 | 只有一位为 1、其余为 0 的稀疏向量 | §6.5 | 用"第几位是 1"表示词表里的第几个词 |
| 池化 | 把一组嵌入向量合并为单个向量的操作 | §6.5 | 把变长窗口压成一个定长摘要，代价是丢位置 |
| 平均池化 | 把一组嵌入逐维求算术平均，不区分位置 | §6.5 | 所有词一视同仁地取平均 |
| 最大池化 | 在每个维度上取所有输入嵌入该维的最大值 | §6.5 | 每个维度只保留最强烈的信号 |
| 交叉熵损失 | 衡量输出分布与真实标签分布之间差距的损失函数 | §6.6.1 | 正确类概率越低，罚得越重；从 0 到 +∞ |
| 负对数似然损失 | 多分类硬标签下与交叉熵等价的形式 | §6.6.1 | 只算正确类那一项的 −log，one-hot 时就是交叉熵 |
| 误差反向传播 | 从损失出发，用链式法则把梯度逐层回传到前面各层 | §6.6.2 | 按图倒着走一遍，每个节点乘上自己的局部斜率 |
| 计算图 | 把计算分解为若干独立运算、每个运算作为节点的图 | §6.6.3 | 把公式画成流程图，前向算值、反向算斜率 |
| 链式法则 | 复合函数导数 = 外层对内层导数 × 内层导数 | §6.6.4 | 一路乘下去；反向传播的全部数学依据 |
| dropout | 训练时按概率随机把部分单元输出置零并重新归一化 | §6.6.5 | 每次随机"掐掉"一些单元，逼网络别押宝在单个单元 |
| 超参数 | 由设计者选定、在开发集上调优而非由梯度学到的量 | §6.6.5 | 人手拧的旋钮：学习率、层数、批量大小、p |
| 连接主义 | 20 世纪 80 年代以大量简单单元的分布式计算建模认知的取向 | §历史注记 | 神经网络在认知科学里的旧名字，也叫并行分布式处理 |
