# 术语表 · 第 14 章 RNN 与 LSTM

> 释义用我自己的话写，英文并列原文用词，出处给节号。共 30 条，按阅读顺序排列。

| # | 术语 | English | 释义（我的说法） | 出处 |
|---|---|---|---|---|
| 1 | 循环神经网络 | recurrent neural network (RNN) | 连接里存在回路的网络：某一步的取值直接或间接用到自己更早的输出 | §14.1 |
| 2 | Elman 网络 | Elman network | 在前馈网络的隐藏层上加一条「上一步隐状态」输入的早期循环结构 | §14.1 |
| 3 | 隐藏层 / 隐状态 | hidden layer / hidden state | 每步被整体重写的定长向量，充当整段历史的压缩记忆 | §14.1 |
| 4 | 循环连接 | recurrent connection | 把 t−1 步隐状态送回 t 步的那条边，进图时画成虚线 | §14.1 |
| 5 | 时间共享权重 | weight sharing across time | W/U/V 在所有步是同一组参数，长度不改变参数量 | §14.1.1 |
| 6 | 前向推断 | forward inference | 从序列开头逐步推进到结尾，每步产出一个输出分布 | §14.1.1 |
| 7 | 展开（沿时间） | unfolding | 把循环结构按步摊开成一张深前馈图，从而可用常规反传训练 | §14.1.2 |
| 8 | 随时间反向传播 | backpropagation through time (BPTT) | 在展开图上倒着走，误差沿时间累加回传 | §14.1.2 |
| 9 | 截断 BPTT | truncated BPTT | 把长序列切成定长片段分别训练，跨片段依赖不再回传 | §14.1.2 |
| 10 | 语言模型 | language model | 给定前文，输出词表上下一个词的概率分布 | §14.2 |
| 11 | 自监督 | self-supervised | 标签由数据自身错位产生，不需要人工标注 | §14.2.2 |
| 12 | 教师强制 | teacher forcing | 训练时把标准答案当下一步输入，而非模型自己的输出 | §14.2.2 |
| 13 | 暴露偏差 | exposure bias | 训练输入全为真值、推断输入含自估错误，两者分布不一致 | §14.2.2 |
| 14 | 困惑度 | perplexity (ppl) | 每词平均分支数的指数形式，越低越好；等价于交叉熵取 exp | §14.2.2 |
| 15 | 权重绑定 | weight tying | 输出层矩阵与输入嵌入矩阵共用一套参数（V = Eᵀ） | §14.2.3 |
| 16 | 序列标注 | sequence labeling | 为序列每个位置各给一个标签，逐位置算交叉熵 | §14.3.1 |
| 17 | 序列分类 | sequence classification | 整段序列给一个标签，常用末尾隐状态或池化表示 | §14.3.2 |
| 18 | 池化 | pooling | 对多步隐状态做平均或取最大，合成一个定长向量 | §14.3.2 |
| 19 | 端到端训练 | end-to-end training | 只有最终任务给损失，全部中间层（含嵌入）一起更新 | §14.3.2 |
| 20 | 自回归生成 | autoregressive generation | 把上一步采样结果追加为输入，循环预测下一个词元 | §14.3.3 |
| 21 | 堆叠 RNN | stacked RNN | 把一层的整段输出作为下一层的整段输入，逐层抽象 | §14.4.1 |
| 22 | 双向 RNN | bidirectional RNN | 左右各跑一个独立 RNN，同一时刻两个表示拼接使用 | §14.4.2 |
| 23 | 梯度消失 | vanishing gradient | 误差沿时间连乘、谱半径小于 1 时按指数衰减到 0 附近 | §14.5 |
| 24 | 梯度爆炸 | exploding gradient | 连乘因子大于 1 导致梯度指数增长，可用范数裁剪压制 | §14.5 |
| 25 | 门 / 掩码 | gate / mask | 取值 0–1 的向量，逐点乘用来软性放行或抹除信息 | §14.5 |
| 26 | 细胞状态 | cell state | LSTM 中独立于隐状态的长期记忆通道，走加法更新 | §14.5.1 |
| 27 | 遗忘门 / 输入门 / 输出门 | forget / input / output gate | 分别控制旧记忆留多少、新内容写多少、当前读出多少 | §14.5.1 |
| 28 | 编码器-解码器 | encoder-decoder | 编码器把源序列压成表示，解码器据此自回归生成目标序列 | §14.7 |
| 29 | 上下文向量 | context vector | 解码时可用的源侧信息载体；固定版为编码器末状态，注意力版为加权和 | §14.7、§14.8 |
| 30 | 注意力 / 点积注意力 | attention / dot-product attention | 用解码器状态与各编码器状态打分并 softmax 归一，再对编码器状态加权求和；打分取内积即点积版 | §14.8 |
