# Lab 03　香农游戏：字母三元模型在哪里被纠正得最多？

**对应行动**：actions.md 第 3 条
**书中锚点**：§1.2.2 香农游戏与预测引擎的起源；练习 1.1
**脚本**：`shannon_game.py`　**产物**：`out/corrections.csv`、`out/rates.csv`、`out/summary.json`、`out/rates.png`

## 玩法与输入

- 目标文本取自 §1.2.2 的英文样例（128 字符）：
  `the room was not very light ... the shabby red carpet`。
- 猜词者是一个**字母三元模型**：上下文 = 前两个字符（含空格），每次猜概率最高的一个字母。
- 猜错就"被告知"正确字母，并把正确字母接回上下文——与书中香农游戏的规则一致。
- 训练语料为本章英文原文（78,508 字符），训练前剔除目标样例，避免抄答案。

## 结论（引用自己的产物）

1. 整体纠正率 67.2%——这个三元模型远不是好的猜词者，但**纠正的分布不是均匀的**。
2. 按词内位置：第二个字母最难（84.0%），首字母反而容易些（65.4%），
   词边界（空格）最可预测（28.0%）。按平均意外度（bits）看也是同一顺序。
3. 按词类：实词 79.8% 被纠正，功能词 63.2%。功能词少、搭配固定，
   实词多、续写分支多，这与"可选后续越多、信息量越大"的直觉一致。
4. 注意这不是人类玩家的曲线。人一旦认出整个词，后面的字母几乎不用猜；
   三元模型没有词库，只能在字符局部统计里打转。**"信息存在哪里"取决于猜的人会什么**——
   这正是香农游戏能反过来拷问语言模型的原因。

## 反思

我原以为"词首最难猜"，因为一个词刚开始时可能性最多。实测对字符模型来说第二个字母最难，
首字母因为受"上一词尾 + 空格"的约束反而好猜。这个反直觉结果让我明白：
书里那句"语言把信息存储在哪里"没有脱离观察者的答案，换一个猜词者，曲线就换一条。
