# 问渠 · 开渠衍生笔记

收录「开渠」（zhihu-wiki 渠系统：论文翻译 / 论文笔记 / 课程消化等渠道动作）产出的**衍生题材深挖笔记**——一条渠打开一个素材源头，这里沉淀由它长出来的读书笔记与选题。

## 记录组织

- 一条记录 = 一个开渠来源（一篇论文 / 一门课 / 一个主题），目录名用源素材目录名（如 `arxiv-2302.12173`）
- **paper 开渠笔记**（zhihu-wiki 渠系统「笔记」动作）由流水线自动写入本目录：`README.md`（总览 + 原文出处）+ `notes/` 结构化笔记 + `topics.json` 衍生选题
- `topics.json` 会被 zhihu-wiki `qu-sync` 回读，成为**可开渠的衍生选题**（反哺开渠）
- 产物命名约定（对应 notes 站产物表格列）：
  - 文件名含 `notes` → 「笔记」列
  - 文件名含 `spinoffs` / `topics` → 「选题」列
  - `raw/` 子目录 → 「素材」列（纯展示，不对外提供下载）
