# 计算语言学基础 · 听课笔记

北京邮电大学 · 人工智能学院 · 智能科学与技术中心。课程创建者 **王小捷**，本讲授课 **李蕾**。
教材为 *Speech and Language Processing*（第三版）——即 [`books/`](https://github.com/toff314/books) 的中文翻译底本。

- **课型**：学术内容课（前 3 节讲授、第 4 节讨论；不讲细节与算法，重思路与参与）
- **本仓库收录**：课堂录音转写 + 课件 PPT → 结构化听课笔记
- **课程页**：从 [`index.html`](index.html) 进入，可在线阅读各讲笔记

## 目录结构

```

```

## 产物说明

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `notes.md` | **主笔记**：按讲者思路主线重排，每节「线索 / 内容 / 一句话总结」 | 复习主线；约 5–10 分钟读完 |
| `outline.md` | **思路大纲**：主线 + Mermaid 结构图 | 先看图建立框架，再读正文 |
| `questions.md` | **自测 + 疑问 + 待查 + 待归类碎片** | 自测用；疑问项待下次课或查资料 |
| `corrections.md` | **勘误**：转写 ↔ PPT 的差异（术语以 PPT 为准、内容以转写为准）+ 存疑 | 核对专名与数字；**不是**对个人笔记的勘误 |
| `spinoffs.md` | **衍生选题**：可独立成文的点，按下游写作流水线入参格式打包 | 直接复制「主题串」投喂写作技能；成文链接回填在表中 |

## 标记约定

`【师】` = 老师所讲；`【PPT】` = PPT 有、转写未覆盖；`❓ 存疑` = 转写/识别不确定；`⚠️ 差异` = 转写与 PPT 不一致。

## 生成方式

由 **`write-notes` 技能**产出：输入＝录音转写文本（必选）+ 课件 PPT（必选），输出＝上述五类产物。
本仓库为**交付与阅读位置**，工作副本在 zhihu-wiki 仓库的 `output/` 下。
