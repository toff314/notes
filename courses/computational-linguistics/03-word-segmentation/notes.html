计算语言学基础 · 第 3 讲 汉语切分方法与评测 · 听课笔记

本讲一句话：承接第 2 讲"词无定界"，本讲把汉语切分当成可评测的工程任务来拆——从基于规则的 FMM/BMM（用词典、不管上下文），到基于分类（位置二分类：NB/KNN/MaxEnt/DNN），再到基于序标（BIO 标签 + HMM/Viterbi 的全局决策）；中间插入"性能评估"这把尺子（评测数据、P/R/F1、Baseline/Ceiling）；最后由一位同学分享"从 BASEBALL 到 RAG"的问答六十年。

结构：承上（未登录词的延伸）→ 难点叠加 → 方法史三路线（规则→分类→序标）→ 性能评估 → 学生分享

可疑处：多处术语 ASR 不稳（Naïve、极大熵、"三点"等），见 corrections.md

1. 开场：为什么要补足"前面"的方法（师者视角）

线索：大模型一句话就能分词，为什么还要学 FMM、HMM？

内容：

  • 【师】老师原计划讲得快，但发现同学对早期方法陌生、对深度/大模型更熟，于是决定"把前面补足"，不求进度只求纵深（细节可课后深谈）
  • 【师】读史两体会："二十年河东二十年河西"——神经网络六七十年代火热、后被批到一无是处、20 年后抬头并克服旧问题再上台阶；"螺旋式上升"——审美与方法的循环中总会长出新东西。学历史是照镜子，但别迷信它
  • 【师】直接上大模型当然行，但"只知道用就伸不进去"，难在机制/方法上创新；故借"切分"这个最小任务，看问题如何推着方法往前走

一句话总结：先补足早期方法史，是为了拿到"问题→方法→新问题"的演进视角，而不是只会调用大模型。

2. 承上：未登录词牵出的更大任务——信息抽取与 NER

线索：未登录词不只影响切分，还牵出了哪些任务？

内容：

  • 【师】未登录词里"命名实体"最有代表性、至今仍被研究 → 由此独立出 命名实体识别（NER，转写作"三点"❓）；它第一次被单独提出时，还隶属于更大的任务——信息抽取（Information Extraction）
  • 【师】信息抽取包含：关系抽取、事件抽取、多模态事件抽取（老师口播简称"MT"❓）；它与知识图谱密切相关，都隶属 NLP
  • 【师】新词：教育部下属机构、学会等会不定期发布"互联网新词"监测报告——这类现象往往先于被收录、被研究

一句话总结：一个"未登录词"引出 NER → 信息抽取（关系/事件/多模态），并勾连知识图谱；新词是持续的监测对象。

3. 难点叠加：当边界歧义遇上 OOV 与新词

线索：为什么"单个问题能处理、合起来就难"？

内容：

  • 【师/PPT】PPT P52 把两类麻烦叠起来：边界歧义 + 命名实体（"敦煌市长孙熙龙说"、"北京人和足球俱乐部"）与 边界歧义 + 新词（"先后 14 次赶超女举 58 公斤级世界纪录"、"一些人在讨论二次元朝什么方向发展"）
  • 【师】转写里还举了"北京仁和"（可整体也可拆）、"赶超女举"、"二次元"等例，以 PPT P52 为准
  • 【师】结论：歧义、OOV、新词一旦组合，问题复杂度就上去了——这正是汉语切分难缠的地方

一句话总结：歧义、OOV、新词单独出现已不易，混合出现时复杂度陡增，这是汉语切分难缠的根源。

4. 方法史总览：基于规则 → 基于分类 → 基于序标

线索：三条路线是"技术"之分还是"视角"之分？

内容：

  • 【师/PPT】老师按分词算法的时间发展梳理三条代表路线：基于规则（最早）→ 基于分类 → 基于序标（P53）
  • 【师】叫"统计/深度"是看所用技术（规则→机器学习→深度学习）；叫"分类/序标"是看看待业务问题的视角——视角变了，方法就跟着变。本讲按视角讲
  • 【师】任何与语言相关的任务史，第一阶段的核心特色几乎都是"基于规则"

一句话总结：同一段历史可有两种切法（技术：规则→机器学习→深度学习；视角：规则→分类→序标）；本讲按"视角"来讲。

5. 基于规则（一）：FMM 前向最大匹配与它的两个参数

线索：FMM 的"最大资源"是什么？/ MaxLen 与词典各带来什么问题？

内容：

  • 【师/PPT】最早成型、老师本人第一个做的就是它：前向最大匹配 FMM（Forward Maximum Match），最大资源来自词典（P54）
  • 【师/PPT】示例（P56/P57）：词典只收"语言学/重要"，参数 MaxLen=3（即词典最长词长），切"语言学很重要"——从前往后取 3 字"语言学"命中词典 → 移入输出串并补"/"；剩余"很重要"取 3 字不中 → 从右逐个删字到单字"很"→ 默认单字成词；如此循环直到输入串取空
  • 【师】讨论一：MaxLen 设多大？结论是权衡——太大浪费匹配/回退操作，太小则长词切不出；PPT P58 的"小规律"是词表平均词长 +1/+2，只是经验参考。同学提的"动态窗口""按 80% 命中率反推长度"被老师赞赏
  • 【师】讨论二：词典该收哪些词？普通词靠规模，专名（机构/地名/人名）问题更大；这一层仍是经验性的（P59）

一句话总结：FMM 用固定词典从左到右做最长匹配，性能被两个经验参数（MaxLen、词典内容）决定——简单、快速，但埋着后面所有的坑。

6. 性能评估：评测数据与指标 P/R/F1（评估者视角）

线索：老师为什么反复把"开发者视角"扭到"评估者视角"？/ 一份可信的评测数据要经过哪些工序？/ P 和 R 的"分母"分别是什么？/ 基线、天花板各回答什么问题？

内容：

  • 【师】老师先纠视角：性能评估要站在第三方评估者的角度想"我拿什么数据、多少数据，才能让所有参与者信服"，而不是站在开发者角度只谈自己的效果/时间空间
  • 【师】评测数据不能只有"原始语料"，还必须有一把尺子（标准答案/gold），并说清这把尺子怎么造出来：统一标注标准 → 专家标注 → 多专家交叉检验 → 冲突交委员会判定 → 多轮迭代 → 直到规模与覆盖达标
  • 【师】覆盖度：内容与规模都要满足最终评测需求；数据质控：不能拿错数据或大模型随便生成的结果来填；接口：还要规定环境、配置文件、输入/输出格式，很多人写代码来"机测"——有专门做评测研究的人
  • 【师/PPT】指标（以 P60 为例）：标准答案 4 个词"本 报 讯 春节 临近"，输出 1 得 5 个词。P（准确率）以自己输出的词数为分母（3/5）、R（召回率）以标准答案的词数为分母（3/4）；二者"各有一套道理"，故用 F1 调和平均平衡；更一般形式 F=(β²+1)PR/(β²P+R)，F1 即 β=1（P61）
  • 【师/PPT】P/R 可用邻接表统一计算（转写口播作"临界表"❓，PPT P61 作"邻接表"）：P=a/(a+b)、R=a/(a+c)；任何有标准答案的分类/推荐/翻译任务都能照此推广
  • 【师/PPT】Baseline 基线（P62）：最简单方法（如规则）的性能或用于对比的模型——用途有二：① 模型性能比较（同数据看新模型是否有优势）② 任务难易比较（同模型换数据比）
  • 【师/PPT】Ceiling 天花板（P62）：大模型超过人之前常指"人（且多人）能达到的水平"；用途是看机器离人还差多少，以及不同任务的天花板高低（有的 50%、有的 98%）能反映任务难易。老师补充：如今大模型个别地方已超过人，此定义有点过时
  • 【师】实务：竞赛/评测通常至少发布一个基线——低于基线就不必凑热闹，先跑通基线再改；论文的 P/R/F1 表就是"信服的证据"（老师另点到一个专门刊物/会议，转写"3D VAD"❓）

一句话总结：可信评测 = 覆盖够、说得清来源的标准答案 + 质控与统一接口；P 看自己、R 看标准答案、F1 调和，基线给"脚下最低"、天花板给"往上最高"。

7. 基于规则（二）：BMM 与规则扩展——以及它必然的失效

线索：BMM 与 FMM 差在哪，为什么汉语常更偏好 BMM？/ 加规则能走多远？

内容：

  • 【师/PPT】BMM 后向最大匹配（P63）：把句子倒着输入，匹配不上时先砍前头；同学点出汉语定语前置、核心词常在后，故后向有时能先把关键核心词切出
  • 【师/PPT】FMM/BMM 的失效（P64）：交集歧义 OA 总是切 XJ/Y（BMM 则 X/JY）、组合歧义 CA 总是把 XY 当一个词、OOV 一律切成单字
  • 【师/PPT】加规则（P65）：如"若 W='个人' 且左侧是数词，则切成 个/人"；但马上遇到两个问题——要写多少条规则（"海了去了"）、规则总有例外（"中国第一个人网站"实为"第一个人/网站"❓）
  • 【师/PPT】规则法总结（P66）：知识源=词表、知识表示=符号+规则、知识应用=搜索匹配；简单快速但切分质量不高；它仍有价值——FMM+BMM 可用来发现 OA（如"的确"：FMM 的确/定、BMM 的/确定）
  • 【师】根因分析（P67）：FMM/BMM 只用词表、没有上下文信息；而"一起"还是"一/起"主要取决于上下文（"他们/一起/去看电影" vs "这里发生了/一/起/火灾"）——于是问题变成"如何把上下文信息引入切分？"

一句话总结：BMM 是 FMM 的镜像，规则能救局部却救不了全局；根因是固定词表不含上下文——切分视角遂从"规则"转向"分类"。

8. 基于分类的切分：位置二分类与 NB/KNN/MaxEnt/DNN

线索：怎么把"切分"变成分类问题？/ NB 的"先验估后验"和"朴素"各指什么？/ 分类视角最终败在哪？

内容：

  • 【师/PPT】换视角（P69）：不看"词"，只看每个字与字之间的位置——在此位置"分还是不分"，即位置二分类（"0 有 1 意 2 见 3 分 4 歧 5"）。切分→一系列二分类→已有的有监督分类器全能用，还能用上下文特征；代价是需要已切分数据训练
  • 【师】NB 朴素贝叶斯：核心是"用先验估后验"——后验事先拿不到，就用训练集先验去估（转写"too young too naive"是老师口语解释 naive❓）；套贝叶斯公式后分母不影响比大小可丢，于是在训练集上数数得到"类别先验 + 已知类别下各特征的概率"，新句来时连乘即决策。"朴素"= 引入特征条件独立假设，把高维联合概率拆成连乘（转写作"辅助/高斯列叶斯"❓）
  • 【师】KNN 不需训练、需要计算——与已知类别样本算相似度取最近 K 个投票，K 常取奇数避免平票
  • 【师】NB 只用 unigram 一种特征；更细粒度特征（位置、距离、bigram）区分力更强 → MaxEnt 极大熵（转写作"几大熵"❓）能综合大量特征函数，但这些特征靠人工手写，即"知识工程/特征工程"（P72/P74）；出路是深度学习自动学表示
  • 【师/PPT】分类视角致命伤（P75）：各位置按次序二分类 → 是 pipeline（管道），前一步的错往后传导、每步只是局部最优（"决策 1 时管不着 2、3、4"）→ 需要联合决策 / 全局最优

一句话总结：位置二分类把切分接进成熟分类器，NB/KNN/MaxEnt/DNN 依次增强，但 pipeline 的误差传导与局部最优逼出了"序列标注"这一新视角。

9. 基于序标的切分：BIO + HMM/Viterbi

线索：BIO 三个标签各代表什么？/ HMM 的"隐"在哪里？/ Viterbi 在解决什么问题？

内容：

  • 【师/PPT】序列标注视角（P78）：给每个字打标签，标签集 S={B, I, O}（B=词的开始字、I=词的非开始字、O=单独成词）；于是联合分类 → 序列标注，"切分 = 找最优标注序列"。例："有意见分歧" → O B I B I
  • 【师/PPT】HMM 隐马尔可夫模型（P80–P86）：以"天气考古"为例——过去某天天气冷/热（隐藏状态）观测不到，只能看到那天卖了多少冰淇淋（观测）；故两组参数：状态转移概率（今→明天气）与发射概率（天气→冰淇淋数量）。"隐"就在于状态是隐藏的。对应切分：观测集=汉字/标点，状态集={B,I,O}，状态转移=标签间转移（p(I|B)…），发射=标签→字（p(今|B)…）
  • 【师/PPT】直接算最优序列有 3ⁿ 种组合、大量重复计算（P93）→ 用 Viterbi 动态规划保留中间结果逐时刻递推、最后反向回溯（P98–P106 有完整算例，转写未逐步展开）。老师区分局部 vs 全局最优（P94–P97）：逐时刻单独取最可能状态可能得到"转移概率为 0 的不可能序列"，Viterbi 求完整最优路径；参数估计（P108）有标注用 MLE、无标注用 Baum-Welch（等价 EM）
  • 【师/PPT】HMM 的不足（P111–P112）：只用相邻局部信息，遇到"看见一个人网站/人影"这类"当前字同、前一标签同、当前标签却不同"的例会错，需利用后文信息
  • 【PPT】HMM 之后还有 MaxEnt+Markov=MEMM（P114–P119，局部归一化/模型偏置）、CRF 条件随机场（P120–P128）、深度网络+CRF（P131–P132）——转写未展开（见 corrections.md）

一句话总结：把切分建模成"字序列→标签序列"后，HMM 用状态转移+发射概率、Viterbi 求全局最优标签序列；BIO 与序列标注模型从此成为切分主流。

10. 学生分享：从 BASEBALL 到 RAG——问答的六十年

线索：1961 年的棒球问答和今天的 RAG，"同一个问题"是什么？/ 六十年里"拿答案的方式"怎么变？

内容：

  • 【同学/PPT 第 11 章】问答是 NLP 最古老的任务之一，标题"从 BASEBALL 到 RAG"——BASEBALL 是 1961 年棒球问答系统，RAG 是今天的检索增强生成，隔 60 年却面对同一问题（学生口播把 BASEBALL 念作"Facebook"❓）
  • 【同学】大模型三硬伤：幻觉（且自信）、看不到企业私有数据、知识静态 → 故回答前先做"检索增强"
  • 【同学】三阶段史：① 结构化库 + 人工规则（BASEBALL、LUNAR）；② 语义解析（GeoQuery、NL2SQL、TREC 评测、2011 年 IBM Watson 赢得"危险边缘"）；③ 检索（1971 向量空间模型 → IDF → 1995 BM25 的稀疏检索几十年 → 稠密检索的双塔/交叉编码器 → 2017 前后 FAISS 十亿级向量检索）
  • 【同学】RAG 检索 top-k 片段拼进提示词给大模型；变体有自我决定检索、重排、多跳、微调/反思、端到端联合训练。总结：六十年表达能力越来越强，但每代都在表达能力与可信可控间权衡，故折中"理解交给大模型、事实交给检索、关键场景用确定程序兜底"
  • 【师】提醒：AI 重度参与的学习成果，正式场合自己要先过一遍把好关

一句话总结：同一问题、六十年、五代方案——从结构化查库到稀疏/稠密检索再到大模型+检索，"理解交给模型、事实交给检索"是当下的可信折中。

全篇 takeaway（5 条）

  1. 一条演进主线：切分被问题一步步推着走——规则（固定词表、无上下文）→ 分类（引入上下文，但 pipeline 局部最优）→ 序标（联合/全局决策）。价值在于看"问题如何驱动方法"。
  2. 两个经验参数定生死：FMM/BMM 靠 MaxLen 与词典，简单快速却注定处理不了 OA/CA/OOV；加规则总有例外，根因是词表没有上下文。
  3. 一把尺子贯穿全课：评测要有带标准答案、覆盖够、说得清来源的数据；P/R/F1 加基线+天花板，回答"我的方法强不强、任务难不难"。
  4. 从分类到序标是关键一跃：把"分不分"从逐位置二分类（局部、误差传导）改成 BIO 标签序列的整体求解，HMM+Viterbi 给出全局最优。
  5. 同一问题六十年：问答史从 BASEBALL 到 RAG，始终在"表达能力 vs 可信可控"之间权衡；这也是任何技术史的一面镜子。
