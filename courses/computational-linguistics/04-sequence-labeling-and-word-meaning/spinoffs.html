1. Viterbi 与编辑距离：同一张表的两种用法

  • 主题串：动态规划 → 网格最短路 → Viterbi（状态×时刻）→ 编辑距离（字符×字符）→ 前向递推 + 反向回溯 → 为什么"记住来源"比"记住值"更重要
  • 锚点：本讲 §3（Viterbi 递推与回溯，转写 L190–L293）与 §7（Dis(i,j) 与 8 步回溯，转写 L556–L605）；课件 02-1 P94–P112、02-2 P14–P24
  • 为什么：两个算法在课上相隔四十分钟，学生容易当成两件事；其实只差"格子代表什么"。合并讲能一次打通 DP 的通用范式。
  • 增益：给出统一模板（状态定义 → 递推式 → 边界 → 回溯 → 复杂度），读者下次遇到 HMM、CRF、DTW、ASR 解码都能套。
  • 发布：状态 待写；链接 —

2. 90% 的 F 值为什么不够用

  • 主题串：SIGHAN 评测史 → F 值 90%+ → 用户仍抱怨 → 评测分布 ≠ 使用分布 → 领域词/OOV/标点混排 → 评测推动迭代
  • 锚点：§5（转写 L409–L420）；课件 02-1 P133–P138（评测年份、SOTA 表）
  • 为什么：这是"指标好看、体验很差"的经典案例，可迁移到所有 NLP 任务（NER、抽取、对话）。
  • 增益：教读者读评测表的三件事——语料来源、OOV 比例、评测单位；并给出"自建小测试集"的实操建议。
  • 发布：状态 待写；链接 —

3. BPE：把"词"变成超参的那一步

  • 主题串：词表爆炸/OOV/多语种 → 子词 → BPE 合并推演（low/lowest/newer/wider/new）→ er 9 次 → 词尾标记 → 停止条件 → 贪心编码
  • 锚点：§6（转写 L429–L507）；课件 02-1 P146–P165
  • 为什么：课上的推演只有五个词，是最好的最小可复现例子；多数科普直接讲"合并高频对"，却讲不清"停在哪、怎么编码"。
  • 增益：附一份 20 行可跑的 BPE 脚本与合并日志，读者能自己改语料验证；并解释 GPT 系中文 token 效率问题的来源。

4. 中文还要不要分词：字、词、byte 三级单位

  • 主题串：规则/统计分词 → 90% 天花板 → 预训练模型端到端 → 字 vs 词 vs 子词 vs byte → 下游任务差异 → 工程选型
  • 锚点：§5–§6（转写 L392–L527）；课件 02-1 P128–P165
  • 为什么：这是中文 NLP 十年未决的工程问题，且直接决定 token 成本与效果。
  • 增益：给一张"任务 × 单位"选型表（检索/分类/抽取/生成），并指出哪些场景分词仍是刚需（词典约束、可解释性、低资源）。

5. 意义的 22 种定义：词向量前史

  • 主题串：1923《意义的意义》→ 22 种定义 → 沟通失败 → 义素/义位 → 语义关系 → 分布假设 → word2vec 类比（China−Beijing ≈ USA−Washington）
  • 锚点：§8（转写 L620–L756）；课件 03-1 P1–P14
  • 为什么：多数词向量文章从 one-hot 讲起，缺"为什么非要表示"这一层；1923 年的 22 种定义是最好的开场钩子。
  • 增益：把"意义无法定义 → 只能表示 → 分布假设 → 向量"这条链讲成一条因果线，而不是罗列模型。
