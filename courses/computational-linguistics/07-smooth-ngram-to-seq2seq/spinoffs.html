衍生选题 · 第 7 讲

筛选判据（四条全过才留）：① 讲而未透；② 可验证（能跑代码或算数）；③ 与我的技术栈有关（Python / 服务端 / 知乎专栏读者能用）；④ 反直觉或可证伪。不产生纯观点稿。

t1 加 1 平滑到底把概率打掉了多少：一张图看 Laplace 的"暴力折扣"

  • 主题串：Laplace 平滑 / 折扣 / 高频压制 / 概率重分配
  • 发布：未发布（状态见文末索引表）
  • 类型：教程（可复现）
  • 角度：用真实词频分布模拟 Laplace 平滑，画出"原始概率 vs 平滑后概率"的散点图，标出 N/V 临界点，看高频词被压掉多少、零频词分到多少
  • 锚点：§一 L21–L55（04-1 P24–P32）
  • 为什么值得写：所有 NLP 教材都写"加 1 平滑简单但效果差"，但没人量化展示它到底有多差；老师课上只给了 V=1000、N=10000 的手算例子
  • 增益：附 50 行脚本，输入任意词频表，输出 Laplace/Lidstone/Good-Turing 三种平滑的对比图 + "want to" 类高频搭配的折扣率表
  • 目标技能：write-tech-tutorial

t2 KN 平滑的"上下文活性"：San Francisco 为什么特殊

  • 主题串：Kneser-Ney / 上下文多样性 / 词的活性 / 固定搭配
  • 发布：未发布（状态见文末索引表）
  • 类型：科普（可验证）
  • 角度：用真实语料统计"San Francisco"和"table"的上下文分布，计算 continuation probability，直观展示为什么 KN 要把它们区别对待
  • 锚点：§一 L82–L90（04-1 P37–P38）
  • 为什么值得写：KN 平滑是 N-gram 平滑的巅峰，但"词的活性"这个概念很抽象；用具体例子可以让读者一眼看懂
  • 增益：附 30 行脚本，输入语料，输出指定词的上下文分布柱状图 + KN 平滑前后的概率对比
  • 目标技能：write-tech-tutorial

t3 PPL 到底在衡量什么：从分支因子到熵的直觉链条

  • 主题串：Perplexity / 分支因子 / 信息熵 / 语言模型评估
  • 发布：未发布（状态见文末索引表）
  • 类型：教程（概念梳理）
  • 角度：把 PPL、分支因子、信息熵三个概念串成一条直觉链：PPL = 分支因子 = 2^熵，用"猜下一个词"的游戏来解释
  • 锚点：§二 L112–L147（04-1 P43–P47）
  • 为什么值得写：PPL 是 NLP 最常用的评估指标，但很多人只记"越小越好"，不理解它和熵的关系；老师课上用"心里门儿清"的比喻很形象，但没有展开公式
  • 增益：附交互式小工具，输入自定义概率分布，实时显示 PPL 和熵
  • 目标技能：write-tech-tutorial

t4 Bengio 2003 的"直连"为什么是 ResNet 的雏形

  • 主题串：NNLM / 残差连接 / skip connection / Bengio 2003
  • 发布：未发布（状态见文末索引表）
  • 类型：技术史（考据）
  • 角度：从 Bengio 2003 的 NNLM 直连结构，到 Highway Network，到 ResNet，梳理"输入直接连输出"这条思想线
  • 锚点：§三 L47–L70, L138–L144（04-2 P8–P18）
  • 为什么值得写：ResNet 是 CV 和 NLP 的标配，但很少人知道 Bengio 2003 就讨论过直连；老师课上提到"后来我就给大家提过一个 last"，这是重要的思想史线索
  • 增益：附 NNLM 最小实现（PyTorch 50 行），对比有/无直连的收敛速度
  • 目标技能：write-tech-tutorial

t5 梯度消失/爆炸的数值模拟：0.9 和 1.1 的连乘实验

  • 主题串：梯度消失 / 梯度爆炸 / BPTT / RNN 训练
  • 发布：未发布（状态见文末索引表）
  • 类型：教程（可复现）
  • 角度：用 Python 模拟反向传播时梯度的连乘过程，画出 0.9^t 和 1.1^t 的曲线，直观展示为什么 RNN 难以训练
  • 锚点：§四 L234–L246（04-2 P40–P42）
  • 为什么值得写：梯度消失/爆炸是 RNN 的经典问题，但很多教程只给公式不给直觉；老师课上用"蝴蝶效应"比喻很形象，可以数值化
  • 增益：附 20 行脚本，模拟不同梯度值下的连乘结果，可视化"消失"和"爆炸"
  • 目标技能：write-tech-tutorial

t6 LSTM 三门机制：用"遗忘、输入、输出"类比讲清楚门控

  • 主题串：LSTM / 门控机制 / 遗忘门 / 输入门 / 输出门
  • 发布：未发布（状态见文末索引表）
  • 类型：科普（概念可视化）
  • 角度：把 LSTM 的三个门比作"人事决策"：遗忘门 = 裁员，输入门 = 招聘，输出门 = 汇报，用具体例子讲清楚每个门的数学作用
  • 锚点：§五 L248–L294（04-2 P43–P58）
  • 为什么值得写：LSTM 是 NLP 的标配，但三个门的具体作用很多人记混；老师课上用"学会遗忘是境界"的比喻很有感染力，可以系统化
  • 增益：附 LSTM 单元结构图（SVG），标注每个门的输入输出和计算公式
  • 目标技能：write-tech-tutorial
