- **主题串**：Laplace 平滑 / 折扣 / 高频压制 / 概率重分配
- **发布**：未发布（状态见文末索引表）

- **类型**：教程（可复现）
- **角度**：用真实词频分布模拟 Laplace 平滑，画出"原始概率 vs 平滑后概率"的散点图，标出 N/V 临界点，看高频词被压掉多少、零频词分到多少
- **锚点**：§一 L21–L55（04-1 P24–P32）
- **为什么值得写**：所有 NLP 教材都写"加 1 平滑简单但效果差"，但没人量化展示它到底有多差；老师课上只给了 V=1000、N=10000 的手算例子

- **目标技能**：`write-tech-tutorial`

### t3 PPL 到底在衡量什么：从分支因子到熵的直觉链条

- **主题串**：Perplexity / 分支因子 / 信息熵 / 语言模型评估
- **发布**：未发布（状态见文末索引表）

- **类型**：教程（概念梳理）
- **角度**：把 PPL、分支因子、信息熵三个概念串成一条直觉链：PPL = 分支因子 = 2^熵，用"猜下一个词"的游戏来解释
- **锚点**：§二 L112–L147（04-1 P43–P47）
- **为什么值得写**：PPL 是 NLP 最常用的评估指标，但很多人只记"越小越好"，不理解它和熵的关系；老师课上用"心里门儿清"的比喻很形象，但没有展开公式
- **增益**：附交互式小工具，输入自定义概率分布，实时显示 PPL 和熵
- **目标技能**：`write-tech-tutorial`
