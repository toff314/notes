# Lab 02 · 梯度消失/爆炸的数值模拟

> 验证：反向传播时梯度的连乘效应——为什么 0.9 会消失，1.1 会爆炸。

## 运行

```bash
python3 run.py
```

## 输出

- 控制台打印：不同梯度值在时间步上的变化表
- `gradient_vanish_explode.png`：梯度随时间步的变化曲线

## 原理

1. RNN 反向传播时，梯度沿时间步连乘：∂L/∂h_t = ∂L/∂h_T × ∏(W^T · diag(f'))
2. 如果每步梯度 < 1（如 0.9），连乘后趋近 0（消失）
3. 如果每步梯度 > 1（如 1.1），连乘后趋近 ∞（爆炸）
4. 这正是 LSTM/GRU 引入门控机制的原因

## 关键观察

- 0.9^50 ≈ 0.005（几乎消失）
- 1.1^50 ≈ 117（已经爆炸）
- 1.0 附近是临界点，实际训练中很难恰好维持在 1.0
