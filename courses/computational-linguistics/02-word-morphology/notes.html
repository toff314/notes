计算语言学基础 · 第 2 讲 词形态分析 · 听课笔记

本讲一句话：词是自然语言处理的基本单元；本讲从"语料 → 单元识别 → 词的形态分析"讲起——英语用词形还原 + 三层知识（词典/配列/正字法）+ FST 处理词形变化，汉语则因"词无定界"而独有切分任务，难点集中在边界歧义（OA/CA）与未登录词（OOV）。

结构：绪论收尾（里程碑/体系/先驱）→ 第 2 章引言（语料/层次/单元）→ 英语词形态分析（断词/还原/FST）→ 汉语切分（字词之争/歧义/OOV）

可疑处：多处人名 ASR 不稳（刘倬、黄昌宁、俞士汶等），见 corrections.md

与我何干：分词/检索/输入法背后都是"消歧"；FST 与 seq2seq 是后续序列模型的历史底座

2. 绪论收尾（一）：研究史的"涓涓细流"与两个里程碑

线索：为什么说今天的巨变"绝不是突然发生的"？/ 2013 与 2018 各发生了什么根本变化？

内容：

  • 【师】老师自述：95 年本科毕设就做中文分词、96 年研究生做自动摘要，做到 2013 已近 20 年；当时国内做中文 NLP 的"用手指头数得过来"（哈工大/复旦/上交/北邮/北大/清华/微软亚研院…），北邮因通信热门而录取分极高
  • 【师】2013 表示之变（里程碑）：从独立符号（字、字母）→ 上下文敏感的向量（词向量化、知识向量化、句子向量化）——神经网络表征登场
  • 【师】2018 范式之变（里程碑）：从分任务各做一套模型（文摘一套、翻译一套）→ 一个基础大模型 + 预训练/微调的通用底座；此前大家觉得这些任务"差太多，不可能用一个模型处理"
  • 【师】提醒"发展传承、量变到质变"：连 Transformer 也借鉴了 CNN 等大量前作，不是某个人凭空创新

一句话总结：80 年积累到两个里程碑——2013 换"表示"、2018 换"范式"，今天的通用能力是量变到质变。

3. 绪论收尾（二）：知识体系、评测之力与"大模型成为研究对象"

线索：自然语言为什么特别依赖"公开评测"？/ 本体（ontology）为什么又火了？/ 可解释性要回答哪些问题？

内容：

  • 【师/PPT】知识体系（P5/P61）：基础 = 语言学 + 计算 + 认知（科学）；两大维度 = 处理单元（词→句→篇章，下含字/子词、短语、段落）× 处理维度（语法/语义/语用）；最右强调跨学科交叉，"AI 的应用是无界的"
  • 【师】本体（ontology）：大模型"什么都会一点"，但在专业领域不够用；业内做法是把专业知识组织成本体图谱（结合知识图谱技术），做成可复用成果——老师举了蚂蚁集团做本体库的例子
  • 【师】评测的力量：语言主观、难像通信那样用误码率/时延度量，"公说公有理"阻碍研究 → 官方推公开评测题与公开语料（训练集公开、测试集先扣住"不漏题"）；数据公开 + 代码公开后迭代陡快，英语先行、中文（中国中文信息学会）随后追赶
  • 【师】可解释性（interpretability）：神经网络不可解释，大模型自己成了研究对象——它学到了什么知识？知识存在哪（哪个模块/块）？如何学习、如何运用、如何被激发？如何为各种任务给出结果？老师举例：其优秀学生正研究幻觉的成因与干预

一句话总结：知识体系是"单元×语法语义语用×跨学科"；评测与开源数据/代码是领域加速器；不可解释性把大模型本身变成了研究对象。

5. 第 2 章引言：语料、层次结构与"方法三件事"

线索：corpus 的词根为什么是"尸体"？/ 理解与生成的方向有何不同？/ 处理一个语言任务，方法上要完成哪三件事？

内容：

  • 【师/PPT】语言是人类交流工具，分横向（同期面对面）与纵向（跨时间——读书、看电影）；语料（corpus，复 corpora）承载纵向交流（P3）；老师点出 corpus 词根意为"尸体"——它"活着的现场"不在了，留下来的是定格的形态
  • 【师/PPT】语料按载体（P3）：文本语料（手写/印刷，视觉）、语音语料（听觉，课上放了一段手机号标注的语音）、以及独立于载体、可直接计算机编码的语料——CL 主要处理第三类，扫描/印刷体的转换不展开
  • 【师/PPT】语料呈层次结构（P4/P5）：篇章 → 段落 → 句子 → 短语 → 词 → 子词
  • 【师/PPT】理解 vs 生成（P5）：理解是自下往上汇聚（词→句→段→篇的逐层抽象，像 CNN；大模型也按词序列读入）；生成是自上往下规划（先定整篇说什么、分几段）
  • 【师/PPT】方法侧三条腿（P5/P6）：单元识别（先找到单元）、单元表示（如向量）、组合（单元如何组合）；识别按粒度（P6）：文本切割（按主题切篇章）→ 句子分割（靠标点就足够好）→ 短语识别（NER、事件/关系抽取）→ 词形态分析（找出词）→ 更小的子词切割（粒度更小、语言无关）——本章取"词"这一层
  • 【师/PPT】组合的三种结构（P5）：线性（序列 → RNN）、树（句法/依存分析 → 树算法）、图（篇章图 → GCN）；例证：检索"和服"（"鞋子和服装" vs "鞋子/和/服装"）直接影响检索准确率（P9）

一句话总结：语料是被"定格"的语言、按层级组织；理解自下往上汇聚、生成自上往下规划；任何任务都拆成"找单元—表示单元—组合单元"。

6. 英语词形态分析（一）：断词 Tokenization

线索：为什么英语断词"看起来平凡"却麻烦？/ "差点没上上上上海的车"难在哪？/ 常用什么工具？

内容：

  • 【师/PPT】断词（Tokenization）：在符号序列中找出词序列、确定词的外部边界（P8）；词是组成句子、也是后续 NLP 的基本单元（P9）
  • 【师/PPT】英语："I've read the book" → "I have read the book"；中文例："差点没上上上上海的车" → 差点/没/上/上/上/上海的车（P8）——中文断词之难、且英汉断词规律不同，由此可见
  • 【师/PPT】英语断词看似平凡任务（靠空格和标点），例外却多（P12）：缩写（I'm, i.e., Ph.D.）、本身带空格的词、数字字母大小写混排、含标点的串——"规则总有例外"
  • 【师/PPT】常用正则表达式方法：NLTK 的 nltk.regexp_tokenize（P13）
  • 【师】老师提醒：此处的 token（"词"）与今天的 token（子词）含义已不同，是一个值得思考的点

一句话总结：断词 = 定词的外部边界；英语凭空格标点近乎"平凡"，但例外（缩写/混排）使它离不开正则工具。

7. 英语（二）：词形还原 Lemmatization、构词法与剖析/生成

线索：词形还原除了"少存词"，还有哪些好处？/ 为什么穷举英文词形不可行？/ 剖析和生成是什么关系？

内容：

  • 【师/PPT】词形还原（Lemmatization）：分析词的内部结构、还原 token 的词典原形（P8）；好处（P9）：① 降低词典规模（dogs 与 dog 是一个词）② 把"长得不一样"的变形归到一起、意义可关联（利于相似度/检索）；中文此类任务少（城市化 → 城市+化；工业化/信息化/智能化）
  • 【师/PPT】英文构词法两类三级：{prefix} + {stem} + {suffix}（P14）；例：im-port（前缀+词干）、tele-vis-ion（前缀+词干+后缀）、unprecedented
  • 【师/PPT】穷举所有词形不可行（P15）：英语 prefix/stem/suffix 各 >200/>400/>200，相乘上百万级；土耳其语（黏着语）一个词可串出很长一串（Uygarlastiramadiklarimizdanmissinizcasina），无法靠列表法
  • 【师/PPT】剖析（Parsing）：串 → 内部结构（cats → cat+N+PL；caught → catch+V+Past）；生成（Generation）：结构 → 串（P16）——二者互为反向，本质是串到串的变换
  • 【师/PPT】引入中间层的双层结构（P17）：词汇层 ↔ 中间层 ↔ 表层，把不同规则分步使用

一句话总结：词形还原把变形归并到词典原形（省词典、聚语义）；剖析与生成是同一结构的两个方向，靠"中间层"分步用规则。

8. 英语（三）：三类知识与其建模——从 FSA 到 FST

线索：词形态分析涉及哪三类知识？/ FST 比 FSA 多了什么？/ fox+N+PL 怎么一步步生成 foxes？

内容：

  • 【师/PPT】三类知识（P18）：① Lexicon 词典（词/词根/词缀）；② Morphotactics 配列规则（词缀使用次序，如"词缀+复数"、动词 +tion+al 变形容词）；③ Orthographic(Phonological) Rules 正字法（拼写规则，如复数何时 +es、去 y 改 i+es）
  • 【师/PPT】词典建模：字符串列表查找效率低 → 用 FSA 有限状态自动机只存单段字母与状态转移（P20）
  • 【师/PPT】FST 有限状态转录机：在 FSA 基础上增加一条输出带子——输入带读、输出带写（P21）；例如正字法读入 "cats"、写出 "cat^s#"；FST 可对称复用——生成方向反向即得剖析
  • 【师/PPT】完整生成（P25–P31）：先用配列规则 FST（名词+复数：fox+N+PL → fox^s#），再用正字法 FST（e-insertion：fox^s# → foxes）；剖析方向反着走（foxes → fox^s# → fox+N+PL）
  • 【师/PPT】NLTK 有基于 WordNet 词典的 lemmatizer（P32）；手工设计 FST 工作量大，遂出现用 RNN 从状态中抽取 FST 的研究（Omlin&Giles 1996、Weiss et al. ICML2018、Michalenko ICLR2019 等，P34）；本质是 seq2seq（翻译/对话/摘要同理，P35），后续章再展开
  • ❓ 存疑：转写把 FSA/FST 听成"finish state automator / SSA / SST / FSD"、把 Parsing 拼作"passing"，已按 PPT 归一
  • 【PPT】P146–P165 进一步讲子词分割（Subwords）（BPE、unigram language modeling、WordPiece），02-2 分册另讲最小编辑距离——转写未覆盖（见 corrections.md 四）

一句话总结：三类知识分建两层——词典用 FSA、配列规则与正字法各用一个 FST 串联，即可"生成"或反向"剖析"词形。

9. 汉语（一）：切分任务与"字/词"之争

线索：为什么汉语叫"切分"而不叫"切词"？/ "词"在汉语里为什么会有争论？/ 同一个串为什么能切出多种结果？

内容：

  • 【师/PPT】汉语（独立语）主要任务在断词，即切分（Segmentation），词形还原基本没有（现代+化、初一）（P38）；故称 Chinese Segmentation / 汉语切分 / 汉语分词——老师 95 年毕设做的就是它
  • 【师/PPT】关于"词"的争论（P40）：赵元任"说汉语的人说到的是字"、吕叔湘"汉语现成的是字"、王力"汉语以字为单位"、徐通锵"字组"——于是由"词"转向"切分单元"，用切分不用切词
  • 【师/PPT】切分标准不唯一（P40）：李焕英 → /李焕英/ 或 /李/焕英/；胜利化工厂 → 胜利化工厂 / 胜利/化工厂 / 胜利/化工/厂——"看你的需要"
  • 【师/PPT】正是因为"没有唯一标准、谁都说不服谁"，评测才需要统一的公开标准（呼应 §3 评测之力）

一句话总结：汉语没有现成的"词"，只有"字"，所以任务叫"切分"；切分标准因人而异，这正是歧义与评测的根源。

10. 汉语（二）：边界歧义（OA/CA）、真实/伪歧义与 OOV

线索：交集歧义 OA 与组合歧义 CA 差别在哪？/ 真实歧义和伪歧义差在哪？/ 未登录词分几类？

内容：

  • 【师/PPT】边界歧义（Boundary Ambiguity）（P41）：武汉市/长江大桥 vs 武汉市长/江大桥——边界有多种选法
  • 交集歧义（Overlap Ambiguity, OA）（P43）：串 "XJY" 中 XJ、JY 都是词 → 两种切分；例：的确、结合成分、为人民工作、中国产品质量、努力学习语法规则（串越长，组合爆炸越"恐怖"）
  • 组合歧义（Combination Ambiguity, CA）（P46）：串 XY 中 X、Y、XY 都是词 → 两种切分；例：本科（他|本科|毕业 vs 非|本|科|人员）、多少（能穿多少穿多少，两解相反）、难过、天真/天真热
  • 混合歧义（P49）：一个串同时含 OA 与 CA（"有些人才能发挥…" / "这些人才…"）
  • 【师/PPT】真实歧义 vs 伪歧义（P50）：真实歧义在真实语料中出现不同切分（"地面积"）；伪歧义仅理论上可能（"市政府"实际 99% 以上是 市/政府）
  • 【师/PPT】未登录词（OOV, Out Of Vocabulary）（P51）：派生词（晕晕乎乎/高高兴兴、自动化）与命名实体（人名/地名/机构/商标/商品名）；老师用墨西哥女孩的超长姓名（名字+母姓+父姓+奶奶姓+爷爷姓）讲长人名
  • 【PPT】P53–P145 系统讲了汉语切分的三类方法（基于规则 FMM/BMM、基于分类、基于序标 HMM/CRF 与深度网络）与 SIGHAN 评测、SOTA 模型——转写未覆盖（见 corrections.md 四）

一句话总结：汉语切分的两大拦路虎是边界歧义（OA/CA，及混合）与 OOV（派生词+命名实体）；歧义又分真实与伪歧义。

全篇 takeaway（5 条）

  1. 骨架：语料 → 单元识别（篇章/句/短语/词/子词）→ 词形态分析；方法永远是"识别 + 表示 + 组合"三件事。
  2. 英语路线：断词定外部边界、词形还原做内部还原；三层知识（词典/配列/正字法）用 FSA→FST 建模，生成与剖析对称，本质是 seq2seq。
  3. 汉语路线：因"词无定界"，任务变成切分；标准不唯一（赵元任/吕叔湘/王力/徐通锵的"字/词"之争）。
  4. 两大拦路虎：边界歧义（交集 OA / 组合 CA / 混合）+ 未登录词 OOV（派生词、命名实体）；歧义别忘分真实与伪。
  5. 历史观：从涓涓细流到 2013 表示之变、2018 范式之变，量变到质变；FST/RNN/seq2seq 是后续序列模型的历史底座。
