自然语言处理基础 · 第 8 课（最后一课）· 听课笔记

本课一句话：最后一课是一场"从注意力到大模型"的收束——老师把第 7 课开了头的注意力从认知科学的"鸡尾酒会效应"讲起，沿"Q+X 两要素 → QKV 三要素 → 多头 → 自注意力"的问题驱动路线一路推到 Transformer，再用"Seq2Seq 是通用模型的一扇小窗"解释预训练范式为什么必然出现，最后 45 分钟把剩下没讲的五章（结构/篇章/人机对话/VGNLP/伦理）全部快速过完——并留下一句总结论：从 Q 到 QKV，每一步都是问题驱动的演化，而不是凭空设计。

2. 注意力从哪来：鸡尾酒会效应（第 1–2 节课）

线索：为什么讲注意力要先讲认知神经科学？

内容：

  • 【师】人工智能的名字就是"借鉴自然智能"：artificial intelligence——"先有人工才有智能"；早期特征工程、今天的人工审核都说明 AI 脱离不开人的因素。
  • 【师】鸡尾酒会效应：嘈杂酒会上你与一人聊天，周围谈话不会打断你——人在强噪声下仍能自主、有目的地选择性加工信息。
  • 【师】为什么要选择性加工？脑处理容量有限：蜜蜂记住新路径必须忘掉旧路径——这正是 LSTM 遗忘门的同类逻辑（呼应第 7 课）；老师引申："学会遗忘不开心的事，生活得更愉快"（金鱼的比喻）。
  • 【师】两种注意：自上而下（自主注意：目标明确，由大脑引导，如专心聊天）；自下而上（反射性注意：刺激驱动，如突然打雷、迪士尼超大花车把所有人注意力吸走）。
  • 【师】借鉴到计算模型 = attention mechanism：模拟自主注意（外部目标驱动）→ 软注意/硬注意；来自自身引导的 = 自注意力（self-attention，Transformer 里大量使用）。

一句话总结：注意力机制不是发明而是借鉴——鸡尾酒会效应（自主注意）+ 处理容量有限（必须遗忘），认知科学早就把原理讲清了。

3. 软注意力：从 Q+X 到权重计算（第 2 节课）

线索：最早的注意力怎么算？打分函数有哪些？

内容：

  • 【师】软注意 = 0–1 之间连续决策（硬注意 = 0/1 离散，取最大）。主流用软注意。
  • 【师】最早没有 QKV，只有 Q 和 X：decoder 当前状态作为 Q，对 encoder 每个时间步状态（X）算相似度打分 → softmax 得注意力权重 → 加权求和出新表达。
  • 【师】打分函数：线性（直接点乘）、缩放点积（点积除以维度，后为 Transformer 主用）、双线性（中间加 W，对前后各做一次线性变换）。
  • 【师】数值样例：Q 与 X1/X2/X3 算出权重 0.38/0.31/0.29（看似差别不大），但加权重算后新向量明显偏向 X1——"不同查询引导，会产生偏向不同词向量的新向量"：查询修正了表示。
  • 【师】机器翻译例（呼应同学报告）：译到 "apple" 时注意力自动偏向源句的"苹果"。

一句话总结：注意力第一步不是 QKV 而是 Q+X——用相似度+softmax 把"当前最需要什么"变成对历史状态的加权，查询本身会重塑词向量。

4. 多头与"必要性之问"（第 2 节课）

线索：为什么出现多头？为什么后来有人质疑注意力没用？

内容：

  • 【师】一个 Q 不永远是目标 → 查询通常有多个 → 多头注意力自然出现：多个 Q 各自算注意力再拼接、映射；"不同引导头偏向不同输入"，增加参数规模、提升模型容量。
  • 【师】关键问题（老师特意展开）：attention 之后还有 Wo 映射（可学习），那"前面辛辛苦苦算的注意力，会不会被后面的调整破坏掉？既然后面都可学习，前面还有必要吗？"——研究者认真讨论过。
  • 【师】问题的根源：Q+X 方案里，注意力完全由输入决定，输出侧的调整可能把它"洗掉"，两段的作用无法区分。

一句话总结：多头来自"查询天然多个"；而"注意力会不会被输出映射冲掉"这个必要性之问，正是 QKV 出现的伏笔。

5. QKV 三要素：把 X 拆成键和值（第 2 节课）

线索：QKV 从哪来？和 Q+X 差在哪？

内容：

  • 【师】解法：把 X 拆成两个角色——键 K（算注意力分布）、值 V（在值上求和）：分布用 K 算，但求和保留"原纸上的 X"——之前担心的"被改掉的 X"由此保住。
  • 【师】QKV 能灵活描述各种情形：K、V 都由 X 得来（常用）；全来自自身 = self-attention（Q、K、V 全是 X）。
  • 【师】维度过高时点积数值差异过大 → 缩放点积。
  • 【师】再引入可学习参数：Q/K/V 各自基于 X 用独立映射矩阵（WQ/WK/WV）生成——任务反馈从这三个矩阵进来，"整体功能更强大"——这就是 Transformer 主用结构。
  • 【师】自注意力网络的性质（对称性/封闭性/恒等性）与数学探索，感兴趣自学。
  • 【师】Transformer 之前注意力已研究很多：Pointer 网络（用注意力选片段）等。

一句话总结：QKV = "分布用 K 算、求和在 V 上"的分工设计——保住原始信息 + 引入可学习映射，从 Q+X 到 QKV 是问题驱动的演化。

6. Transformer：替换 RNN（第 2 节课）

线索：Transformer 为什么出现？结构里每块是干嘛的？

内容：

  • 【师】RNN 两大死穴：不能并行（时刻依赖）+ 长距离衰减（越扯越远）。注意力恰能跨远距离、可并行 → "能否用注意力网络替换 RNN" → Transformer。
  • 【师】结构：继承 Seq2Seq 的编解码架构，各堆 6 块。编码块 = 多头自注意力 + 残差&层归一化 + 前馈层；解码块多一层编解码交叉注意力，且自注意力加 mask（自回归解码不能看未来 = 因果遮蔽）。
  • 【师】重要洞见：知识主要存在前馈层——多头自注意力负责"算"，FFN 负责"存"；后来很多外部知识注入工作都打在 FFN 上。
  • 【师】残差 = 直连（ResNet 式，梯度直传、收敛快——回应第 3 节开头 sigmoid 梯度问题）；层归一化 = 让深层堆叠的数值分布稳定。
  • 【师】并行化的代价：位置信息丢了 → 位置编码（sin/cos；方案有 30 多种，试了一圈发现 sin/cos 够用）。
  • 【师】后续改进方向：空洞注意力、长文本（XLNet 式滑窗）、非自回归解码、MoE（多专家共享结构不同参数，当时已提出）。
  • 【师】不可能三角：训练并行、性能优秀、推理高效——Transformer 占了两头牺牲推理，另有结构试图三全但没成气候。
  • 【师】时代感："各种智能体之前是大模型，大模型之前是各种 Transformer"。

一句话总结：Transformer = 注意力（可并行、跨距离）替换 RNN + 前馈层存知识 + 残差保梯度 + 位置编码补顺序；它的爆发不是设计巧，而是踩中了 RNN 的两个死穴。

7. 预训练范式：通用模型的"小窗户"（第 3 节课）

线索：为什么一定要编码器-解码器？预训练范式怎么形成？

内容：

  • 【师】学生问"为什么一定要编解码架构"→ 回到 Seq2Seq：串到串的转换让一个模型适配所有 NLP 任务——对话、翻译、问答、摘要统一成 sequence to sequence，"这才糊弄到一块儿"，是通用模型的一扇小窗户。
  • 【师】老师提醒：AIGC 是"通用的生成式人工智能"（课堂口径）。
  • 【师】范式迁移：每任务一个模型 → 预训练基座模型 + 微调（任务头不过是一个 MLP）→ 带出 transfer learning 研究方向。
  • 【师】三种结构分流：只用编码器（BERT，曾引领潮流）、只用解码器（GPT 1/2/3 起步不显眼，ChatGPT 一出全场目光聚焦解码器）、编解码（BART/T5，算力紧张时实用区还很好用）。
  • 【师】T5 = Text-to-Text Transfer Transformer（5 个 T）：任务前缀让同一架构区分任务——指令微调的雏形。
  • 【师】自监督（不靠标注）让语料不受限 → 越训越大。
  • 【师】预训练 = 大模型的前一步，是 NLP 的范式革新："大规模通用语言与世界知识"此前不可想象。
  • 【师】前沿引申：PLM 与人脑的相似性——老师课题组用脑电 vs 大模型隐层状态做比较，已有发现，欢迎交流。
  • 【师】大模型部分（RLHF、prompt、评测等）同学都熟，略过自学。

一句话总结：Seq2Seq 把一切任务变成"串到串"，才有了"一个模型解决所有任务"的曙光——预训练+微调范式与迁移学习由此而来，BERT/GPT/T5 是同一扇窗的三个位置。

8. 最后 45 分钟：五章快览（第 3 节课）

线索：剩下的结构/篇章/对话/VGNLP/伦理，各章"当时为什么研究"？

内容：

  • 【师】结构（第 5 章）：字词 token 之外语言还有"结构"，大模型把研究必要性"遮盖"了但没人敢说不需要。成分句法（上下文无关语法/PCFG/Earley/句法树，NP/VP/PP 短语标注）——"早年多么痛苦"，现在用得少，但句法树对歧义分析仍有帮助；依存分析：句法是树，依存更像图（词为节点、支配/从属为边，从谓语出发分主语/直接宾语/间接宾语，例句 "I give him a red apple"）；语言复杂性：乔姆斯基层级——正则语言规则说得清、越往上越灵活，有人用泵引理证明"自然语言不是正则语言"。
  • 【师】篇章（第 6 章）：单元从词到句再到篇章；篇章难、真做的人不多。衔接 cohesion vs 连贯 coherence 是两个概念——语言学研究精细至此。词汇衔接例（阿Q 正传）：指代消解/coreference resolution（阿Q="他"）；回指（有先行词）可视为共指（同一对象）的特殊情形；mention detection、实体链接等评测任务由此发展；Winograd Schema："city council denied demonstrators a permit because they feared/advocated violence"——同一个 they 指代随从句改变，理解之难可见一斑；事件共指（多文档是否同一事件，新闻聚类用）。句子连贯：RST 修辞结构理论（详述/并列/因果等关系构成语篇树，阿Q 段例）；文本表示：TF-IDF → SVD 降维 → 降维结果难解释 → 主题模型（LSI → pLSI → LDA：狄利克雷先验"调色板"式生成 + 吉布斯抽样）——后被词向量替代。
  • 【师】人机对话（第 7 章）：王老师研究多年梳理的发展脉络 + 关键节点，PPT 放自学。
  • 【师】VGNLP（第 8 章）：视觉接地 = 视觉与文本跨模态连接；两张荷花图配不同句子哪张更贴——"一图值千言"；语言解决不了的问题也许多模态能介入；应用如体育赛事自动解说、文生图。
  • 【师】伦理（第 9 章）：大模型越来越快引发担忧——性别/职业偏见、"有毒"内容、GPT 生成虚假信息；"作为科研人员，要对伦理有一种敬畏"。
  • 【师】收尾："到现在基本上我把所有课的内容都跟大家说了一下"。

一句话总结：五章快览的共同视角是"当时为什么研究"——结构是语言的形式骨架（树/图/层级），篇章是超出句子 Unit 的衔接与连贯，而大模型把"必要性遮盖"但没人敢断言不需要。

拿走这五条

  1. 注意力是借鉴不是发明：鸡尾酒会效应（自主注意）+ 脑容量有限（必须遗忘，LSTM 遗忘门同源）——认知科学先行。
  2. 从 Q+X 到 QKV 是问题驱动：多头来自"查询天然多个"；QKV 把 X 拆成 K（算分布）和 V（做求和），保住原始信息；WQ/WK/WV 让任务反馈有入口。
  3. Transformer 的洞见在前馈层：注意力管"算"，FFN 管"存"（知识主要存在 FFN）；残差保梯度、位置编码补顺序；不可能三角 = 并行/性能/推理效率。
  4. Seq2Seq 是通用模型的小窗户：一切任务统一成"串到串"，才有预训练基座+微调范式与迁移学习；T5 的任务前缀是指令微调的雏形。
  5. 大模型遮盖了结构研究的必要性，但没人敢说不需要：句法树（图/树/乔姆斯基层级）、篇章衔接连贯、伦理敬畏——旧地图上仍有未探明的领土。
