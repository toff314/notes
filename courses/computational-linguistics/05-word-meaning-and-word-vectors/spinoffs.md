### 1. 2000 个义原能不能盖完一门语言

- **主题串**：词典释义的循环 → 基本词假设 → 义原（HowNet 2000+）→ "打酱油/打毛衣"两个 DEF → 义原预测（Sememe Prediction）→ 新词新义（粉丝、饭圈）→ 义原集至今没有公认答案
- **锚点**：本讲 §2–§3（转写 L21–L137）；课件 03-1 P12–P19
- **为什么**：几乎所有 NLP 教材都提 HowNet，但很少讲清"为什么它没成为标准"——不是不好，是产能不够、出版即固化。
- **增益**：把"知识工程 vs 统计学习"的老争论落在一个具体资源上，读者能自己判断今天的大模型是否绕过了这个问题（答案是绕过，但没解决）。

### 2. 相似 ≠ 相关：语义场是怎么骗过词向量的

- **主题串**：sim(猫,狗) > sim(猫,桌子) → 语义相似 vs 语义相关 → 语义场（医生/病人/医院/急症）→ "苹果的屏幕"义项定位 → 词向量把相关词也拉近 → WSD 与检索里踩的坑
- **锚点**：§6（转写 L310–L341）；课件 03-1 P37–P38
- **为什么**：这是词向量最常被误用的地方——"向量近 = 意思近"在语义场上直接失效，而语义场恰恰是上下文里最常见的共现结构。
- **增益**：给一个可自测的小实验（取 20 组词对，人工标"相似/仅相关"，再对比余弦相似度排序），读者能亲手看到错在哪。

### 3. "无价"到底贵还是贱：反义关系的四个抽屉

- **主题串**：互补（生/死）→ 分级（庞大—微小）→ 关系（给/收、买/卖）→ 自反（cleave、无价）→ 为什么反义词典难编 → 反义在情感分析/对比学习里的用法
- **锚点**：§5（转写 L244–L271）；课件 03-1 P29
- **为什么**："无价"这类词是反义分类的天然反例，讲它能一次说清"反义不是二元对立"。
- **增益**：附一张四类反义的判定流程图（问三句：能否中间插程度？是否视角互换？是否同一动作指向自身？），可直接用于标注培训。

### 4. 哈夫曼树上做分类：14 次替代一万次

- **主题串**：softmax 的 O(V) 之痛 → 层次 softmax → 按词频建哈夫曼树 → 左小右大 → 路径概率连乘 → 高频词路径短 → log₂10000≈14 → 与负采样的取舍
- **锚点**：§9（转写 L601–L651）；课件 03-2 P22–P34
- **为什么**：多数科普只说"层次 softmax 更快"，讲不清"为什么按词频建树"和"解码时到底算了几次"。
- **增益**：附 30 行 Python 实现（建树、编码、路径概率连乘），用课上 6 词词频 6/10/40/5/30/4 跑出与课件一致的路径，读者可对照。
