# 第 4 讲 · 自测与疑问

## 自测

### 一、看图基础

1. 频谱仪为什么从 0 Hz 开始扫就够了？"负频率"在什么语境下才出现？
2. 一台频谱仪上右下、右上、左上、左下四张图分别是什么？哪一张能看见被大信号盖住的小信号，为什么？
3. dBm 与 dBm/Hz 是什么关系？已知 RBW 时，怎么从功率谱密度回到绝对功率？
4. RBW 与频率分辨率是什么关系？两个载波间隔 1 kHz，RBW 要设成多少才能分开？

### 二、架构与测量

5. 示波器与频谱仪在接收机架构上的根本区别是什么？各自的代价是什么？
6. 为什么说示波器"暴力"？用本讲例子说明 1.25 GSa/s 对应多宽的分析范围。
7. 超外差频谱仪的"本振调到哪儿就看哪儿"如何换来采样率的节省？

### 三、参数反推

8. AM 信号的调制指数怎么从频谱上测出来？Δ = −6 dB、−12 dB、−26 dB 分别对应多少？
9. dB 的定义是 10log(P₁/P₂)，为什么换到电压会变成 20log(V₁/V₂)？50 Ω 在这里起什么作用？
10. 已知 WCDMA 码片速率 3.84 Mcps、带宽 5 MHz，用 B = Rs(1+α) 反推滚降系数大约是多少？
11. 等效矩形带宽是什么？为什么需要它？

### 四、识别与管理

12. 不加发射滤波器会导致什么？为什么运营商必须测邻道泄漏比？
13. 为什么"提一个符号速率就够了"，而提频点、带宽、信噪比、平坦度、尖峰数都不够好？
14. 深度学习相对经典模式识别三步流水线改动了哪一步？为什么这个改动关键？
15. 频谱"不够用"与"没用满"如何区分？审计看什么指标？
16. 为什么 6G 要往高频走？"频率越高带宽越大"这个说法准确吗？请给出更准确的表述。
17. 车载雷达为什么需要 2–4 GHz 这么宽的带宽？用距离分辨率公式说明。
18. I/N = −12.2 dB 看起来在物理上不可能，为什么实际成立？

### 五、制度与博弈

19. 中国/欧洲/美国/ITU 分别由谁管频谱？FCC 与 NTIA 的分工是什么？
20. ITU 三区怎么分？中国属第几区？
21. 频谱模板（spectrum mask）约束的是什么？型号核准为什么必须要它？
22. FCC 12.2–12.7 GHz 之争中，Dish 一方与 SpaceX 一方的核心分歧有哪几个？
23. WRC-23 在 IMT 上新增了哪些频段？6 GHz 的结论对中国意味着什么？

## 提取练习协议

1. **遮住笔记**，只看上面的问题，口头作答（每题 60 秒内）。
2. **自答不出的**，标记进「我没掌握的」，回到 notes.md 对应小节重读一遍再答。
3. **费曼环节**：把「调制指数可测」和「为什么往高频走」两件事，讲给一个不懂通信的人听，要求对方能复述。
4. **次日复述**：合上全部材料，在白纸上画出"从频谱图能读出什么"的树状图。
