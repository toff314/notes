S1 RIS 的隐藏成本：三次信道估计与频段约束

  • 主题串：RIS 论文都假设 CSI 已知 → 实测要三次估计 → 开销随单元数×配置数增长 → 所以只在毫米波视距场景成立。
  • 锚点：转写 §8「所有缺陷都来自这个」「毫米波 30 GHz」「低频要估的信道太多」；PPT P38–P39 信道估计流程、P30 频段动因。
  • 为什么：老师给了结论但没给数量级，读者最容易在这里被"RIS 万能"的宣传误导；这条线能把宣传与工程现实对齐。
  • 增益：可推一个导频数闭式（∝ N 单元 × K 配置），代两组参数给出"低频要估几十万条等效信道"的量级，配一张开销随频率变化的示意图。

S2 半静态 RIS：为什么工程上不要"实时智能"

  • 主题串：学术默认 RIS 实时可调 → 工程实际是"电子皮肤"式半静态 → 电池供电、调一次管几天 → "智能"该放在网络侧而非板子上。
  • 锚点：转写 §3「电子皮肤」「调一次管好几天」「电池能撑」；PPT P19–P20 材料与调节方式。
  • 为什么：这是学术与工程的口径差，几乎没人正面写；且能解释为什么 RIS 商用进展慢。
  • 增益：给出"实时 vs 半静态"的控制回路对比图（谁在算、多久算一次、能耗落在哪一端），并列出三类适合半静态的场景。

S3 通感一体里"资源分开"为什么赢了"深度融合"

  • 主题串：ISAC 宣传"一体化" → 工程多用分立部署 → 因为共硬件后干扰路径从 1 条变 3 条 → 折中成本高于频谱收益。
  • 锚点：转写 §7「分开部署最省事」「整合以后干扰路径三条」；PPT P34–P35 单双基地与整合级别。
  • 为什么：反直觉且可量化，正好补上教材只讲"一体化好处"的空白。
  • 增益：画干扰路径图（分立 1 条 / 共硬件 3 条），配一张"整合度—干扰管理难度"阶梯表。

S4 可移动天线：把位置变成优化变量，代价是 CSI 更贵

  • 主题串：MIMO 的自由度在相位与流数 → MA 增加位置 → 半波长深衰落被"挪开" → 但每挪一次信道就变，CSI 成本上升 → 离散网格与预配置是折中。
  • 锚点：转写 §10「缺的这个维度」「六个维度」「每挪一次信道就变」；PPT P47–P53 6DMA 模型、P75–P79 数值对比。
  • 为什么：中文系统材料极少，且老师把它讲成"与 RIS 同一本账"，这个类比可以直接做文章骨架。
  • 增益：半波长深衰落的仿真小图（位置—增益曲线）+ 六维自由度对照表（vs FAS、RET）。
  • 状态：idea

S5 用视觉和地图换掉信道测量：天花板在哪

  • 主题串：信道难测 → 用摄像头/地图先猜 → 跳过波束扫描、修 TDOA 误差、墙边 RISE 绕射 → 天花板由感知精度与训练数据量决定。
  • 锚点：转写 §9 四条线；PPT P42–P46 RISE 与感知辅助。
  • 为什么：四条线散落在课件与专利里，没人合起来讲；"灯下黑"这个场景读者有直观感受。
  • 增益：四条线的输入/输出/失效条件对照表 + 一张"感知精度 vs 可获得增益"曲线（定性）。
