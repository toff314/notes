# 我的课上笔记（第 2 讲）

**本次未提供课上笔记。**

本文件按 `write-lecture-notes` 的约定保留占位：如果你有手写/电子笔记，把它贴到本文件（或另存为 `my-notes-raw.md` 并在 README 里注明路径），我会据此重跑"课堂记录 ⊕ 我的笔记 ⊕ 原始转写"三源交叉，按以下顺序处理冲突，并把每处冲突写入 `corrections.md`：

1. **我的笔记**（听课当时记下的、老师口头补充但没进转写的）
2. **课堂记录**（`notes.md`，即本讲笔记正文）
3. **原始转写**（`raw/transcript.md`，只作事实核对，不作理解依据）

优先级之所以这样排：转写只记录"说了什么"，笔记记录"当时听懂了什么"，二者冲突时以能自洽解释文献的那一方为准，并在差异报告里留痕。
