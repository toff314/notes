# 习近平著作选读 · 第 2 讲（专题三 · 专题四）· 思路大纲

## 主线（讲者是怎么推下来的）

1. **交底（本讲地图）**：一次课连讲两个专题、五篇文献；先报讲义页码（56 / 62 / 74 / 82 页），每篇给 5—8 分钟速读 + 一个问题，读完即答、答完即归。
2. **专题三起手（制度）**：从"社会主义国家为什么允许私有制"这个最容易被质疑的点切入——1949 私有为主 → 1953—1956 三大改造 → 单一公有制 → 1978 放开非公，用"生产力不发达 + 马克思消灭私有制的前提"给出理论解释。
3. **换挡的事实（速度）**：2012 年前年均 12% → 现阶段 4.6%（2026 前三季）、目标 5% 左右；把"降速"作为一个必须解释的现象摆出来。
4. **换挡的原因（三因）**：先让同学答（八人聚类），再由老师归为三条——经济规律（体量 + 三驾马车钝化）、社会主要矛盾变化、全球体系结构（四层国家 + 美元霸权 + 3 万美元门槛）。
5. **换挡的方向（五个词）**：创新、协调、绿色、开放、共享；用宁德时代"分红 80 亿 vs 一线工人涨 150 元"把"共享"落到分配（按劳 + 按资）。
6. **换挡的空间（双循环）**：14 亿人口的超大市场是真的，但"未富先老"、城乡差距（1.3 亿农村老人每月不足 200 元）使内需不足，所以扩内需要回到分配与保障。
7. **专题四起手（改革从哪来）**：十一届三中全会 → 计划经济（指令性、计委、苏联模式）→ 市场的三特征（价格引导、竞争创新、可破产）→ 市场作用的定性"补充 → 基础性 → 决定性"。
8. **改革的真问题（政府）**：政府有没有负面作用？同学答"一抓就死一放就乱 / 时滞 / 遏制创新 / 裁判兼运动员"，老师补"官员政绩观错位（独山县）""政府有自己的利益（中央与地方不一致）"→ 结论是"有为政府 + 有效市场"。
9. **改革的载体（治理骨架）**：五级政府（34 / 330 / 2800 / 3 万 / 60 万）+ 四套班子（党委管决策与人事）+ 条块分割（县教育局受县委县政府与市教育局双重领导）。
10. **制度的评价（自信与不足）**：从一张美国急诊账单（15 分钟、5670 美元）说到种牙 13000 → 5000、支架 3—4 万 → 几千、医保近 10 亿人；再用"议行合一 vs 三权分立""2035 年才更成熟定型""意见表达渠道偏窄"收尾——既讲优势，也讲待完善。

## 如果只记三件事

- **降速三因**：经济规律（体量越大越慢）／主要矛盾（从"有没有"到"好不好"）／全球结构（四层国家 + 美元霸权，3 万美元门槛）。
- **政府与市场**：市场作用从"补充 → 基础性 → 决定性"；政府要"有为"，但会失灵（时滞、裁判兼运动员、政绩观错位）→ 有为政府 + 有效市场。
- **治理骨架**：五级政府 + 四套班子（党委管决策与人事）+ 条块分割，是理解中国政策如何落地（以及为何走样）的底层地图。
